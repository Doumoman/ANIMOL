# 공통 9종 · 테마 디자인 개정

기준은 joint_finish_v4의 32px·Sweetie16·20스타일과 사용자의 이번 수정이다. 표의 소재는 기능을 읽을 수 있는 형태로 표현한다. 지형 몸체·광원·문양 위상은 원본을 유지한다.

|---|---|---|---|---|---|

C01은 별도 기능 그림이 완전히 투명하다. v4의 윗면 8px만 사용하므로 팻말·아래 화살표·하부 큰 블록을 만들지 않는다.
C02는 천장·하부 틀·큰 박스를 제거했다. 세로 접촉판과 뒤 고정부 사이를 흰색 지그재그 코일이 가로로 잇는다. 코일 위·아래는 투명하고 바깥 공기가 보인다. 왼쪽·오른쪽은 전체 기능 장식의 정확한 미러다. 기존 지형 몸체를 회전시키지 않는다.
C03은 넓은 발사판·높게 늘어난 흰 코일·짧은 바닥 받침을 분리해 읽을 수 있게 했다. 땅속 몸체 위에 작은 장식을 붙이는 방식은 폐기했다. 32px 장치 자체를 지형 위 빈 칸에 놓으며, 바닥 받침의 최하단이 지지 지형 윗면에 닿는다. 상판이 내려오고 코일 간격이 좁아지는 7프레임 후 원래 높이로 복원된다. 배경 박스·화살표·불필요한 점 명암은 없다.
C05는 불규칙 점 명암 대신 상판을 끝까지 가르는 연속 균열 3개로 4개의 큰 조각을 구분한다. 덮인 원본 상판을 함께 그리지 않아 균열 틈이 보인다. 조각 이미지 20개는 같은 warn 상판을 겹침 없이 잘라 만든다.
C06은 한 색의 면과 1px 윤곽만 쓴다. 흰 떡에는 점·갈색 얼룩·하이라이트·입자 질감을 넣지 않는다. 테마는 떡의 한 색과 주변 v4 구조로 구분한다.
C08은 고무 띠의 일정한 홈과 롤러가 같은 방향으로 움직인다. 화살표가 켜졌다 꺼지는 표시는 쓰지 않는다. 실제 이동 속도에 맞추려면 기존 벨트 속도로 phase를 계산하며 전역 지형 무늬 위상은 유지한다.
C10은 모든 테마에서 얼음으로 읽히는 흰색·청록색·파란색을 공유한다. 넓은 대각 반사 면 하나와 작은 고드름만 사용한다. 랜덤 반짝임·점 명암은 추가하지 않는다.
C04는 가시를 항상 표시하며 alpha=1이다. 점멸 예고의 박스·노란 상태 그림은 없다. C09 그래픽은 제작·선택·배치 대상에서 제거했다.

## 애니메이션

| 장치 | 프레임 | 기본 간격 | 재생 |
|---|---|---|---|
| C02/C03 | 작동 7 | 30ms | 압축 후 복원, 210ms 뒤 마지막 프레임 유지 |

| C08 | 방향별 8 | 80ms | 640ms 반복; 띠는 프레임당 1px 이동 |
| C05 | 밟음/예고/비활성 상태와 4개 조각 | 런타임 | 400ms 낙하, 80ms 후부터 페이드. Unity 기본 기능 사용 |

미리보기의 반복 충돌은 확인용이다. 실제 게임은 기존 착지·충돌 이벤트와 게임 시계를 사용한다. 무작위 타이머로 점유 상태나 물리를 다시 만들지 않는다.

## 픽셀 검수 규칙

- 32×32 안의 정수 좌표, Sweetie16, 자산 alpha 0/255, Point·압축 None·mipmap Off.
- 곡선의 계단 길이는 계획된 순서와 좌우 대칭을 따른다. 스프링은 연속 코일이며 고립 픽셀을 덧붙이지 않는다.
- 윤곽은 1px를 기본으로 하고 불필요한 검은 2×2 겹선은 제거한다. 정상 색 면의 2×2 블록은 지우지 않는다.
- 이미 정상인 v4 명암은 유지한다. 새 떡에는 내부 명암을 추가하지 않는다. 단색을 피하기 위해 잡음을 넣지 않는다.
- 상판·끝캡·청크 경계와 모든 프레임을 원배율·최근접 확대에서 확인한다. 자동 후보 검사는 완전한 미관 승인이 아니다.

지역 후보 M02 달그릇, R01 공명 수정판, R03 대전 수정판은 기존 그래픽 8개를 유지한다. 이번 공통 개정으로 지역 기능을 새로 확정하지 않는다.
