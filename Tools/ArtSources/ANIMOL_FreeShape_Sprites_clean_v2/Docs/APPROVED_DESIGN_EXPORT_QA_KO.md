# 승인 디자인 추출·픽셀 검수 기록

이번 패키지의 시각 원본은 `SourceArt/Approved/T01.png`부터 `T05.png`까지 다섯 파일이다. 승인 원본과 `Raw` 복사본 총 10개는 업로드 원본과 SHA256이 같다. 다른 시안과 미선택 제작 가이드는 포함하지 않았다. 원본 매핑과 해시는 `Data/approved_design_sources.json` 및 `SourceArt/approved_sources.json`에 있다.

`APPROVED_DESIGNS.html`은 승인 원본과 전체 추출 패널 80개를 보여준다. `DESIGN_GALLERY.html`은 최종 아틀라스와 문양으로 실제 32px 셀 지형을 조합한다. 원본·참고 패널과 Runtime 연결 셀을 구분하여 확인한다.

## 출력과 연결 계약

| 항목 | 최종 결과 |
|---|---|
| 디자인 | 5테마 × 4스타일, 기존 20개 styleId 유지 |
| 연결 | `ANIMOL_FREE_SHAPE_BLOB47_V1`, 47형태 × 4위상 |
| 셀 | 32×32px, PPU32, 점유 1×1, 셀 PNG 3,760개 |
| 연결 부품 | 16×16px 1,600개 |
| 아틀라스 | 256×192px 80장 |
| 문양 | 128×128px 20장, 4×4셀 시각 범위, 추가 점유 0 |
| 원본 디자인 참고 | material/frame/ring/motif 전체 패널 80개 |
| 조합 예시 | 320개 |
| 출력 팔레트·알파 | Sweetie16, 알파 0 또는 255 |

V1과 최종 V2의 계약·마스크·위상·문양 배치·Sprite 파일 경로·rect를 비교하여 동일함을 확인했다. 아트 버전은 2다. 기존 V1 manifest의 5,883개 파일도 모두 기존 SHA256과 일치한다.

## 원본을 유지하며 교정한 출력

| 영역 | 처리 |
|---|---|
| 원본 형태·장식 | 전체 참고 프레임 유지. 코너 패치를 16×16 전체로 사용하여 걸쇠를 자르지 않음 |
| 가로·측면 연결 | 가로는 원본의 중앙 16px 레일, 측면은 32px 주기 사용. 천장·측면을 만들기 위해 그림을 회전하지 않음 |
| T01_A 몸통 | 원본 재료 면의 역할 팔레트로 작은 회색 군집을 제외하고 청록색 대면 유지 |
| T01_A/B 레일 | 정상 금색을 허용 팔레트에 유지하여 크림 띠의 주황 오변환 교정 |
| T02_B | 적갈색 판재 줄 복원. 몸통 각 원본 행의 역할색으로 주황 55행·적갈색 8행·금색 1행을 정돈 |
| T02_D | 원본 노란 레일 복원. 몸통의 밝은 회색 58행·짙은 회색 6행을 유지하며 경계의 고립 회색 점 제거 |
| T05_C | 큰 분홍색 문양 복원. 접합 문양의 보라색 세로 팔 내부가 회색·파랑으로 갈라지던 색 매핑 교정 |
| T05_D | 밝은 청록 띠와 분홍색 쐐기 색 복원 |
| T05_B 레일 | 중앙 상단 청록 면의 3행만 역할 팔레트로 정돈. 다음 행의 파란 그림자·코너·전체 참고 프레임 유지 |

처리는 원본 crop, nearest 표본 추출, 역할별 팔레트 변환과 조합이다. Lanczos·median·블러를 사용하지 않았으며 새로운 프레임이나 장식을 그려 대체하지 않았다. 각 행의 원래 색 분포와 허용색은 lookup의 `materialSampling.rolePalette.horizontalBands`에 기록했다. 마지막 T02_B/D 몸통 교정 전후 참고 패널·프레임·코너·나머지 18종 몸통 등 778개 파일의 SHA256이 같았다.

## 실제 이미지 시각 검수

- 승인 원본 5장과 20스타일의 아틀라스 연락표 20장을 직접 비교했다. 각 표는 2048×1536px, nearest 4배, 47형태 × 4위상이다. 마지막 수정된 T02_B/D 두 표도 재생성 후 다시 확인했다.
- 20스타일의 single(4배), 가로 thin(2배), 세로 thin(원배율), overhang(2배), T 분기(2배), 최대 사각형(원배율), motif(2배) 총 140개 출력과 최종 5테마 pit/hole/stairs 보드를 확인했다.
- T04/T05의 큰 사각형 8개와 닫힌 구멍 8개를 원배율로 추가 확인했다.
- T01 레일·T02 레일·T05_C 접합 문양의 교정 영역을 nearest 8배로 확인했다. 지적된 오변환과 잘린 가로 걸쇠 조각이 사라졌다.
- T02_B/D의 body field와 body-only 셀, 실제 4위상 조합을 nearest 8배로 확인했다. 판재·명암 띠를 유지하며 고립 점과 작은 군집이 제거됐다.
- T01_B의 한 인접 검토 후보를 12배로 조합해 확인했다. 검은 2px 구간은 기둥·걸쇠 끝의 구조선으로 보였으며, 투명 틈이나 몸통 내부의 긴 중복선을 발견하지 못했다.

검수 범위에서는 다른 디자인 유입, 주요 모서리·걸쇠 소실, 빈 셀을 가로지르는 아트와 가시적인 사분면 틈을 발견하지 못했다. 연락표의 서로 다른 슬롯이 맞닿는 부분을 실제 지형 이음으로 판단하지 않았다.

## 남은 검수 범위와 한계

T03_D 종이 접힘, T05_B 광맥, T05_D 쐐기 경계에는 body-only 고립 후보가 각각 2개·1개·1개 남는다. 원본 형태의 작은 끝점과 겹치므로 일괄 삭제하지 않았다. T01_A 문양 끝캡·고리, T04_A 유리 문양과 일부 유리관·파셋에도 원본에서 파생된 작은 명암 면이 남는다.

T05_B 광맥은 원본 64px 몸통 core를 반복하므로 큰 지형에서 반복 간격과 절단된 사선 패턴이 보일 수 있다. 원본 전체의 긴 광맥을 그대로 늘린 결과는 아니다. 서로 다른 스타일 사이의 전용 전환 아트는 포함하지 않는다.

20개 연락표와 지정 조합의 시각 확인은 모든 픽셀·모든 합법 인접의 의미적 무결성 보증이 아니다. 자동 2×2 ink 후보도 모두 Doubles는 아니며, 승인된 구조선과 채워진 면을 구분해야 한다. 모든 윤곽이 정확히 1px이거나 모든 Jaggies/Doubles가 0이라고 단정하지 않는다.

이 제작 공간에서는 실제 ANIMOL Unity 프로젝트 설치·에디터 렌더·플레이·모바일 실기기 검증을 실행하지 않았다. 적용 명령은 `ANIMOL_CLEAN_ART_V2_APPLY.txt`다. Unity에서 실행한 결과는 별도 패치 결과 보고서에 기록해야 한다.
