# ANIMOL clean_v2 픽셀 마감 기준

이번 작업은 사용자가 승인한 다섯 원화의 픽셀 마감·추출·조합이다. 발판·측면·밑면·천장·구멍의 선을 정리하되 승인된 형태·색 배합·세로띠·클램프·상하 마감·모티프를 보존한다. 기존 32px 셀, 공용 Sweetie16, 47종 연결 규격과 물리 점유는 유지한다.

## 승인 원화와 작업 범위

시각 정본은 T01 `image(20261005-190222).png`, T02 `image(20261005-190237-2).png`, T03 `image(20261005-190303).png`, T04 `image(20261005-190219).png`, T05 `image(20261005-190312).png`의 다섯 원화다. 원본을 `SourceArt/Approved/T01.png`부터 `T05.png`까지 바이트 그대로 보존하고 SHA256을 기록한다. 업로드 이름과 경로의 대응은 `Data/approved_design_sources.json`을 따른다.

처리 범위는 픽셀 마감, 연결 부품 추출과 지형 조합으로 제한한다. 추가 아트 시안, 형태·색 변경안, 별도의 단순한 프레임을 생성하지 않는다. 몸체를 평평하게 만들기 위해 승인 원화의 세로띠·클램프·입체 결합부·상하 마감·큰 문양을 없애지 않는다. 앞서 제시된 두 번째 사진은 Jaggies/Doubles와 색 면의 품질 참고이며 실제 디자인을 대체하지 않는다.

승인 원화의 제작 프롬프트는 출처 기록이다. 그 기록을 승인 디자인을 다시 생성하거나 다른 디자인으로 교체하는 지시서로 사용하지 않는다.

## 색과 면

- 승인 원화의 주요 색 면과 배합을 보존한다. 단순한 면은 2~4개 주요 색으로도 읽히게 정리할 수 있지만, 이 수치를 맞추려고 승인된 색 영역이나 장식을 없애지 않는다. 공용 팔레트의 16색을 한 그림에 모두 추가할 필요는 없다.
- 승인 원화에 있는 단색의 넓은 면을 허용한다. 빈 느낌을 없애려고 임의의 밝은 점·검은 점·지글거리는 디더링을 새로 넣지 않는다.
- 명암은 구조를 설명하는 큰 연속 면으로 넣는다. 조각마다 불규칙하게 한 픽셀씩 번갈아 밝히거나 어둡히지 않는다.
- 소재의 결·접합선·장식은 승인 원화의 방향과 간격을 유지한다. 같은 면에 짧은 선과 점을 무작위로 추가하지 않는다.
- 질감 위상 변형은 외곽선 두께와 셀 이음 위치를 바꾸지 않는다. 위상마다 테두리 명암이 흔들리지 않아야 한다.

최종 적용용 `Art` 및 `Samples`의 불투명 색은 Sweetie16에 정확히 포함되어야 한다. 알파는 0/255다. 승인 생성 원본은 이 제한을 통과한 최종 Sprite로 설명하지 않는다. 원본의 바이트와 해시는 보존하고, 실제 출력에서만 팔레트 매핑과 픽셀 마감을 수행한다.

## 윤곽선

외곽과 오목한 경계의 윤곽선은 기본 1px로 설계한다. 위·아래·좌·우 끝에서 동일한 기준을 적용한다. 임의의 구간만 2px로 굵어지거나 겹쳐 보이는 선을 제거한다.

넓은 들보·벽돌·책등·결합부는 의도된 구조의 색 면이다. 이런 면을 테두리 두께 오류와 혼동하지 않는다. 구조의 넓은 어두운 면을 사용한다면 한 픽셀 윤곽과 명확히 구분되도록 배치한다.

밟는 윗선은 옆모습의 수평 경계로 표시한다. 탑뷰처럼 기울어진 넓은 윗면, 원근 사다리꼴, 셀마다 높이가 흔들리는 윗선을 만들지 않는다. 밑마감·천장·측면에는 끝이 끊긴 선이나 임의의 튀어나온 점을 남기지 않는다.

## Jaggies 점검

Jaggies는 의도하지 않은 불규칙 계단 때문에 픽셀 곡선·대각선이 울퉁불퉁해 보이는 문제다. 원본 아트의 경로를 확대하여 다음을 확인한다.

- 직선에는 이유 없는 1px 돌출·홈·흔들림이 없어야 한다.
- 대각선에는 계획한 1:1 또는 2:1 등의 계단 간격을 사용한다. 길이가 불규칙하게 바뀌며 선 방향이 흔들리는 구간을 정리한다.
- 곡선은 곡률에 맞춰 계단 길이를 순서 있게 바꾼다. 모든 곡선을 동일 계단 길이로 만드는 것이 목표는 아니다.
- 외곽 모서리와 오목한 모서리의 꺾임이 대응해야 한다. 위상·셀 경계를 넘을 때 계단 경로가 끊기거나 되돌아가지 않도록 한다.
- 얇은 1셀 지형에서도 위·아래 또는 좌·우 윤곽이 서로 압착되어 지저분해지지 않도록 확인한다.

원래 점유 모양의 각진 굴곡은 지형 설계다. 마감 수정으로 이 굴곡을 임의로 둥글게 만들거나 충돌 점유를 바꾸지 않는다.

## Doubles 점검

Doubles는 선 경로에서 불필요하게 중복된 픽셀이 붙어 윤곽이 두꺼워지거나 둔해지는 문제다. 특히 대각선과 모서리에서 1px 선이 의도 없이 2px 폭 또는 2×2 덩어리로 바뀌는 구간을 검사한다.

- 외곽·내곽 선의 꺾임 주변에 붙은 중복 픽셀과 작은 검은 돌기를 제거한다.
- 직교 이웃으로 이어지는 윤곽을 두 번 덧그려 선이 두꺼워지지 않도록 한다.
- 아틀라스 조각을 결합할 때 양쪽 테두리가 같은 연결면에 중복되지 않아야 한다.
- 위상 이음·문양 끝에서도 중복 선이 생기지 않아야 한다.

모든 2×2 동일색 면을 Doubles로 취급하지 않는다. 벽·옥판·구름·종이·암석 내부의 정상적인 단색 덩어리는 면을 형성하는 필수 픽셀이다. 선 오류를 지우는 작업 때문에 정상적인 면에 구멍을 내지 않는다.

## 점 노이즈와 장식

작은 고립 픽셀, 억지 반짝임, 산발적인 밝은 점과 어두운 점을 점검하여 잡음을 제거한다. 승인 원화의 의도한 장식은 보존하고 읽을 수 있는 연속 픽셀 덩어리로 마감한다. 점 후보가 잡혔다는 이유로 클램프·세로띠·원화의 반짝임·큰 문양 전체를 삭제하지 않는다. 문양을 위해 새로운 충돌이나 점유를 만들지 않는다.

Jaggies와 Doubles를 없애는 방법으로 블러·안티앨리어싱·반투명 가장자리·선형 필터를 사용하지 않는다. 픽셀 경로 자체를 고친다. 전체 그림을 두꺼운 외곽으로 덮는 방식도 피한다.

## 검수 범위와 기록

최종 셀 3,760개, 연결 부품 1,600개, 아틀라스 80장, 문양 20개 및 조합된 예시를 함께 검토한다. 같은 픽셀 조각의 반복 출력이라는 이유로 셀 이음과 위상 경계 검토를 생략하지 않는다.

전체 디자인은 `APPROVED_DESIGNS.html`의 승인 원화와 패널 80개에서 확인하고, 연결된 셀과 지형 형태는 `DESIGN_GALLERY.html`·Samples·아틀라스에서 확인한다. 이 목록은 검수 대상이며 전부 사람이 검수했다는 완료 주장이 아니다. 결과에는 실제로 연 파일·스타일·형태·확대 배율을 적는다.

1. 원본 배율에서 발판의 밟는 위치와 구조를 읽을 수 있는지 확인한다.
2. 최근접 4배와 8배에서 직선·곡선·대각선·외곽·내곽을 확인한다.
3. 사각형, U자 구덩이, 내부 구멍, 천장, 얇은 가로/세로 지형, 계단·돌출부에서 선의 이어짐을 확인한다.
4. 전역 위상 네 조합·음수 좌표·청크 경계·문양 끝이 외곽선이나 질감을 갑자기 바꾸는지 확인한다.
5. 발견한 문제는 해당 스타일·파일·좌표·종류와 수정 전후를 기록한다.
6. 승인 원화와 비교하여 형태·색 배합·세로띠·클램프·상하 마감·모티프가 유지되는지 확인한다. 새로 단순화한 프레임이나 자체 생성 시안이 섞이지 않아야 한다.

자동 검출은 확인할 위치를 찾는 보조 수단이다. 후보가 0개인 결과는 검출 규칙에 걸린 위치가 없다는 뜻이며 Jaggies/Doubles가 전부 제거되었거나 모든 곡선이 자연스럽다는 보증은 아니다. 일부 원화·예시의 확인을 셀 전체의 미관 검수로 확대하지 않는다. 검출 후보, 실제 확대 검토, 사용자의 미관 승인을 구분하여 보고한다. 기존 v1의 QA·Unity PASS 수치를 clean_v2 검증 결과로 재사용하지 않는다.
