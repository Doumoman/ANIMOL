# ANIMOL 자유형 지형 아트 clean_v2

이 패키지는 이미 구현된 Scene View 자유형 지형 편집기에 넣을 아트 자료다. 사용자가 승인한 다섯 원화만 사용하며 처리 범위는 픽셀 마감·연결 부품 추출·조합이다. 형태·색 배합·세로띠·클램프·상하 마감·모티프를 보존하면서 외곽·밑마감·천장·측면·오목한 모서리의 픽셀 윤곽을 정리한다.

승인 원화는 T01 `image(20261005-190222).png`, T02 `image(20261005-190237-2).png`, T03 `image(20261005-190303).png`, T04 `image(20261005-190219).png`, T05 `image(20261005-190312).png`다. 승인 원본은 `SourceArt/Approved/T01.png`부터 `T05.png`까지 바이트와 SHA256을 보존한다. 실제 대응은 `Data/approved_design_sources.json`에 있다. 이전 두 번째 참고 사진은 픽셀 품질 참고이며 이 다섯 디자인을 대체하지 않는다. 새로운 형태·색 시안이나 장식을 뺀 단순 프레임을 만들지 않는다.

압축을 풀어 `APPROVED_DESIGNS.html`을 열면 승인 원화와 20스타일의 완성 소재·외곽·내곽·문양 패널 80개를 볼 수 있다. 실제 32px 연결 셀로 칠하고 지우는 지형 조합은 `DESIGN_GALLERY.html`에서 확인한다. 두 화면은 각각 전체 디자인 보존과 셀 연결 결과를 확인하는 용도다. 원화 이미지의 상대 경로를 유지한다.

## 유지하는 배치 규격

5개 테마, 테마당 네 스타일을 제공한다. styleId는 기존 T01_A부터 T05_D까지 유지한다. 각 스타일의 정규화 형태 47종과 위상 4종으로 셀 Sprite 3,760개를 구성한다. PNG 셀은 32×32px, Unity PPU는 32이며 논리 점유는 한 셀이다.

주변 8셀의 256상태에서 대각선은 인접한 두 직교 이웃이 채워졌을 때만 연결에 반영한다. 지형의 덩어리는 4방향 연결로 해석하며 대각선만 닿은 셀은 별도 덩어리다. 청크 경계는 외곽선으로 취급하지 않는다.

| 테마 | A | B | C | D |
|---|---|---|---|---|
| T01 월궁 | 포개 옥판층 | 통보 맞물림층 | 옥심 압착블록 | 처마 접합교 |
| T02 구름고래 목장 | 압축구름 띠층 | 짐목 맞물림층 | 봉합 구름패널 | 계류 짐교 |
| T03 별가루 도서관 | 제본 종이층 | 접힘 종이벽돌 | 묶음 책등층 | 팝업 제본교 |
| T04 시간유리 온실 | 응결 유리블록 | 모래 적층용기 | 덩굴 압착매듭 | 모래관 접합교 |
| T05 오로라 수정광산 | 어긋난 암층 | 수정맥 결합암 | 톱니 광석블록 | 쐐기 공명교 |

폐기한 달떡 다리는 제작 방향에 포함하지 않는다. 밟는 선은 수평 옆모습으로 표현하고 기울어진 탑뷰 발판을 만들지 않는다. 구덩이·내부 구멍·돌출부·천장·얇은 가로/세로 지형은 같은 셀 구조를 조합한다.

## 아트 파일

- `Art/Atlases`: 80개 아틀라스. 실제 프로젝트의 기본 Runtime 셀 참조용이다.
- `Art/<style>/Sprites` 및 `variants`: 위상별 개별 셀 PNG. 아틀라스와 함께 Runtime에 중복 설치할 필요는 없다.
- `Art/<style>/modules` 및 `variants`: 16×16px 연결 부품, 총 1,600개.
- `Art/<style>/material.png`, `frame.png`, `ring.png`, `motif.png`: 스타일별 소재·외곽·내곽·큰 문양 자료.
- `Samples`: 20스타일 × 16형태, 총 320개 조합 지형 예시.
- `Data/sprite_lookup.json`: 아트 버전 2, 실제 이미지 경로·아틀라스 rect·위상·문양 규칙.
- `SourceArt/Approved/T01.png`~`T05.png`: 승인 원본 5장. 원본 바이트·SHA256을 보존하며 최종 팔레트·마감 검증 대상 Sprite와 구분한다.
- `APPROVED_DESIGNS.html`: 승인 원화와 128×128px 패널 80개의 전체 디자인 보기.
- `DESIGN_GALLERY.html`: 실제 셀을 조합하는 자유형 지형 보기.

적용용 `Art` 및 `Samples`는 불투명 Sweetie16 색과 0/255 알파를 사용한다. 큰 문양은 4×4셀 시각 오버레이이며 추가 점유는 0이다. 문양 아래의 16셀과 주변 1셀 여유 영역이 같은 스타일일 때만 표시한다.

Sprite rect는 PNG 왼쪽 위 좌표다. Unity 임포트에서는 `atlasHeight - y - height`로 y를 바꾼다. 아틀라스 셀은 중앙 pivot, 문양은 bottom-left pivot을 사용하고 PPU 32·Point·mipmap Off·압축 None으로 표시한다.

## Jaggies와 Doubles

자세한 제작·검수 규칙은 [PIXEL_ART_FINISHING_RULES_KO.md](PIXEL_ART_FINISHING_RULES_KO.md)에 있다. 1px 윤곽을 기준으로 불규칙한 계단 경로, 의도하지 않은 2px 선 두께, 모서리에 겹친 픽셀, 임의의 고립 명암점을 확인한다. 정상적인 단색 면의 2×2 픽셀 덩어리를 윤곽 오류로 지우지 않는다. 승인된 구조와 장식을 지워 평평한 몸체나 새 프레임으로 바꾸지 않는다.

자동 후보 검사는 전수 미관 승인과 같지 않다. 원본 배율과 최근접 확대에서 셀·외곽·내곽·위상 이음·큰 문양을 함께 확인한다. 후보 0개를 Jaggies/Doubles가 모두 없다는 보증으로 사용하지 않는다. 시각 검수 기록에는 실제 확인한 파일·형태·배율을 적고, 일부 원화나 예시만 확인한 결과를 전체 셀의 검수로 확대하지 않는다.

## 기존 프로젝트에 적용

[ANIMOL_CLEAN_ART_V2_APPLY.txt](ANIMOL_CLEAN_ART_V2_APPLY.txt)를 실행 명령으로 사용한다. 기존 레지스트리와 아트 초기화 도구를 확장하여 버전 1과 2를 구분하고, 현재 맵의 아트 버전을 명시적으로 전환한다. 이 설치만으로 기존 맵을 일괄 변환하지 않는다.

`FreeShapeLayer.schemaVersion=1`, 연결 계약 `ANIMOL_FREE_SHAPE_BLOB47_V1`과 점유 셀·스타일·seed는 유지한다. 아트 버전 2가 실제 설치·검증된 경우만 명시적으로 허용하며, 다른 알 수 없는 버전 거부와 운영 Ready 검증은 유지한다. 버전 1 레지스트리·GUID·사용자 맵·v3 스탬프·충돌 소유자는 보존한다.

이 제작 공간에서는 실제 Unity 아트 패치, 버전 전환, Scene/Runtime 재검증과 모바일 실기기 검증을 실행하지 않았다. 과거 v1 보고서의 Unity 테스트 수치와 QA 결과를 이번 clean_v2 결과로 읽지 않는다. 새 검사 결과는 실제로 재실행한 보고서와 적용 후 `ANIMOL_CLEAN_ART_V2_PATCH_RESULT.md`로 확인한다.

## 이번 clean_v2 출력의 검사 결과

최종 출력에서 `validate:clean -- --check-core --contact-sheets`를 실행했고 exit code 0, topology·sprite files·gallery 검사가 PASS다. PNG 규격·Sweetie16·0/255 알파·아틀라스 일치 검사는 셀 3,760개·연결 부품 1,600개·아틀라스 80장·패널 80개·예시 320개의 28,446,720픽셀을 확인했다.

Sampling body/frame/ring PNG 60개, 513,280픽셀 검사도 PASS이며 body-only mask255 출력 80개와 실제 body crop 일치를 확인했다. 실제 셀 이음 조사 범위는 163,840개 논리 문맥, 중복 제거한 그림 쌍 27,040개, 공유 경계 865,280픽셀이다. 20스타일의 47종 × 4위상 contact sheet 20장을 최근접 4배로 새로 출력했다. 검토 시트를 생성했다는 사실을 모든 그림의 사람이 판단한 미관 승인으로 설명하지 않는다.

고립 픽셀 후보는 v1의 41,215개에서 28,219개로 31.53% 감소했다. 면적 3픽셀 이하 작은 덩어리 후보는 65,265개에서 44,155개로 32.35% 감소했다. body field 20개 중 17개는 고립 후보 0개, 나머지는 총 24개다. body-only 셀 80개에는 총 4개 후보가 있다. T02_B/D는 승인 원화의 가로 판재·명암띠를 유지한 행별 팔레트 정리 후 body field와 mask255 네 위상 모두 고립·작은 덩어리 후보 0개를 확인했다. 승인된 장식이나 작은 기호의 끝점도 후보에 포함될 수 있으며 Jaggies/Doubles 전체 제거로 해석하지 않는다.

최종 셀 PNG 집합 digest는 `e7cc6852e054845d1241a2d3ccbd4e49b82c9f5eb1520af213a5dea69a5f0d3e`이다. `SourceArt/Approved` 5장과 Raw 5장의 SHA256 일치, 기존 v1 패키지 5,883파일 보존을 확인했다. 실제 검출 기록은 `clean_pixel_validation.json`, 원본·디자인 보존과 실제 시각 검수 범위는 [APPROVED_DESIGN_EXPORT_QA_KO.md](APPROVED_DESIGN_EXPORT_QA_KO.md)를 확인한다.

`old_v3_preserved_sha256.json`은 과거 원본 출처의 해시 비교 기록이며 새 아트의 미관 QA가 아니다. 빌드·검사 JSON은 이번 clean_v2 최종 출력에서 다시 생성했다. 새 픽셀 후보 검사는 `npm run validate:clean`이며 재실행하려면 v1 비교 원본 폴더가 필요하다. 경로와 전체 명령은 패키지 루트 README에 있다. 실제 Unity 적용과 모바일 검증은 이번 제작 작업에서 실행하지 않았다.
