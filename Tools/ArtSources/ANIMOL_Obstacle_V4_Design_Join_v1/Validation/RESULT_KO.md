렌더링 검사에는 올바른 배치 960개와 기능 면을 가리는 배치 40개가 포함된다. 40개는 C02의 작동 면을 가리는 바닥·음수 경계 배치 × 20스타일이며, 예상한 배치 경고를 표시했다. 그래픽 선택기는 맵이나 충돌체를 자동 수정하지 않는다.

HTML 검사는 포함된 전체 JavaScript를 Node VM에서 실행하고 `@napi-rs/canvas`로 실제 아트를 그렸다. 셀 지우기 클릭 콜백과 PNG 생성 함수도 실행했다. 원본 1배 비교판과 8배 상세 이미지를 이 폴더에 남겼다.

## 육안으로 확인한 범위

5테마 공통 50개 비교판의 원배율, T01_A의 TOP 발판·벽면 장치 접합을 원배율과 최근접 확대에서 확인했다. 화살표 방향, 작동 면 대비, 상판과 하부 몸체의 분리, 끝캡 복원에 중점을 두었다.

고립 점·검은 2×2 후보 0개는 모든 곡선의 Jaggies나 모든 색의 Doubles를 자동 판정했다는 뜻이 아니다. 정상 색 면·원본의 소재 명암을 지우지 않았으며, 전체 163프레임과 모든 이웃 조합을 사람이 하나씩 승인한 결과도 아니다. 새 기능 표시는 정수 좌표·규칙적인 계단·연속 색 면을 사용한다. 랜덤 점·디더링·블러·중간 알파를 추가하지 않았다.

## 실행하지 못한 검사와 적용 범위

- 이 환경에는 ANIMOL Unity 프로젝트와 C# 컴파일러가 없다. `ObstacleVisualResolver.cs` 컴파일, 제공한 NUnit 테스트, 실제 Registry/Renderer 연결, Scene·Runtime·충돌·Undo 검증은 실행하지 않았다. 적용 명령문에 이 검사를 포함했다.
- Chromium 실행 파일이 없어 Playwright의 실제 브라우저 레이아웃·다운로드 검사는 실행하지 못했다. Native Canvas 결과를 브라우저 전체 검증으로 설명하지 않는다.
- 과거 사용자 맵·프리팹을 변경하거나 마이그레이션하지 않았다. 게임 규칙·물리·경고 시간은 기존 런타임에서 읽어야 한다.
- `Design/Concept_50_Theme_Skins.png`는 제작 방향을 설명하는 이미지 생성 시안이다. 정밀 픽셀 검사의 대상이나 Runtime 아틀라스가 아니다.
