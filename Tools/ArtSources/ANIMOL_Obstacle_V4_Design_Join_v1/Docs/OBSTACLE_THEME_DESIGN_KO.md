# 장애물별 테마 디자인과 픽셀 제작 규칙

기준: `ANIMOL_Common_10_Tile_Design_v2.md`의 공통 10종, `joint_finish_v4`의 20스타일·32px·Sweetie16·47 연결 마스크.
배경 장식으로 동작을 숨기지 않는다. 발판 윗면은 정면 옆모습의 수평선이다. 기능 장식은 한 셀 안에 있고, 위험 판정·발판·바람의 크기를 넓히지 않는다.

## 공통 10종의 5테마 디자인

| 장치 | 월궁 T01 | 구름고래 목장 T02 | 별가루 도서관 T03 | 시간유리 온실 T04 | 오로라 수정광산 T05 |
|---|---|---|---|---|---|
| C01 하향 발판 | 옥판 걸침판 | 압축구름 걸침판 | 제본 낱장판 | 덩굴 유리받침 | 광석 걸침판 |
| C02 좌우 반사 | 옥판 반사 범퍼 | 짐목 탄성 범퍼 | 책등 접힘 범퍼 | 유리 결합 범퍼 | 광맥 탄성 범퍼 |
| C03 상향 스프링 | 옥판 탄성 받침 | 계류 탄성 받침 | 접힌 제본 받침 | 유리관 탄성 받침 | 쐐기 탄성 받침 |
| C04 점멸 위험칸 | 달 쐐기 | 계류 쐐기 | 제본 쐐기 | 유리 쐐기 | 광석 돌기 |
| C05 이탈 소멸판 | 달빛 등잔판 | 응결 구름판 | 접히는 책갈피판 | 응결 유리판 | 희미한 광맥판 |
| C06 착지 반동 | 떡 쿠션 | 양털 받침 | 두꺼운 책받침 | 꽃받침 | 광석 완충판 |
| C07 방향 바람칸 | 달빛 흐름 | 상승기류·순풍 | 활자 기류 | 꽃가루 흐름 | 오로라 흐름 |
| C08 방향 벨트 | 옥판 운반띠 | 짐목 운반띠 | 활자 운반띠 | 유리관 운반띠 | 광석 운반띠 |
| C09 접근 생성판 | 달빛 징검판 | 응결 구름판 | 팝업 페이지 | 이슬 새싹판 | 성장 수정판 |
| C10 저마찰 바닥 | 매끈한 옥유약 | 매끈한 짐목 | 왁스 제본면 | 이슬 유리면 | 매끈한 수정면 |

이는 같은 기능을 다른 소재로 표현한 스킨이다. C06의 떡 쿠션은 반동 장치이며 보류된 M03의 감속 기능을 갖지 않는다. 바람칸에 하늘다람쥐의 스태미나 회복을 자동 부여하지 않는다. C02는 충돌 전 수평 속도의 부호만 바꾸는 기존 설계를 표시하며 고정 발사로 바꾸지 않는다.

## 각 기능의 실루엣

| ID | 보이는 구조 | 작동 표현 | 보존할 읽기 요소 |
|---|---|---|---|
| C01 | 수평 상판·안쪽 작은 받침 | 아래 통과 입력 때 중앙 표시 밝아짐 | 아래 화살표, 비어 있는 하부 |
| C02 | 벽면 탄성판·규칙적인 3단 접힘 | 셀 내부 접힘 부분만 압축·복귀 | LEFT/RIGHT의 실제 작동 면, 반사 방향 |
| C03 | 윗면에 매립한 탄성 받침 | 내부 가로 접힘과 위 화살표 변화 | 수평 속도와 무관한 위 발사 표시 |
| C04 | 비충돌 공중 셀의 예고 프레임·3개 돌기 | 같은 칸에서 어두운 예고 → 노란 예고 → 붉은 위험 | 공통 위험 색과 실제 활성 영역 |
| C05 | 상판·중앙 상태 문양 | 마지막 이탈 후 예고, 비활성 때 상태 문양만 남음 | 올라탄 사람을 떨어뜨리지 않는 기존 규칙 |
| C06 | 둥근 쿠션·소재별 큰 연속 면 | 쿠션 내부 눌림, 상판·몸체 좌표는 고정 | 낮은 착지 반동, C03과 다른 형태 |
| C07 | 두 개의 연속 흐름과 방향 화살표 | 효과 중 방향 강조 | 공중 칸, 가짜 바닥 없음 |
| C08 | 고정 몸체·롤러 2개·규칙적인 화살표 | 표면 방향 표시의 변화 | 몸체 자체가 이동하지 않음 |
| C09 | 접힌 소재와 한 칸 상판 | 접근 예고 → 상판 등장 → 마지막 이탈 후 접힘 | 생성 위치가 같은 한 칸임을 표시 |
| C10 | 평평한 하나의 연속 반사 띠 | 표면 강조, 점 반짝임 없음 | 가속 장치와 다른 매끈한 면 |

이번 기능 PNG는 각 상태의 표시 프레임이다. 독립 시간·랜덤 수치로 게임의 경고 타이밍을 재생하지 않는다. 실제 게임의 상태를 읽어 그 프레임을 선택한다. 압축이나 표면 이동은 향후 동일 틱 기반 추가 프레임으로 확장할 수 있지만 현재 프레임 수를 완성된 연속 애니메이션이라고 설명하지 않는다.

## 지역 전용 후보 3종

| 후보 | 그래픽 설계 | 공통 장치와 구별 |
|---|---|---|
| 월궁 M02 달그릇 | v4 옥 상판 안쪽에 담긴 밝은 그릇 면과 큰 충전 문양 | 착지 충전 후 다음 점프에 소비. C03의 즉시 발사와 구별 |
| 광산 R01 공명 수정판 | 얇은 수정 상판과 큰 공명 문양, 같은 셀의 켜짐/예고/꺼짐 | C05 이탈 소멸과 달리 공용 위상 |
| 광산 R03 대전 수정판 | 광맥 몸체 안의 세로 충전 결정, 붉은 활성 면 | C04 주기 위험과 달리 오래 서 있는 입력 |

이 3종은 그래픽 검토 후보로만 등록한다. 기존 프로젝트의 기능 구현 상태를 확인하지 않고 운영 스테이지 타입으로 활성화하지 않는다. 목장·도서관·온실의 새 지역 전용 3종을 임의로 채워 넣지 않는다.

## v4 소재·광원·마감

- T01_A의 청록 벽돌, 흰 옥판, 산호색 명암, 자두색 받침을 원본대로 사용한다. 1px 하이라이트와 둥글고 뭉툭한 돌 모서리를 지우지 않는다.
- 다른 19스타일도 v4 원본 아틀라스를 사용한다. 색만 바꾼 월궁 블록으로 통일하지 않는다.
- 원본 몸체를 비균등 확대하거나 통째로 회전하지 않는다. 기능 화살표만 방향을 바꾼다.
- 빛은 기존 상단 하이라이트와 하단의 연속 그림자 면을 따른다. 점 형태의 추가 빛·검은 얼룩·랜덤 무늬를 넣지 않는다.
- PNG는 정확한 Sweetie16과 alpha 0/255. 16색을 모두 넣을 의무는 없다. 넓은 단색 면은 그대로 허용한다.
- 기능 표시의 테두리는 기본 1px, 둥근 꺾임은 대칭 1px 코너 컷이다. 중앙 정상 면의 2×2 픽셀은 색 면이므로 삭제하지 않는다.

## Jaggies와 Doubles 검사

| 항목 | 실패 사례 | 수정 원칙 |
|---|---|---|
| 직선 | 1px 돌출, 중간 홈, 셀 경계에서 높이 흔들림 | 원래 수평·수직 좌표로 정리 |
| 곡선·대각선 | 계획 없이 긴/짧은 계단이 섞여 방향이 꺾임 | 곡률에 맞는 순서 있는 계단 길이, 대칭 확인 |
| Doubles | 연결선·모서리의 불필요한 검은 2×2, 두 겹 끝선 | 중복 선만 정리하고 정상 면은 보존 |
| 점 잡음 | 불필요한 고립 밝은 점·검은 점·디더링 | 구조를 설명하는 연속 면으로 정리 |
| 명암 | 타일마다 색 깊이나 하이라이트 위치가 바뀜 | v4 전역 위상·광원·색 역할 유지 |
| 이음 | 끝캡 두 개가 접합 면에 남음, 줄눈 어긋남 | 동일한 이웃 마스크와 전역 위상에서 몸체 재선택 |

`verify_pixel_art.py`는 정확한 팔레트·알파와 검토 후보 좌표를 기록한다. Jaggies의 미관 판정은 자동화했다고 주장하지 않는다. 원배율·최근접 4배·8배에서 상태 프레임과 연결 결과를 확인한다. 블러·안티앨리어싱·Shader로 선을 감추지 않는다.
