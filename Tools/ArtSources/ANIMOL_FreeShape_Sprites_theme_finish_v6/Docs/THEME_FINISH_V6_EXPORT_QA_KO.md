# ANIMOL theme_finish_v6 실제 출력 검사

T01_A는 내부 구멍 마감을 수정한 v5의 실제 PNG와 메타데이터를 유지한다. 다른 19스타일은 각 테마의 재료 구조를 넓은 면·반복 이음·일정한 명암 띠로 다시 제작했다. 기존 승인 5테마와 20 styleId/이름, 기존 큰 문양은 보존한다. 몸체 색을 장식으로 잘못 추출하는 경로 대신 독립적인 투명 native 분면 역할을 사용한다. 외곽·내곽 모서리의 접속 포트는 동일 방향의 경계 띠에서 계산하며 구멍 모서리 밖으로 무관한 명암 조각을 연장하지 않는다.

artVersion=6 / schemaVersion=1 / ANIMOL_FREE_SHAPE_BLOB47_V1.
32×32px / PPU32 / 셀 점유1×1. 20스타일·47 canonical mask·4전역 위상으로 셀 Sprite3,760개, 분면1,600개, 아틀라스80장, 기존 문양20개다. 문양은4×4셀 시각 크기이며 추가 점유·Collider0이다.

현재 결과는 Docs/theme_finish_validation.json(실제 v5 패키지와 비교)과 Docs/theme_finish_validation_packaged.json(동봉한 정확한 v5 PNG/RGBA SHA256 기준)이다. 두 경로 모두 PASS다. 별도 v5 폴더가 없는 다운로드본에서도 동봉한 기준으로 현재 native 재료·역할·셀·포트를 검사할 수 있다. Data/v5_preservation_manifest.json은 v5 lookup SHA256, T01_A 전체 메타데이터, 보존 PNG·문양·기준 원화와 기존 반복장의 RGBA 해시를 보관한다.

색상별 작은 군집은 시각 검토 후보다. T03_C 책등의 금색 상단 명암은 등록된3px 가로 띠6개로 검출되며, 임의의 점무늬로 지우지 않았다. 의도한 넓은 명암 면, 둥근 면의1px 절개, 정규45도 접힘이나 일정한 수정맥 계단은 선언한 형상과 대조한다. 후보 수 또는 검사PASS를 모든 Jaggies/Doubles가 자동 판별되어0이라는 의미로 확대하지 않는다.

최종 수정한 T05_A/B/C의 넓은 암면 명암은 몸체의 큰 면으로 유지하고 명암 안쪽의 불필요한 검은 테두리를 제거했다. 암판 윤곽·수정맥·광석 맞물림과 명암 색은 유지한다. T05_D의 규칙적인 쐐기 면과 다른 테마의 색 면에도 노이즈나 블러를 추가하지 않는다. 발판 상면은 수평인 2D 측면 경계다.

비교판은 Previews/ANIMOL_theme_finish_v6_overview.png와 T01~T05_theme_finish_v6_comparison.png다. 실제 전체20스타일 보기와 지역별 비교판5개를 열어 몸체 밀도, 반복 이음, 작은·큰 구멍, 계단과 열린 구덩이의 마감을 확인했다. 이는 표시한 조합의 시각 검토이며 3,760셀 전부와 가능한 모든 지형을 사람이 개별 미관 승인한 주장은 아니다.

SourceArt/DesignReferencesV6의5개 새 이미지는 테마별 재료 디자인 참고 자료다. Runtime이나 공용16색·32px 출력 검사의 증거로 사용하지 않는다. 최종 제작 소스는 SourceArt/NativeV6의19스타일과 보존한 T01_A v5 native 파일이다. 기존 승인 원화의 SHA와 바이트는 보존한다. 실제 셀/패널을 오프라인 DESIGN_GALLERY.html / APPROVED_DESIGNS.html에서 확인할 수 있다.

Runtime 소스는 Data/sprite_lookup.json의 아틀라스와 문양이다. 과거 v5 이하 적용 명령·검사·비교판은 제작 이력이며 현재 출력 검사로 재사용하지 않는다. 현재 전체 파일 목록·크기·SHA256은 PACKAGE_MANIFEST.json이다. 기존 맵의 점유·seed·객체·충돌을 바꾸지 않고 별도V6 Registry와 선택 맵 전환을 적용한다.

Unity 프로젝트가 이 공간에 없어 Unity 컴파일·Scene/Runtime·Undo·저장·물리 검사는 미실행이다. 적용 명령은 Docs/ANIMOL_THEME_FINISH_V6_APPLY.txt이며 실제 대상 프로젝트 결과는 별도 ANIMOL_THEME_FINISH_V6_PATCH_RESULT.md에 기록해야 한다. 브라우저 이벤트·canvas PNG인코딩 실행과 서로 다른 styleId의 자연스러운 혼합 접합도 이번 검사로 완료 주장하지 않는다.
