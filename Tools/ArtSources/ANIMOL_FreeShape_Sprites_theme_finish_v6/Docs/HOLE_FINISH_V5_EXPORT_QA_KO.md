# ANIMOL hole_finish_v5 실제 출력 검사

T01_A 내부 구멍의 모서리에서 산호색 마감·그림자 조각이 튀어나오는 문제를 수정한 출력이다. 같은 색의 몸체 명암을 장식으로 잘못 추출하지 않도록 실제 선언한 면·윤곽의 provenance를 사용한다. 내곽 받침 두께와 기둥 연결 위치를 정돈했다. 몸체와 외곽 프레임 원본은 v4 그대로이며, 기존 벽돌 무늬, 5색 팔레트, 흰 하이라이트, 산호색·보라색 하단 그림자와 둥글고 뭉툭한 돌 모서리를 유지한다. 다른 19스타일은 v4와 같은 PNG를 유지한다.

artVersion=5 / schemaVersion=1 / ANIMOL_FREE_SHAPE_BLOB47_V1.
32×32px / PPU32 / 점유 1×1. 20스타일·47 canonical mask·4위상으로 Sprite 3,760개, 아틀라스 80장, 문양 20개다. 문양은 4×4셀 시각 크기이며 추가 점유와 Collider는 없다.

현재 버전의 실제 검사 결과는 Docs/hole_finish_validation.json과 연결·Sprite·갤러리 검사 JSON에 기록했다. v4 이하의 joint_finish_validation.json 등은 과거 이력이며 v5 검사 결과로 재사용하지 않는다.

일반 고립 픽셀·작은 클러스터 후보 수가 곧 Jaggies/Doubles 제거 판정인 것은 아니다. 정해진 곡선 코너와 명암도 후보에 포함될 수 있다. 이번 검사는 명시적으로 등록한 장식 영역과 실제 픽셀 조립의 일치 여부이며 모든 2×2 잉크 또는 모든 미관 문제가 0이라는 뜻이 아니다.

| 비교판의 실제 조립 | 조건 |
|---|---|
| 가운데 1×1 구멍 | 3×3 지형, origin (0,0)/(1,0)/(0,1)/(1,1), seed 0, 정수 최근접 2× |
| 가운데 2×2 구멍 | 4×4 지형, origin (0,0), seed 0, 정수 최근접 2× |
| 막힌 몸체 | 5×3 지형, origin (0,0), seed 0, 원배율 1× |
| 큰 구멍 | 10×7 지형의 가운데 6×3 구멍, 기존 closed_hole 점유, 원배율 1× |

| 제외한 요소 | 문양, 에디터 격자, 커서, 평활 필터, 손으로 그린 픽셀 보정 |

이 시각 검토를 모든 가능한 지형 조합의 미관이 자동 승인되었다는 뜻으로 확대하지 않는다.

Runtime 소스는 Data/sprite_lookup.json의 아틀라스와 문양이다. v4 이하 제작 자료·적용 명령·검사 기록은 과거 이력으로 보존한다. 현재 패키지 전체 파일 목록·크기·SHA256은 PACKAGE_MANIFEST.json으로 확인한다.

Unity 프로젝트가 이 공간에 없어 Unity 컴파일·Scene/Runtime·Undo·저장·물리 검사는 미실행이다. 적용 명령은 Docs/ANIMOL_HOLE_FINISH_V5_APPLY.txt이며 실제 대상 프로젝트의 결과는 별도 PATCH_RESULT에 기록해야 한다.
