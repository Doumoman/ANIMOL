# ANIMOL 원래 디자인 유지 보정 v2

기존 5개 테마의 건물·지붕·아치·난간과 재질 색 역할을 기준으로 마감을 다시 정리했습니다. 다리 기둥·상판·아치에는 넓게 이어지는 기본색·그림자·밝은 면을 사용했습니다. 월궁 장식과 시간유리 온실의 파랑·금색 모래시계 구조, 광산의 어두운 석조 보강대를 유지했습니다.

- 적용 자산: `runtime/main-background/`의 20 PNG, 각각 352×704.
- UI 보정: `ui-config/campaign-style-corrections.json`의 밝은 카드·헤더 배킹과 어두운 글자색. SC02 PNG 교체는 0개이며 기존 Batch01의 정돈된 프레임·썸네일·배경을 사용합니다.
- 메인 버튼과 현재 토끼 디자인·세잎클로버 핀은 이번 보정의 교체 대상에 포함하지 않았습니다.
- `previews/Bridge_Comparison.png`는 원본 / 지난 v1 / 이번 v2 다리의 정수 2배 비교입니다. 그림과 윤곽을 직접 대조하세요.
- HTML은 원본·v1·v2의 5초 순환, 같은 시점 비교, 정지 다리 확대를 제공합니다. 캠페인 탭은 참고 시안이며 실제 진행도와 서버가 연결되어 있지 않습니다.

`source/`는 원본과 편집 기록입니다. 운영에 수입하는 파일은 `manifest.json`에 선언된 PNG만 사용합니다. 개정본은 원래 주요 형태를 유지하지만 작은 윤곽 정리로 원본 알파와 픽셀 단위로 동일하지는 않습니다. T04 바닥은 원본 527행을 전체 레이어 1픽셀 등록 이동으로 526행에 맞췄으며 런타임에서 다시 이동하지 않습니다.

허용색은 기존 Sweetie16이고 Point/무압축/밉맵 없음/PPU32를 유지합니다. 아트 편집은 이미지 편집 도구로 수행했습니다. 이후 코드는 크롭·정수 확대·고정 팔레트 매핑·알파 내보내기·레이어 합성에 사용했습니다. 최종 프롬프트는 각 `source/T##/`에 보존했습니다.

유니티 적용 명령은 `ANIMOL_Original_Design_Correction_Unity_Commands.md`에 영역별로 있습니다. 이 환경에는 실제 Unity 프로젝트와 Editor가 연결되어 있지 않아 적용·컴파일·기기 검증은 미실행입니다. 20개 파일의 규격·팔레트·이진 알파·바닥 정렬과 오프라인 미리보기 검증 결과는 `Verification/` 및 `previews/preview-verification.json`에 있습니다.
