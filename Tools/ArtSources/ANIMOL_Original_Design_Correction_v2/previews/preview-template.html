같은 형태, 정돈된 색면

원래 디자인과 지난 개정본을 같은 시점에서 비교할 수 있습니다. 움직이는 레이어 뒤로 발판을 고정하고, 가까운 장식은 더 빠르게 이동합니다.

토끼는 기존 64×96 크기, 8프레임·14fps 시트를 그대로 사용합니다. 다리 보기에서는 다른 레이어를 가려 기둥과 아치만 확인합니다.

캠페인 UI

흰 카드·헤더와 짙은 글자로 기존 인상을 복원했습니다. 이 화면은 352×704 디자인 참고 합성입니다. 글자 일부는 첨부 화면에서 가져온 참고 픽셀이며 운영 자산이나 실제 진행도가 아닙니다.

테마 선택 UI의 런타임 PNG 교체는 0개입니다. 배킹·글자색 설정을 복원하는 작업입니다.

배경 20개 PNG 교체를 위한 아트 미리보기입니다. 실제 Unity 프로젝트 적용·컴파일·Safe Area 검증 결과가 아닙니다.
