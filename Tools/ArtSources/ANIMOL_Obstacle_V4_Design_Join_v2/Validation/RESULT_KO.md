900개 배치 중 40개는 C02의 작동 면을 가린 의도적 실패 배치다. 이를 배치 경고로 잡았으며 다른 860개는 정상이다. 맵·물리를 자동 수정하지 않는다.
C01 표식 제거, C09 선택·렌더 거부, C04 상시 표시·과거 비활성 진단, C06 내부 단색·밑면 고정, C02 좌우 정확한 미러·압축·복원, C08 띠의 실제 이동 방향·8프레임 순환, C05 cap 대체·조각 rect 분할을 테스트했다.
HTML은 전체 스크립트를 Node VM에서 실행하고 @napi-rs/canvas로 그렸다. 셀 지우기·붕괴 콜백과 모든 등록 프레임을 실행했다. 그림 압축과 루프는 실제로 생성했다. 원본 v4 body atlas 파일은 재색칠하지 않았다.

## 육안 확인

공통 45개 원배율 비교판, 월궁 좌우 코일의 최근접 8배 접합, 소멸판 조각 낙하 화면을 열어 확인했다. 컨베이어에서 띠 밑선과 롤러 윗선의 검은 겹선을 정리했다. 신규 기능 PNG의 자동 후보가 0이라고 해서 모든 곡선의 Jaggies·모든 색의 Doubles를 완벽하게 판정했다는 뜻은 아니다. 전체 조합을 사람이 한 장씩 승인한 결과도 아니다.

## 미실행·한계

이 환경에는 ANIMOL Unity 저장소·C# 컴파일러가 없다. 순수 C# 선택기, UnityCrumbleVfx, 제공한 NUnit 7개는 실제 Unity에서 컴파일·실행하지 않았다. 실제 게임의 C09 삭제, C04 상시 위험 로직, 기존 맵 마이그레이션, C05 이벤트 연결, 물리·Scene/Runtime·Undo·모바일 검증은 MCP 적용 명령의 필수 작업이다.
Chromium 실행 파일이 없어 실제 브라우저 레이아웃·다운로드 검사는 미실행이다. Native Canvas 실행을 브라우저 전체 검증으로 설명하지 않는다.
C05의 점진적 alpha 페이드는 요청한 런타임 연출이다. 원본 PNG는 alpha 0/255를 지킨다. GIF에는 불투명 비교판만 포함하므로 16색이 그대로 유지된다.
원시 결과는 node_tests.txt, pixel_audit.json, native_preview_audit.json, v4_source_preservation.json에 있다.
