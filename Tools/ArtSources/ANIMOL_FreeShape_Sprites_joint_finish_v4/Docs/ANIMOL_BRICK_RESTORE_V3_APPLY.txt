ANIMOL brick_restore_v3 — T01_A 벽돌 구조·끝마감 복원 아트 적용 명령

목표
이미 구현된 Scene View 자유형 지형 편집기에 아트 버전 3을 추가한다.
T01_A의 벽돌 구조와 기존 끝 형태를 복원하면서 v2처럼 깔끔한 명암으로 표시한다.
이번 변경 스타일은 T01_A 하나이며 나머지 19스타일의 픽셀은 v2와 동일해야 한다.
편집기·새 맵 정본·새 충돌 경로를 다시 만들지 않는다.

사용자가 이번에 요청한 T01_A 복원은 이전의 승인 5원화 디자인 고정 규칙에 대한 명시적 예외다.
T01_A의 material/frame/ring/motif 네 패널이 이번 복원에 포함된다.
이 예외를 나머지 19스타일의 형태·색·모티프 변경에 확대 적용하지 않는다.
기존 v1의 벽돌 형태와 끝마감을 참고하지만 지저분했던 명암·점 질감을 그대로 export하지 않는다.
최종 적용 아트는 이 패키지의 새 v3 PNG이며 v1 PNG를 대체 참조로 연결하지 않는다.
이번 artVersion=3과 기존 terrainPlacements schemaVersion=3 덩어리 스탬프는 별개다.

1. 실제 소스와 상태 확인

AGENTS.md와 현재 Git 변경을 읽는다. 사용자의 작업과 맵을 덮어쓰지 않는다.
기존 Scene 자유형 에디터 적용 보고서는 구현 이력으로 확인한다.
현재 StageMapDefinition.freeShapeTerrain / FreeShapeLayer와 Read/Validate/Commit 흐름을 조사한다.
FreeShapeArtBuilder / FreeShapeArtRegistry / FreeShapeTerrainRenderer의 실제 경로를 찾는다.
보고서의 파일명이나 메서드를 확인 없이 복제하여 병렬 경로를 만들지 않는다.
현재 설치된 아트 버전과 레지스트리를 확인한다. v2가 설치되었다고 가정하지 않는다.
알 수 없는 schema/contract/artVersion 거부 검사를 제거하지 않는다.

2. 패키지와 실제 그림 확인

제작 자료를 Tools/ArtSources/ANIMOL_FreeShape_Sprites_brick_restore_v3에 둔다.
기존 v1과 clean_v2 자료는 보존한다.
PACKAGE_MANIFEST.json의 크기·SHA256을 검사한다.
Data/sprite_lookup.json과 Data/source_rects.json을 읽어 실제 파일 경로·버전·rect를 확인한다.
Data/topology_catalog.json, Data/style_catalog.json, Tools/terrain_composition.mjs를 읽는다.
T01_A의 새로운 제작 원본과 material/frame/ring/motif 관계를 출처 기록에서 확인한다.
새 원본: SourceArt/Revised/T01_A_BrickEnd_Restore.png
생성·참조 기록: SourceArt/BRICK_RESTORE_GENERATION.json
SourceArt/Approved/T01.png는 clean_v2 기준 자료이며 v3 Runtime을 대신하지 않는다.
복원 원본은 이번 지시에 따른 수정 출력이며 사용자의 새 미관 승인을 완료했다는 뜻이 아니다.
다른 19스타일의 최종 PNG가 clean_v2와 같은지 SHA256으로 확인한다.
누락된 v2 비교 원본 때문에 확인하지 못한 항목은 미확인으로 기록한다.

유지하는 계약:
- contractId / artContract: ANIMOL_FREE_SHAPE_BLOB47_V1
- lookup 및 FreeShapeLayer schemaVersion: 1
- 새 아트 버전: 3
- styleId: T01_A부터 T05_D까지 기존 20개
- 셀 32×32px / PPU 32 / 정규화 형태 47종 / 이웃 raw 상태 256종
- 위상 v0~v3 네 종류, 셀 Sprite 3,760개, 아틀라스 80장
- 스타일별 128×128px 문양 20개, 문양 추가 점유 0

계약 이름의 V1은 연결 규격이다. 아트 버전 3 때문에 계약을 V3로 바꾸지 않는다.
같은 이름의 Sprite라도 반드시 lookup의 실제 경로와 버전을 사용한다.
T01_A Art/material.png나 frame.png를 v1에서 단순 복사하는 방식으로 복원을 끝내지 않는다.
원화·패널·실제 셀·조합 지형을 함께 보고 새 v3 출력이 벽돌 구조와 끝마감을 재현하는지 확인한다.
개별 셀 PNG·Sampling·원화·Samples·HTML을 Runtime에 중복 설치하지 않는다.
Runtime은 아틀라스와 문양의 완전한 참조 레지스트리를 사용한다.

3. v1/v2/v3 레지스트리 공존

artContract와 artVersion에 따라 정확한 레지스트리를 선택하도록 확장한다.
v1 맵은 v1, v2 맵은 v2, v3 맵은 v3 레지스트리를 사용한다.
기존 레지스트리를 새 T01_A로 덮어써 모든 이전 맵의 그림을 조용히 바꾸지 않는다.
기존 v1/v2 에셋·meta·GUID·GlobalObjectId를 보존한다.
새 v3 참조는 설치와 재초기화 후에도 안정적이어야 한다.
버전 3 참조를 별도 경로에 둔다. 예: Assets/ANIMOL/TerrainFreeShape/Art/V3.
실제 프로젝트의 참조 규칙을 조사하여 최종 경로를 결정하고 보고한다.

버전 3 레지스트리는 20스타일·모든 mask·위상·문양 참조가 완전해야 한다.
이미 v2가 설치되어 있고 다른 19스타일의 PNG가 동일한 경우에는,
SHA256 확인 후 해당 참조를 버전 3 레지스트리에 명시적으로 공유해도 된다.
이 경우에도 버전 3 레지스트리의 존재·완전성·파일 해시를 검증한다.
버전이 없을 때 임의로 v1/v2 그림을 가져오는 fallback과 혼동하지 않는다.
v2가 설치되어 있지 않으면 패키지의 실제 나머지 19스타일 파일을 정상 임포트한다.
T01_A에서 어떤 아틀라스·문양을 새로 설치하거나 공유했는지 명시한다.
실제 텍스처 수·메모리와 버전 공존 비용을 측정한다.

schemaVersion=1 / 동일 contract / 지원 artVersion 1·2·3만 명시적으로 허용한다.
각 버전의 완전한 아트가 설치되지 않았거나 다른 버전이면 저장·Runtime 로드를 거부한다.
검증을 제거하거나 모든 정수 artVersion을 허용하지 않는다.
Ready·보상·스테이지 배정 검증을 우회하지 않는다.

4. 픽셀 그대로 임포트

셀 아틀라스는 Multiple, rect 32×32px, 중앙 pivot, FullRect, PPU 32.
문양은 bottom-left pivot, PPU 32, 4×4셀 크기, 추가 점유 0.
Point / mipmap Off / 압축 None / 기존 정상 sRGB 설정을 유지한다.
JSON rect는 PNG 왼쪽 위 기준이다. Unity y = atlasHeight - y - height로 변환한다.
최종 Art/Samples의 불투명 색은 공용 Sweetie16, 알파는 0/255여야 한다.
제작 원본은 제한 없는 생성 파일일 수 있으므로 최종 Sprite와 구분한다.
블러·선형 필터·색 양자화 Shader·자동 테두리 효과로 마감을 대체하지 않는다.

5. 선택한 현재 맵의 명시적 전환

기존 Scene 자유형 패널에서 설치된 아트 버전을 보여준다.
사용자가 선택한 현재 맵만 artVersion 3으로 전환할 수 있게 한다.
설치·초기화·창 열기만으로 기존 맵들을 자동 전환하거나 일괄 저장하지 않는다.
처음에는 별도 개발 검증 맵 복사본에서 확인한다.
원래 맵의 좌표·점유·styleId·seed·객체·스탬프·셀 크기·revision·hash를 기록한다.
기존 후보 검증과 Commit으로 한 트랜잭션을 수행한다.
자유형 artVersion만 3으로 전환하며 고체 점유·스타일·seed·객체는 동일해야 한다.
기존 hash 규칙에 아트 버전 변경을 반영하고 revision은 한 번 증가시킨다.
Undo/Redo는 버전과 파생 아트 캐시를 함께 복원한다.
검증·저장 실패 시 정본·디스크·Scene 프리뷰·레지스트리 선택을 롤백한다.
명시적 전환 없이 이전 버전 맵에서 v3 T01_A가 나타나면 실패다.

6. 연결·문양·물리 유지

N1/NE2/E4/SE8/S16/SW32/W64/NW128과 대각선 게이팅을 유지한다.
rawToIndex / canonicalMask / 네 위상 / 전역 좌표 / 저장 seed 계산을 그대로 사용한다.
resolveVariant와 문양 hash/support는 Tools/terrain_composition.mjs의 실제 규칙을 따른다.
청크는 바닥 나눗셈을 사용하고 전역 점유로 이웃을 조회한다.
셀 및 문양 캐시는 기존 변경 범위로 갱신한다.
문양은 동일 스타일 4×4셀과 주변 1셀 여유 영역이 지원될 때만 표시한다.
장식·벽돌 줄눈·끝마감이 추가 Collider나 점유를 만들지 않는다.
기존 operational 고체 소유자, 객체 footprint/swept path, one-way 물리를 유지한다.
아트 Tilemap에 Collider를 추가하거나 외접 사각형으로 내부 구멍을 막지 않는다.
다른 스타일 사이의 전환 아트는 이번 수정에 포함하지 않는다.

7. 실제 검증

패키지 PNG/Node 결과와 실제 Unity 검사를 구분한다.
복제된 v2 QA 숫자와 기존 Unity PASS를 이번 v3 결과로 옮기지 않는다.
- v3의 실제 Sprite/rect/PPU/pivot/필터/참조/색 검증.
- T01_A의 원화 패널과 실제 사각형·얇은 가로/세로·U자 구덩이·내부 구멍·천장 검토.
- v2 대비 다른 19스타일의 PNG 동일성과 Runtime 표시 동일성 확인.
- v1/v2/v3 선택 → 저장 → 재열기 → 시험 플레이에서 버전에 맞는 그림 재현.
- 버전 전환 Undo/Redo, 한 revision 증가, hash 반영, 실패 rollback 검증.
- Scene 프리뷰와 Runtime의 같은 좌표·seed 렌더를 v3 Samples/PNG와 픽셀 비교.
- 음수 좌표·청크 경계·네 위상 이음·문양 지원 제거와 복원 확인.
- 버전 변경 전후 점유·빈 공간·실제 착지·일방통행·객체 배치 동일성 확인.
- 기존 사용자 맵과 v1/v2 참조 식별자 보존 확인.
- 실제 Unity 컴파일과 변경 경로에 필요한 기존 테스트 실행.

원본 배율과 최근접 확대에서 벽돌 결합·외곽·밑마감·모서리·끝 형태를 확인한다.
원래 v1의 울퉁불퉁한 명암과 고립 점을 그대로 되살리지 않는다.
자동 후보 0개를 Jaggies/Doubles 전체 제거로 단정하지 않는다.
실제 시각 검수 파일·형태·배율을 기록하고 일부 예시를 전체 검수로 확대하지 않는다.
실행하지 않은 Unity·모바일 검사는 미실행으로 보고한다.
