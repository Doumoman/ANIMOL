ANIMOL joint_finish_v4 — 기존 Unity 프로젝트 적용 명령

이 패키지를 기존 Scene 자유형 지형 편집기에 artVersion=4로 추가해라.
수정 범위는 T01_A 벽돌의 꺾이거나 두꺼워진 접합부다. 기존 명암과 둥글고 무딘 모서리를 유지한다. native64 몸체는 대칭인 radius1 모서리 컷을 통일하고, 의도한 모서리 패턴 밖의 일반 줄눈을 직선 1px로 정돈한다. frame/ring128의 작은 끝캡·하부 받침은 기존 건축적 역할을 유지하며 native 곡선 면을 국소 좌표에 등록한다. 새 테마를 만들지 않는다. 나머지 19스타일은 최종 v3 PNG와 파일 목록·바이트가 같아야 한다.
이 작업 공간에서는 실제 Unity 임포트·렌더·물리·저장 검사를 실행하지 않았다. 아래 검사는 적용할 Unity 프로젝트에서 수행한다. ZIP의 ANIMOL_CLEAN_ART_V2_APPLY.txt, ANIMOL_BRICK_RESTORE_V3_APPLY.txt, BRICK_RESTORE_V3_EXPORT_QA_KO.md 등 기존 v2/v3 문서·검사 기록은 과거 버전의 이력이며 v4 PASS로 재사용하지 않는다.

1. 소스와 패키지 확인
AGENTS.md, 현재 Git 변경, 기존 FreeShapeLayer 및 Read/Validate/Commit·Undo 흐름을 먼저 읽어라. 실제 Builder/Registry/Renderer 경로를 찾아 기존 구현을 확장해라.
패키지 전체를 Tools/ArtSources/ANIMOL_FreeShape_Sprites_joint_finish_v4에 보관하고 v1/v2/v3 자료를 보존해라. PACKAGE_MANIFEST.json의 파일 목록·크기·SHA256을 검사해라.
Data/sprite_lookup.json, source_rects.json, topology_catalog.json, style_catalog.json과 Tools/terrain_composition.mjs를 읽어라. native 원본 제작 규칙은 Tools/build_joint_native_sources_v4.mjs와 Data/joint_native_layout_v4.json에서 확인해라.
T01_A 명암은 청록 벽돌 위쪽의 직선 1px 오프화이트 하이라이트(양 끝 2px inset), 흰 면 아래쪽의 연어색 1px, 연어색 면 아래쪽의 자두색 1px 그림자를 유지해라. 모서리·명암을 지운 평면 면색으로 마감을 대신하지 마라.
패키지 루트에서 npm run validate:joint 또는 node Tools/validate_joint_finish_v4.mjs를 실행하고, package.json의 연결·Sprite·gallery 검사도 실행해라. artVersion=3 전용 검사를 v4 검사로 간주하지 마라.
몸체는 전역 좌표·seed에 따른 같은 반복 위상으로 모든 분면 상태에서 이어져야 한다. 장식은 실제 장식 영역만 덮고, frame/ring 원본의 배경 몸체가 별도 위상의 줄눈을 다시 덮지 않아야 한다. 끝캡 구조를 통째로 지워 접합 검사를 통과시키지 마라.

2. 계약과 버전 공존
contractId/artContract=ANIMOL_FREE_SHAPE_BLOB47_V1, lookup/FreeShapeLayer schemaVersion=1을 그대로 유지해라. artVersion만 4다. 기존 terrainPlacements schemaVersion=3과 혼동하지 마라.
기존 20 styleId, 32×32px/PPU32, 47 canonical mask/256 raw mask, v0~v3 네 위상을 유지해라. 목표 참조는 셀 Sprite 3,760개·아틀라스 80장·128×128px 문양 20개다.
V4 레지스트리를 별도 경로에 명시적으로 추가해라. 예: Assets/ANIMOL/TerrainFreeShape/Art/V4. 실제 프로젝트 규칙에 맞춘 최종 경로를 보고해라.
v1/v2/v3 맵은 각 버전 레지스트리를 계속 사용한다. 기존 에셋·meta·GUID·GlobalObjectId·사용자 맵을 덮어쓰지 마라. 미설치 버전·알 수 없는 계약/schema/버전 거부 검사를 유지하고, 임의 fallback으로 다른 버전 그림을 보여 주지 마라.
V4는 20스타일의 모든 mask·위상·문양 참조가 완전해야 한다. 다른 19스타일의 v3 파일과 SHA256이 같고 해당 에셋이 설치돼 있으면 V4 레지스트리에서 참조를 명시적으로 공유해도 된다. 없으면 이 패키지의 실제 파일을 임포트해라.
Runtime 아트 참조는 lookup이 지정한 Art/Atlases의 아틀라스와 각 스타일의 motif PNG를 사용해라. 개별 셀 PNG·Sampling·원화·Samples·HTML을 Runtime에 중복 설치하지 마라.

3. 픽셀 임포트
아틀라스: Multiple, 32×32 rect, 중앙 pivot, FullRect, PPU32. 문양: bottom-left pivot, PPU32, 4×4셀 크기, 추가 점유/Collider 0.
Point, 압축 None, mipmap Off, 기존 정상 sRGB 설정을 적용해라. JSON rect는 왼쪽 위 기준이므로 Unity y=atlasHeight-y-height로 변환해라.
최종 Sprite의 공용 팔레트와 alpha 0/255를 검사해라. 선형 필터·블러·Shader·자동 테두리로 줄눈을 보정하지 마라.

4. 선택 맵만 전환
현재 설치된 버전을 표시하고 사용자가 선택한 맵만 기존 Undo/Validate/Commit으로 artVersion=4에 전환해라. 설치·창 열기·재초기화가 기존 맵을 자동 전환하거나 저장해서는 안 된다. 먼저 별도 개발 맵 복사본으로 검증해라.
전환 전후 좌표·점유·styleId·seed·객체·스탬프·셀 크기·물리 소유자를 보존해라. 자유형 artVersion만 바꾸고 기존 규칙대로 hash에 반영, revision은 한 번 증가시켜라.
Undo/Redo는 버전과 파생 아트 캐시를 함께 복원하고, 검증/저장 실패는 정본·디스크·Scene 프리뷰·레지스트리 선택을 롤백해라. Ready·보상·스테이지 배정 검증을 우회하지 마라.

5. 연결·문양·물리 유지
N1/NE2/E4/SE8/S16/SW32/W64/NW128, 대각선 게이팅, rawToIndex/canonicalMask를 유지해라. resolveVariant와 문양 hash/support는 terrain_composition.mjs의 실제 규칙을 그대로 사용해라.
음수 청크 좌표는 floor division, 이웃 판정은 전역 점유로 처리해라. 문양은 동일 스타일의 4×4셀과 주변 1셀 지지가 있을 때만 표시한다. 줄눈·끝마감·문양이 점유나 Collider를 만들지 않아야 한다.
기존 고체 충돌 소유자·객체 footprint/swept path·one-way 물리를 보존해라. 아트 Tilemap에 Collider를 추가하거나 내부 구멍을 외접 사각형으로 막지 마라.

6. 실제 검증과 보고
패키지 검사: manifest SHA256, v4 Node 검사, 19스타일의 v3 대비 파일 목록·바이트 동일성, lookup 전체 참조·rect·위상·팔레트·알파를 확인해라.
T01_A에서 선언한 대칭 radius1 모서리 패턴·하이라이트·그림자, 패턴 밖의 직선 1px 줄눈, 반복 경계 연결을 검사해라. 모서리 곡선의 의도한 2×2 잉크는 허용한다. 판정은 등록되지 않은 접합 오류 0이며, 모든 2×2 잉크나 jaggies/doubles가 0이라는 주장은 하지 마라.
Unity에서 T01_A 47 mask×4위상과 단일 셀·얇은 가로/세로·양방향/비대칭 계단·U자 구덩이·내부 구멍·천장/돌출·T분기·음수 청크 경계를 실제 PNG와 비교해라. Scene와 Runtime을 원배율 1× 및 최근접 8×로 캡처해 명암·둥근 모서리·줄눈·외곽·끝캡의 접합을 확인해라.
v1/v2/v3/v4 선택→저장→재열기→시험 플레이, 선택 맵 전환 Undo/Redo·hash/revision·실패 rollback, 동일 좌표/seed의 Scene/Runtime 픽셀 일치, 문양 지지 제거/복원, 빈 공간·착지·one-way·객체 배치 보존을 검사해라. 실제 Unity 컴파일과 변경 경로의 기존 테스트를 실행해라.
Docs/ANIMOL_JOINT_FINISH_V4_PATCH_RESULT.md에 변경 경로·버전별 참조·PNG 해시·19스타일 보존·선택 개발 맵·임포트 설정·Unity 검증 결과·검수 캡처와 남은 문제를 기록해라. 실행하지 않은 검사는 미실행으로 남겨라. 일부 지형 검수를 모든 가능한 조합이나 20스타일 전체 수정으로 확대해 보고하지 마라.
