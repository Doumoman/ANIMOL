# ANIMOL 공통 장애물 9종 설계 v3

2026-10-07 사용자 수정 지시가 이전 Common 10 v2보다 우선한다. 기존 ID를 유지하며 C09를 다른 기능으로 재사용하지 않는다.

| ID | 개정 명칭 | 기능 | 구조 | 디자인·상태 |
|---|---|---|---|---|
| C01 | 하향 발판 | 기존 아래 통과 입력 | TOP | 팻말 없는 얇은 상판, 하부는 비어 있음 |
| C02 | 좌우 반사 스프링 | 수평 속도 부호만 반전, 나머지 기존 규칙 유지 | FULL | 벽면 접촉판·실제 코일, 좌우 미러·압축 복원 |
| C03 | 상향 스프링 | 기존 위 방향 발사 | FULL | 상향 코일 받침, 압축 복원 |
| C04 | 상시 위험칸 | 항상 활성인 기존 위험 효과 | AIR | 항상 보이는 가시. 주기·점멸·예고·안전 구간 없음 |
| C05 | 이탈 소멸판 | 기존 마지막 이탈·점유 보호 유지 | TOP | 처음부터 4조각의 금 간 상판. 밟음 시 균열 강화, 실제 비활성 시 낙하·페이드 |
| C06 | 떡 반동 발판 | 하강 중 유효 착지 시 기존 약한 반동 | TOP | 내부 한 색의 둥근 떡. 7프레임으로 눌렸다 복원 |
| C07 | 방향 바람칸 | 기존 방향의 공중 바람 | AIR | 기존 연속 흐름과 방향 표시 |
| C08 | 컨베이어 | 기존 방향 벨트 이동 효과 | FULL | 고무 띠·롤러·틀. 방향에 맞는 8프레임 반복 |
| C10 | 얼음 바닥 | 기존 저마찰 효과 | FULL | 연속 얼음 띠·넓은 반사 면·작은 고드름 |

C09 접근 생성판은 배치 목록·레지스트리·운영 로직·생성 후보에서 삭제한다. 직렬화 숫자·GUID는 다른 ID로 재사용하지 않는다. 기존 맵의 C09 셀만 삭제 마이그레이션하고 바닥으로 자동 변환하지 않는다.
C04는 그래픽만 켠 채 위험 판정을 점멸 상태로 남기지 않는다. 기능과 아트를 함께 상시 활성으로 전환한다. 기존 피해 처리·접촉 쿨다운·AIR 비고체 의미는 유지한다.
C05의 부서짐은 유니티 기본 SpriteRenderer·Transform·투명도로 처리한다. 조각에는 Collider와 피해 판정이 없다. 기존 소멸판 의미를 바꾸어 밟은 사람을 즉시 떨어뜨리는 기능을 추가하지 않는다.
스프링·떡의 그림 압축은 기존 충돌체나 반동 수치를 바꾸지 않는다. 공통 기능을 테마별로 다르게 구현하지 않는다.
