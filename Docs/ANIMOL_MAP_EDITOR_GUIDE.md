# 퍼즐 맵 제작기 사용법

Unity 메뉴 `ANIMOL/퍼즐/맵 제작기`에서 연다. 맵 에셋의 Inspector에서도 `퍼즐 맵 제작기 열기`를 누를 수 있다.

## 새 맵 만들기

1. `새 맵`을 누르고 맵 이름과 테마를 고른 뒤 `기본 맵 만들기`를 누른다. 기본 테마는 별길 목장, 기본 크기는 12×18이다. 크기는 만든 뒤 맵 설정에서 바꿀 수 있다.
2. 맵은 `Assets/ANIMOL/Data/Puzzle/Maps/이름.asset`에 저장된다. 장치 데이터 에셋은 같은 폴더에 자동으로 만들어져 연결된다.
3. 시작 맵은 걸을 수 있는 Grass 지형, 시작점, 방울 하나, 출구, 빈 장치 데이터를 가진다. 위치와 지형을 퍼즐에 맞게 편집한다.
4. `지형`, `장식`, `표식`, `장치`, `물` 레이어를 골라 왼쪽 드래그로 배치하고 오른쪽 드래그로 지운다. 각 레이어는 독립적이다. 물은 배가 사용할 논리적 물 칸이다.
   지형에서는 재질과 통행 금지 여부를 정한 다음 왼쪽 드래그로 원하는 칸에 칠한다. 오른쪽 드래그 또는 지우개로 지우면 해당 칸은 통행 불가가 되며 다른 레이어 데이터는 남는다.
5. `장치·물·목표 설정`에서 장치, 물 칸, 추가 목표, 비용 제한과 장치 정책을 설정한다.
6. `플레이 미리보기`로 실행한다. 하단 검사는 배치 유효성 검사이며 퍼즐 풀이 가능성은 증명하지 않는다.

## 장식 배치

- `장식` 레이어에서 그림과 이름이 있는 장식 목록을 고른 뒤 맵을 클릭한다. 목록에는 현재 테마의 장식품만 표시된다.
- 별길 목장의 벤치, 꽃, 울타리, 풍차 등을 각각 선택하면 맵과 플레이 미리보기에도 고른 그림이 나타난다. 오른쪽 클릭으로 장식을 지울 수 있다.

## 장치 배치

- 장치 레이어의 `테마 장치 목록`은 `Data/Puzzle/Prototypes`에 저장된 01~24 장치 연습 시나리오에서 설정과 프리팹을 읽는다. 하나의 연습 시나리오에 압력판과 다리처럼 여러 부품이 있을 수 있다.
- `테마 장치 목록`은 현재 맵의 `PuzzleTheme`를 기준으로 해당 테마의 연습 장치만 그림과 한국어 이름이 있는 카드로 보여준다. 장치 카드의 왼쪽 줄이 선택 상태다. 테마를 바꾸면 목록과 배치 가능 장치도 즉시 바뀐다. 테마 ID는 기존 저장 키 `starway`·`memory_theater`·`letter_observatory`·`twilight_sea`를 사용한다.
- 장치 데이터가 없는 이전 맵은 `장치` 또는 `물` 레이어를 열면 필요한 에셋이 자동으로 만들어진다. 테마를 먼저 지정하면 된다.
- `이 맵의 장치`는 현재 맵에 이미 놓은 장치를 복사한다. 카드를 고르고 칸을 누르면 별도 ID의 복사본이 만들어진다.
- 포털의 목적지와 선로·다리 칸은 배치 위치만큼 이동한다. 폭탄의 폭발 범위 오프셋은 상대 좌표로 유지한다.
- 연결 그룹, 포털 목적지, 선로, 물 칸, 폭발 범위와 추가 목표는 배치 후 확인한다. `왼쪽 클릭으로 배치된 장치 선택`을 켜면 그 칸의 장치를 선택해 바로 편집할 수 있다.
- 장치 레이어에서는 기본적으로 카드를 고른 뒤 클릭해 배치한다. `왼쪽 클릭으로 배치된 장치 선택`을 켜고 장치를 클릭하면 프리팹 그림과 번호, 방향, 연결선을 확인할 수 있다. 방향 버튼으로 회전하고 `다른 장치와 연결...`을 누른 다음 대상 장치를 클릭하면 두 장치가 같은 논리 그룹에 연결된다. `선택한 장치 연결 해제`는 선택 장치의 연결만 끊는다.
- 하늘색 실선은 같은 그룹의 장치, 분홍 점선은 포털 목적지다. 선택한 장치의 주황 점선은 선로/점유 칸, 폭탄의 주황 영역은 폭발 범위다. `연결선과 작동 범위 표시`에서 표시를 켜고 끈다. 연습 장치의 그룹 이름은 새 배치에 복사되지 않으므로 연결은 각 맵에서 명시적으로 만든다.
- 프리팹이 없는 장치는 미리보기에서 보이지 않으므로 경고를 확인한다. `장치 목록 새로고침`으로 연습 에셋 변경을 다시 읽을 수 있다.
- 별돌 소켓을 배치하거나 선택하면 `별돌 소켓 작동`에서 별돌이 들어간 뒤 실행할 동작을 고를 수 있다. `덩굴 다리 펼치기`는 먼저 맵에 배치한 다리를 목록에서 선택한다. `방울 나타내기`는 방울이 나타날 통행 가능한 칸을 지정한다. 맵의 `방+` 표시는 활성화 전에는 숨겨진 방울이다. 필요하면 목표 방울 수도 늘린다.

장치의 **현재** 판정은 [24종 장치 규칙 정리](ANIMOL_DEVICE_RULES_CURRENT.md)에 기록한다. 장치 규칙 변경안은 별도로 결정한다.
