# 24종 장치의 현재 판정

2026-10-18 코드 기준. 이 문서는 **현재 구현**을 기록한다. 앞으로 논의할 장치 규칙 변경안은 아직 반영하지 않았다. 판정 기준은 [PuzzleDeviceSession.cs](../Assets/ANIMOL/Scripts/Runtime/PuzzleDeviceSession.cs), 데이터 형식과 정책 기본값은 [PuzzleScenario.cs](../Assets/ANIMOL/Scripts/Runtime/PuzzleScenario.cs)다.

## 공통 턴 규칙

- 상하좌우의 유효한 입력 한 번에 코스트 1, 장치 턴 1이 진행된다. 막힌 입력은 위치·장치 상태·타이머를 확정하지 않는다. 자동 이동과 연쇄는 같은 입력에 포함된다.
- 플레이어는 지형의 이동 가능 칸 또는 활성 다리·이동 발판 위에 선다. 시나리오의 `water`만 배가 이동하는 물 칸이다.
- 시작점에서 출구로 가고 방울 목표 수를 모으며 `goals`의 추가 조건도 모두 만족해야 승리한다. `costLimit`이 0보다 크면 비용 한도 도달 시 실패한다.
- 연습용 시나리오에는 장치별 예제가 있지만, 장치를 복사한 새 맵에서는 연결 그룹·목표·보조 부품·물/선로/폭발 범위를 별도로 확인해야 한다.

## 장치별 현재 동작

| 번호 | 장치 (`PrototypeRole`) | 현재 판정 |
|---:|---|---|
| 01 | 별돌·별 소켓 (`StarSocket`) | 별돌을 한 칸씩 밀 수 있다. 돌의 `number`와 같은 번호의 소켓에 닿으면 돌이 제거되고 소켓이 활성화된다. |
| 02 | 압력판·덩굴 다리 (`VineBridge`) | 판의 칸을 플레이어 또는 고체 물체가 차지하면 같은 `group`의 다리가 펼쳐져 지지 칸이 된다. 기본 정책에서는 다리 위에 누군가 있으면 판을 떼어도 다리가 유지된다. |
| 03 | 초승달 도약대 (`CrescentLeap`) | 진입 전에 도약 방향으로 세 칸 떨어진 착지점의 사용 가능 여부를 검사한다. 진입하면 해당 칸으로 이동한다. 기본값은 중간 두 칸을 건너뛴다. |
| 04 | 셔터 (`Shutter`) | 유효 행동이 끝날 때마다 열림/닫힘 위상이 바뀐다. 점유 중이면 열린 채 유지된다. 기본값은 점유 중에도 위상을 진행한다. |
| 05 | 이탈 가시 (`DepartureSpikes`) | 처음 올라서면 무장한다. 플레이어가 그 칸을 떠날 때 솟으며 이후 해당 칸은 막힌다. |
| 06 | 이동 발판 (`MovingStage`) | 유효 행동마다 `cells` 선로의 다음 칸으로 왕복한다. 플레이어가 발판 위에 있으면 함께 이동한다. 다음 칸이 막히면 그 턴은 정지한다. |
| 07 | 무빙워크 (`Conveyor`) | 올라선 플레이어 또는 밀린 물체의 이동 방향을 장치 방향으로 바꾸어 자동 이동시킨다. |
| 08 | 책장·압력판 (`Bookshelf`) | 연결된 판이 새로 눌릴 때 책장의 3칸 몸체를 90도 회전한다. 회전 후 차지할 칸이 막히면 회전하지 않는다. |
| 09 | 일방통행 문 (`OneWayGate`) | 문의 방향과 같은 방향으로 지날 때만 통과한다. 반대 방향 입력은 거절된다. |
| 10 | 광학 장치 (`Optics`) | 광원 빛이 직진하고 거울에서 꺾인다. 빛을 받은 센서가 활성화되면 같은 `group`의 광학 문이 열린다. 기본값에서는 거울을 향해 입력하면 플레이어 이동 대신 거울을 회전한다. |
| 11 | 배 (`Boat`) | 시나리오의 물 칸에 있는 배에 탑승한다. 탑승 상태에서 물 칸 사이를 한 칸씩 이동하고, 육지로 이동하면 하선한다. |
| 12 | 통 (`Barrel`) | 밀기에 성공하면 진행 방향으로 장애물 앞까지 굴러간다. 포털, 무빙워크, 바람, 얼음과 상호작용한다. |
| 13 | 도미노 (`Domino`) | 놓인 방향과 같은 방향으로 밀면 이어진 미접힌 조각들이 접혀 통로가 된다. 다른 방향에서는 밀리지 않는다. |
| 14 | 자석·스위치 (`Magnet`) | 스위치를 밟으면 같은 `group`의 자석이 활성화된다. 기본값은 첫 진입 후 켜진 상태를 유지한다. 자석은 바라보는 직선상의 첫 금속 상자를 자기 쪽으로 당긴다. |
| 15 | 폭탄 (`Bomb`) | 처음 성공적으로 밀리거나 바람에 움직이면 타이머 3으로 무장한다. 이후 유효 행동에 따라 감소하여 `blastOffsets`에 지정된 칸에서 폭발한다. 기본값은 유리·금 간 벽을 파괴하고 폭발 범위 안 플레이어를 실패시킨다. |
| 16 | 포털 (`Portal`) | 진입 전 목적지와 그 다음 한 칸의 사용 가능 여부를 검사한다. 통과하면 목적지로 순간 이동한 뒤 기존 방향으로 한 칸 더 이동한다. 물체도 밀려 포털에 진입할 수 있다. |
| 17 | 석상 (`Statue`) | 바라보는 직선상에서 플레이어를 보면 조준을 고정한다. 다음 유효 행동에 돌진하며 접촉하면 실패한다. 유리·금 간 벽은 부수고, 기본값에서는 부순 칸에서 멈춘다. |
| 18 | 반사판 (`Bounce`) | 자동 이동 중 들어온 방향과 모서리 방향이 맞으면 진행 방향을 직각으로 꺾는다. |
| 19 | 브레이크 (`Brake`) | 플레이어의 강제 이동을 멈춘다. 밀려 움직이는 물체도 이 칸에서 멈춘다. |
| 20 | 바람 (`Wind`) | 송풍기는 막히지 않은 방향으로 바람 칸을 만든다. 바람 위 플레이어는 자동 이동한다. 유효 행동 종료 시 별돌·나무 상자·통·폭탄·주사위를 밀 수 있으며 금속 상자는 바람으로 움직이지 않는다. |
| 21 | 유리 (`Glass`) | 평소에는 고체 장애물이다. 폭탄이나 석상의 충돌로 제거된다. 광선은 유리를 통과한다. |
| 22 | 주사위·목표 (`Dice`) | 밀려 한 칸 움직일 때마다 면이 회전한다. 목표 칸에 올라가 윗면 숫자가 목표 `number`와 일치하면 목표가 활성화된다. |
| 23 | 겁쟁이 인형 (`CowardDoll`) | 유효 행동 후 플레이어가 인접하면 플레이어에게서 멀어지는 방향으로 한 칸 물러난다. 막혀 있으면 제자리에 남는다. |
| 24 | 병아리 (`Chick`) | 플레이어가 떠난 칸을 기록하고 `number`로 정한 지연 길이 뒤 따라간다. 다음 칸이 인접하고 비어 있을 때만 이동한다. |

`Ice`는 자동 미끄러짐을 주는 보조 장치(역할 25)다. 벽, 금 간 벽, 나무 상자, 금속 상자도 보드 구성 요소로 별도 역할 100~103을 쓴다. 위 24종 개수에는 포함하지 않는다.

## 시나리오별로 조정 가능한 현재 정책

| 필드 | 기본값 | 영향 |
|---|---|---|
| `holdOccupiedBridge` | 참 | 판에서 발을 떼어도 점유된 다리 칸 유지 |
| `shutterPhaseAdvancesWhenOccupied` | 참 | 셔터 점유 중에도 위상 진행 |
| `leapSkipsIntermediate` | 참 | 도약의 중간 칸 충돌 검사 생략 |
| `mirrorBumpRotates` | 참 | 거울에 부딪히는 입력으로 회전 |
| `magnetSwitchLatches` | 참 | 자석 스위치가 한 번 켜지면 유지 |
| `bombHurtsPlayer` | 참 | 폭발 범위의 플레이어 실패 |
| `bombDestroysOrdinaryObjects` | 거짓 | 고체 일반 물체까지 폭발로 제거 |
| `statueStopsAfterBreakingWall` | 참 | 석상이 벽을 부순 칸에서 정지 |

이 필드는 기존 코드의 선택지이며 이번 작업에서 기본값이나 판정을 바꾸지 않았다.
