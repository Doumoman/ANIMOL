# 흰 네온 별자리 지도 UI

별자리 그림과 밤하늘을 화면 전체로 보여준다. 살구색 상·하단 띠, 지역 제목 카드, 지역별 진행 수, 항상 보이는 안내 문구를 사용하지 않는다. 별자리32종·스테이지110개·별선·진행선·원본 NightSky PNG와 기존 좌표는 유지한다.

## 화면 규격

모든 위치는1080 기준이며 조작부는 실제 Safe Area에 배치한다. 지도 스크롤 영역은 상단240/하단324 예약을 제거해 전체 높이를 쓴다. 넓은 화면 바깥도 정적 NightSky로 채우며 스테이지의 그림 내부 좌표는 변경하지 않는다.

| 요소 | 위치·크기 | 표시 |
|---|---|---|
| 뒤로가기 | 왼쪽32·위24,132×132 | MapNeon/Utility 상태 PNG + Icon_Back |
| 망원경 | 오른쪽32·위24,300×112 | MapNeon/Wallet 상태 PNG + Icon_Telescope + 수량/상한 |
| 선택 패널 | 왼쪽48·아래24,984×240 | MapNeon/PanelFrame, 중앙투명 |
| 정보 | 패널 안 왼쪽32·위32,폭570 이내 | 스테이지 식별 정보와 테마명 |
| 스토리 다시보기 | 패널 안 X648·Y48,144×144 | MapNeon/Action + Icon_StoryReplay, 클리어한 별만 |
| 입장 | 패널 안 X816·Y48,144×144 | MapNeon/Action + Icon_Enter, 잠금 상황은 Icon_Lock |

PanelFrame은 Border36, Utility/Wallet/Action은 Border32의9-slice다. 아이콘96×96는 Border0이다. 모든 PNG는 흰 RGB와 가변 알파를 사용한다. 중앙에 불투명 색을 깔지 않고 그림과 별선이 프레임 안으로 비쳐야 한다. 네온 윤곽과 얕은 halo는 PNG에 구워진 정적 픽셀이며 실시간 빛 효과를 만들지 않는다. 일반 글자는 갈무리14의 흰색으로 표시한다. 밝은 별자리 그림 위에서도 읽히도록 노드ID·선택 정보·망원경 수량 글리프에만1080기준 약1.5픽셀의 얇은 고정 남색 윤곽을 적용한다. 패널 중앙은 계속 투명하며 글자 뒤에 색 상자를 추가하지 않는다. Unity는 원본 TMP 폰트 재질을 복제한 `Generated/Galmuri14_NeonReadability.mat`를 이 지도 글자에만 사용한다.

## 선택 흐름

지도 진입 시 선택 패널은 숨긴다. 플레이어가 별을 누르면 선택 정보가 채워지고 약0.20초 ease-out으로 아래에서 올라온다. 다른 별을 누르면 그 별의 정보로 갱신하며 요청/애니메이션이 겹쳐 과거 선택이 되살아나지 않는다. 접근성의 움직임 감소에서는 큰 이동을 생략한다. 선택 패널 바깥에는 전체 화면 입력 차단을 만들지 않는다.

잠긴 별도 선택 정보를 보여준다. 즉시 설명 팝업을 강제하지 않는다. 미보유 지역의 입장 동작은 기존 구매 팝업을 열고 선행 조건이 잠긴 스테이지는 입장을 막는다. 기존 입장 승인·망원경 소모·필수 스테이지 조건은 변경하지 않는다.

표시할 텍스트는 스테이지 식별 정보·테마명·망원경 수량뿐이다. 꼭 필요한 잠금 상태는 아이콘 또는 짧은 상태로 표시할 수 있다. '별자리 지도', 조작 안내, 지역별 클리어 수, 다음 충전/가득참 문구와 장식용 설명은 상시 표시하지 않는다. 버튼 접근성 이름은 스크린리더용으로 유지한다.

## 스토리 다시보기

검증된 클리어 기록이 있는 선택 단계에서만 다시보기 버튼을 표시한다. 클리어 전에는 해당 버튼을 숨겨 빈 자리를 남긴다. 진행 정보가 갱신되거나 선택을 바꾸면 즉시 조건을 다시 판단한다.

실제 스토리 서비스의 전용 Gateway를 호출한다. 스테이지 입장/재시작 경로를 대용으로 쓰지 않으며 망원경 차감·보충·클리어 기록 변경을 하지 않는다. 미연결·실패는 성공 처리하지 않는다. 중복 탭과 다른 선택/화면으로 바뀐 뒤 도착한 응답을 구분한다. 네이티브는 `NotebookGateway.RequestStoryReplay(string stageId, string operationId, Action<bool> completed)`를 사용한다. 기존 공급자를 깨지 않는 가상 기본 구현은 `completed(false)`다. Root는 동기 예외도 실패 완료와 동일하게 정리해 진행 중 상태가 남지 않게 한다. 상세 서비스 연결은 INTEGRATION.md의 Gateway 계약을 따른다.

## 기존 지도에 적용하는 전용 경로

현재 씬 또는 Prefab Stage에서 실제 `NotebookRoot`를 선택하고 `ANIMOL > New Notebook UI > Apply Neon Map To Selected Notebook`을 실행한다. 새 지도는 기존 지도와 같은 부모·형제 위치에 생성하고 Root/Layout 참조를 새 지도에 연결한다. 기존 지도는 비활성화하며 즉시 삭제하지 않는다. Undo로 되돌릴 수 있다.

이 경로는 Main/Settings/Modal/Camera/EventSystem/Build Settings와 진행·BM 데이터를 변경하지 않는다. 자동 씬 저장·전체 씬 교체 없이 Scene Dirty 상태만 남기므로 실제 참조·레이아웃을 확인한 뒤 저장한다. Play Mode에서는 실행하지 않는다. 처음 설치할 때만 별도의 기존 Build Fresh Scene 경로를 사용한다.

## 보존과 검증 한계

기존 무료/유료 지역, 구매 복원, 망원경 최대10·180초당1개·검증 광고+5, 입장 승인 후1회 차감, 필수 단계 클리어 후 대전 해금은 유지한다. 얼굴 스크롤링 원본과 메인·설정·인게임·클리어 디자인은 변경하지 않는다.

현재 작업은 정적 PNG·화면 생성 코드·브라우저 미리보기와 연결 계약을 제공한다. 실제 Unity 프로젝트의 활성 Scene/Prefab과 스토리 서비스가 없어 Unity Import/컴파일/Play Mode·실기기·실제 재생 거래는 검증하지 않았다. 브라우저나 C# 구문 검사 통과를 실제 게임 적용 완료로 부르지 않는다.
