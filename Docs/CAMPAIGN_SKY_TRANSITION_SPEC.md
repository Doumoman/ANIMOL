# 캠페인 시작 · 별하늘을 올려다보는 전환

메인의 캠페인 시작 버튼을 누르면 시선이 위로 이동하고 가까운 별을 지나 별자리 지도에 정착한다. 기존 그림을 새로 그리지 않고, 현재 메인 배경과 원본 `Map/NightSky.png` 사이를 짧은 셰이더 전환으로 연결한다. 지도 입장이 스테이지 입장·재시작·구매 요청으로 이어지지는 않는다.

## 연출과 시간

기본 재생 길이는 unscaled time 기준 1.10초다. UI를 누른 원인과 지도에 도착한 결과가 이어지도록 한 번의 짧은 동작으로 구성한다. 반복 진입 때도 추가 대기나 긴 마무리를 붙이지 않는다.

| 구간 | 정규화 진행도 | 화면에서 보이는 변화 |
|---|---:|---|
| 시작 | 0.00–0.16 | 현재 화면 위로 전환 레이어가 부드럽게 나타난다. |
| 시선 이동 | 0.00–0.55 | 메인 배경을 위로 0.15UV 이동하고 최대 1.65배 확대한다. 0.16–0.55에 원본 밤하늘로 연결한다. |
| 지도 준비 | 0.55–0.78 | 원본 밤하늘로 연결한다. 레이어가 화면을 완전히 가리는 동안 지도를 한 번만 연다. |
| 실제 지도 전환 | 0.62 / 약 0.682초 | 기존 `OpenStages()` 경로를 실행한다. 선택 정보 패널은 숨긴 상태를 유지한다. |
| 정착 | 0.78–1.00 | 별 효과와 전환 레이어가 사라지며 실제 별자리 지도와 네온 조작부가 보인다. |

전환 레이어는 0.16부터 0.78까지 불투명하다. 지도 화면 교체를 감추기 위해 흰색 플래시나 검정 암전을 추가하지 않는다. 별 27개는 고정 배치와 세 깊이 층을 사용한다. 가는 선 8개가 두 부분 별자리와 사이의 연결을 짧게 보여준다. 가까운 별은 크림, 먼 별과 선은 옅은 보라로 표시하고 원본 남색 밤하늘과 연결한다. 빠르게 무작위 생성되는 반짝임·무지개·과한 방사형 블러·카메라 흔들림을 사용하지 않는다. 목적지 밤하늘은 최대 1.26배에서 진행도 0.80까지 원래 배율로 정착한다.

확대와 원근감은 전환 레이어에서만 표현한다. 기존 메인 그림, 캐릭터 일러스트, 지도의 별자리 그림·별·연결선과 원본 얼굴 패턴을 변형하거나 재저장하지 않는다. 실제 게임 카메라의 Transform·투영·후처리 설정도 바꾸지 않는다.

## 구현 경계

- 전용 `NotebookCampaignSkyTransition`이 실제 루트 Canvas 전체를 덮는 임시 `RawImage` 레이어와 런타임 전용 재질을 관리한다. Safe Area 안에만 갇히지 않고 넓은 PC 화면도 채운다.
- `UI/WilliamCampaignSkyTransition` 셰이더는 진행도·소스/목적지 텍스처·UV 영역·화면비를 받아 그린다. 원본 그림을 직접 샘플링하며 GrabPass·추가 카메라·RenderTexture 캡처·Bloom 설치를 요구하지 않는다.
- 캠페인 버튼은 별도의 `OpenCampaign()` 진입점을 사용한다. 기존 `OpenStages()`는 실제 게임에서 돌아오는 경로 등 즉시 지도 열기가 필요한 호출을 위해 남긴다. 모든 지도 진입에 전환을 무조건 붙이지 않는다.
- 재생 중 중복 클릭과 다른 메뉴 입력을 막고, 완료·취소 때 이전 입력 상태를 복원한다. 지도 열기 콜백은 최대 한 번만 실행한다. 원본 버튼의 Persistent Listener와 새 연결이 중복 실행되지 않게 실제 바인딩을 확인한다.
- 시작 전에 셰이더·참조 이미지가 없거나 해당 렌더러를 사용할 수 없으면 기존 지도 열기로 즉시 대체한다. 재생 중 네이티브 렌더러가 실패하면 `CompleteImmediately()`로 지도 오픈을 최대 한 번 완료하고 정리한다. 브라우저의 재생 중 렌더링 실패·컨텍스트 상실은 현재 교체 지점에서 취소해, 교체 전이면 메인·교체 후이면 지도에 남는다. 두 경우 모두 검정 화면이나 남은 입력 차단 레이어를 만들지 않는다.
- 기존 접근성의 움직임 감소가 켜져 있으면 확대·파티클을 생략하고 바로 지도로 간다. 별도의 설정 항목을 추가하지 않는다.
- 포커스 이탈·앱 일시정지·오브젝트 비활성화·화면 이탈 시 전환을 정리한다. 지도 교체 전 취소는 기존 화면, 교체 후 취소는 이미 열린 지도에 정착한다. 재개 시 오래된 콜백을 재실행하지 않는다.

## 기존 지도와 BM 보존

네온 상단 조작부·투명 선택 패널·클리어 후 스토리 다시보기·비대칭 별 48프레임과 선택한 별의 4fps 회전은 유지한다. 전환이 끝난 지도에는 선택 패널과 자동 회전 별이 없어야 하며, 플레이어가 별을 탭한 뒤 기존 선택 동작을 시작한다.

원본 별자리 그림 32종, 스테이지 110개(20/30/30/30), catalog의 좌표·wireVertices·wirePath, NightSky, 얼굴 스크롤 PNG·셰이더·모션, 메인·설정·인게임 HUD·클리어 팝업 자산은 유지한다. 얼굴 스크롤 on/off 설정을 되살리지 않는다.

전환 자체는 망원경 입장 차감·보상 지급, 구매·광고 SDK, 진행 기록 변경을 호출하지 않는다. 전환 중에도 기존 180초 시간 회복은 정상 동작하므로 지갑이 시간 경계에서 증가할 수 있다. 전역 지갑 최대 10개·180초당 1개·검증된 광고 +5, 지역 영구 해금, 입장 승인, 중복 차감 방지, 인게임 재시작 5칸 게이지의 기존 계약은 바꾸지 않는다. 스토리 다시보기에도 영향을 주지 않는다.

## 적용과 확인

기존 설치에는 `CAMPAIGN_SKY_TRANSITION_APPLY_COMMAND.txt`를 따른다. 실제 Scene 또는 Prefab Stage의 `NotebookRoot`를 선택하고 `ANIMOL > New Notebook UI > Apply Campaign Sky Transition To Selected Notebook`을 실행한다. 이 메뉴는 전환 레이어와 참조를 추가하며 메인·지도 전체를 다시 만들지 않는다. Undo와 실제 연결을 확인한 뒤 사용자가 Scene/Prefab을 저장한다.

이전 네온 지도와 별 48프레임이 아직 적용되지 않았다면 먼저 `NEON_MAP_AND_STAR_APPLY_COMMAND.txt`의 지도 전용 적용을 진행한다. 이미 적용된 지도를 전환만 추가하려고 다시 생성할 필요는 없다. 전체 씬 생성 메뉴는 최초 설치용 별도 경로다.

실제 프로젝트에서는 캠페인 한 번 클릭·빠른 연속 클릭·뒤로가기·설정·실제 게임 복귀, 전환 전후 포커스/일시정지, 움직임 감소, 누락 셰이더/이미지, Scene/Prefab 저장과 Undo를 확인한다. 360×640·390×844·445×773·노치 Safe Area·1440×900에서 가장자리 노출과 잘림도 확인한다. 정상 시간 회복을 제외한 망원경 차감·지급이나 진행 기록 변경이 없어야 하며 지도 정점은 동일해야 한다.

현재 제공 환경에는 실제 Unity 프로젝트·Editor·실기기가 없으므로 Unity Import/셰이더 컴파일/C# 의미 컴파일/Play Mode·URP/기본 렌더 파이프라인 실기기 성능을 검증 완료로 주장하지 않는다. 브라우저 셰이더 미리보기, 정적 자산 검사, C# 구문 검사 결과와 실제 Unity 실행 결과를 구분해 보고한다.
