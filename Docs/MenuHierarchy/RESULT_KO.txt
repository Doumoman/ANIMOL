적용 결과
- 가로 팬: 원본 ±6도트 → ±30도트. 1080 기준 전체 이동 범위 48px → 240px(5배).
  한 테마는 사전 크로스페이드 0.5초와 본 슬롯 5초 동안 같은 연속 경로를 사용한다.
  따라서 표시되는 5초 슬롯 안에서의 이동은 약 220px이며, 전체 경로 범위는 240px이다.
- 세로 팬은 ±4도트(±16px) 그대로 유지. 토끼 접지와 버튼 간격을 보존했다.
- 1408px 너비의 일체형 배경을 확대 없이 이동한다. 가장자리 최소 여유 44px.
  건물·기둥·회랑을 분리해 움직이지 않는다. 배경/토끼 4배, UI 2배 유지.
- 테마 5초, 마지막 0.5초 크로스페이드, 토끼 8프레임/10fps, 구간별 방향 선택 유지.

새 객체와 참조를 두 씬에 저장했다. 공통 UI 프리팹에 Apply하지 않았다.
시작/모드 UI의 위치·크기·스프라이트와 상태 패널은 씬에서 편집 가능하며,
실행 시 MenuThemeSkin을 다시 적용해 덮어쓰지 않는다.
배경 위치·투명도·토끼 프레임/방향은 애니메이션 소유 값이므로 실행 중 갱신된다.
버튼 이벤트와 재화/광고/온라인 가용 상태는 기존 컨트롤러가 계속 연결·갱신한다.
씬에 배치된 객체를 재사용하고 중복 생성하지 않는다. 구 구조 호환용 생성 fallback만 유지했다.
재배치 도구: ANIMOL > Five Theme Menu > Author Bootstrap and Lobby hierarchy.
이 도구는 명시적으로 실행할 때 레이아웃을 다시 적용하므로 수동 조정 후에는 주의한다.
