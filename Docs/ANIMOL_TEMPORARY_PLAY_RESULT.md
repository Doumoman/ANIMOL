# 임시 자유 플레이 설정

2026-11-13. 기존 게임 HUD의 리롤(현재 판 재시작) 버튼에 실제 초기화를 연결하고, 망원경 무제한과 현재 플레이 대상 40맵의 임시 클리어 상태를 적용했다. 버튼·프리팹·씬을 새로 만들거나 교체하지 않았다.

## 적용 범위

- 별길과 극장의 기존 리롤 버튼을 횟수 제한 없이 사용할 수 있다. 현재 맵의 기존 `ResetStage`를 호출해 이동·예약 입력·코스트·수집·장치 상태와 HUD를 초기화한다. 같은 런타임 맵·세션·뷰를 재사용하며 씬이나 맵 에셋을 다시 로드하지 않는다. 일시정지 중이거나 실제 클리어가 확정된 판, 잘못된 스테이지 요청은 거절한다.
- 망원경 표시를 `무제한`으로 바꾸고 잔액 0에서도 입장할 수 있게 했다. 입장 승인과 중복 요청 검사는 유지하고 실제 잔액 차감만 생략한다. 저장 잔액을 큰 수로 채우거나 광고 보상·구매 기록을 생성하지 않는다.
- 별길 SW01~SW20과 극장 ET-01~ET-20을 지도에서 모두 클리어 상태로 표시하고 바로 입장할 수 있게 했다. 낙일 성소·별너울 해안 등 아직 연결되지 않은 지역을 완료 처리하지 않는다.
- 임시 클리어 표시는 실제 클리어 기록과 분리했다. 진행 동기화에는 저장된 기록만 사용하며, 임시 표시가 PlayerPrefs나 지갑의 클리어 목록에 기록되지 않는다. 실제 퍼즐을 풀면 기존 방식으로 실제 클리어 기록을 저장한다. 판 자체를 승리 상태로 만들거나 승리 연출·보상을 강제로 재생하지 않는다.
- 기본 재시작 게이지의 유한 승인 경로는 유지한다. 무제한 모드는 지원하는 실제 별길·극장 게이트웨이에서만 사용하며, 다른 프로바이더를 임의로 승인하지 않는다. 새 피드백 사건이나 입력 잠금, 시간 배율 변경은 추가하지 않았다.

## 설정과 원복

`Assets/ANIMOL/Data/Puzzle/Resources/NotebookCampaignPreview.asset`에서 다음 세 항목을 켰다.

| 항목 | 현재 값 | 기능 |
|---|---|---|
| `unlimitedTelescopes` | true | 망원경 무제한 |
| `unlimitedRerolls` | true | 기존 리롤 버튼 무제한 |
| `allStagesCleared` | true | 활성 40맵 임시 클리어·진입 |

각 항목을 끄고 로비에 다시 들어오면 해당 임시 설정이 해제된다. `enabled`를 끄면 임시 지역 접근을 포함한 프리뷰 설정 전체가 꺼진다. `Prepare Android 40 Stage Preview`는 새 설정 자산을 만드는 경우 세 항목을 켜며, 이미 있는 자산의 개별 설정은 유지한다.

APK 빌드는 사용자가 직접 하기로 했으므로 실행하지 않았다. 기존 APK에는 이 변경이 없으며 새로 빌드한 파일을 설치해야 한다. 실제 휴대폰 검증 역시 이번 실행 범위에 포함하지 않는다. Legacy의 `CommercialPolishPolicyTests`는 비활성 보관본이므로 활성 ArtAssetTests / ArtQaPlayTests와 구분한다.

검증 결과와 원본 맵·메타·씬·프리팹 보존 결과는 [Validation/TemporaryPlay](Validation/TemporaryPlay)에 기록한다.

- EditMode **29/29**: Notebook 20(새 임시 플레이 정책 검사 3개 포함), AndroidCampaignBuildTests 3, ArtAssetTests 4, ArtCatalogBuildValidationTests 2.
- PlayMode **15/15**: 새 무제한 재시작·지도 표시 검사 2, NotebookUiPlayTests 5, NotebookCampaignPlayTests 5, 실제 40맵 로드 1, 기본 유한 게이지 HUD 검사 1, 세로 ArtQaPlayTests 1. 별길·극장에서 실제 기존 버튼으로 각각 12회 초기화하고, 이동 중 예약 입력 취소·잔액 0 입장·일시정지/잘못된 스테이지 거절·동일 맵/세션/뷰 재사용을 확인했다. 기존 잠금/미클리어 별 애니메이션 검사는 임시 클리어 설정을 끈 정상 진행 모드로 격리하고 설정을 복원했다.
- 작업 시작 때 기록한 원본 맵·메타 122개와 메인 씬·UI 프리팹 3개 해시가 모두 동일하다. 이전 검증 캡처 40개도 복원했다. 소스클리어 ID와 작성된 경로·아트·GUID는 변경하지 않았다.
