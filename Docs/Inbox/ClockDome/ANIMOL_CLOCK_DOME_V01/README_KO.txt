ANIMOL 시계탑 — 어두운 천문대 돔 내부 환경팩 V01

작업 범위
첨부한 시계탑/천문대 이미지의 거대한 천체 시계, 굵은 사슬, 남청색 골조를
기존 ANIMOL의 정사각형 탑뷰 퍼즐 아트로 옮겼습니다.
돔과 기둥이 판을 감싸는 실내 구조이며, 금색은 시계/결합부의 강조에 사용합니다.
이 팩은 배경·바닥·장식입니다. 이전 편지 천문대 장치나 게임 로직을 교체하지 않습니다.
참고 이미지의 횡스크롤 시점, 캐릭터, UI, 로고는 사용하지 않았습니다.

구성
parts: 돔 캡 960×400, 같은 캡의 좌/중/우 분할 각 320×400,
       좌/우 반복 기둥과 기둥 발 각 160×80,
       천체 시계 240×240, 사슬 추 80×240, 망원경 160×160. 총 11PNG.
tiles/floor, tiles/underside: 각각 외곽16 + 오목 패치4 + 조립 완료47종.
       기본 원본은 80×80. 설명용 오목 모서리 적용 샘플4종도 각각 포함.
backgrounds: Far/Mid/Near 각 960×960, 가로·세로 반복 가능.
animation/pendulum_idle: 80×240 개별8프레임과 시트, 400ms씩/3.2초 루프.
inspection: 원본1배, 정확한4배 Nearest 접합 시트, 기둥 길이별 조립 예시, 미리보기.
examples: 불규칙 판/배경/격자 유무 합성, 레이아웃 JSON.
camera: 세 카메라 위치의 레이어 및 합성 비교 이미지.
prompts: 기본 image_gen으로 제작한 실제 프롬프트5개, 추가 제작 결정.

팔레트
Sweetie-16의 HEX만 허용합니다. 아트에 사용한 색은 8개입니다.
#1A1C2C 외곽선/가장 어두운 공간
#333C57 깊은 금속면/배경 벽
#29366F 돔 유리/시계 내부
#566C86 퍼즐 바닥/금속의 기본 밝은 면
#94B0C2 작은 금속 하이라이트
#3B5DC9 렌즈와 천체 시계의 파란 강조
#FFCD75 시계/결합부의 금장
#EF7D57 금장 어두운 면
원본 알파는 0 또는255입니다. 반투명 안개/글로우/중간색/디더링을 쓰지 않습니다.
검수판 설명 글자에는 승인16색의 #F4F4F4 등이 추가로 사용됩니다.

조립 원칙
Far → Mid → Near → 돔·시계·배경 사슬 → 단면 전체 → 바닥 전체 → 선택 격자
→ 가장자리 망원경 → 기존 장치/캐릭터 → 기존 UI.
기본 셀 간격80px/1unit(PPU80), 바닥 피벗 중앙입니다.
단면은 같은 점유 맵을 사용하고 이미지Y+12px/UnityY-0.15unit으로 표시합니다.
단면은 비충돌이며 모든 단면을 먼저, 모든 바닥을 나중에 그립니다.
한 칸별로 단면/바닥을 번갈아 그리지 않습니다.
각 방향 명암이 이미 들어 있으므로 타일을 회전/반전해서 재사용하지 않습니다.
inner4는 지정20×20 사각형의 RGBA를 교체하는 패치입니다. 투명도까지 교체합니다.
권장 런타임 입력은 tiles/*/blob47의 완성 PNG입니다.

돔 크기와 반복의 구분
돔 캡은 960px 폭의 고정 장식입니다. 캡 분할3장은 좌/중/우 순서로만 조립하며 반복용이 아닙니다.
돔 아래 기둥은 80px 단위로 세로 반복할 수 있습니다. 길이를 늘여도 픽셀을 늘리지 않습니다.
전체 높이 = 400 + 기둥반복행수×80 + 기둥발80.
더 넓은 맵에서는 돔을 하나의 뒤쪽 중심 장식으로 두고 주변 벽은 반복 레이어로 계속 채웁니다.
돔 캡을 가로로 반복하여 여러 시계/돔이 이어지는 모습으로 만들지 않습니다.
Far/Mid/Near가 양축 무한 반복의 빈틈 없는 바탕을 담당합니다.
돔 자체의 지붕 곡선이 모든 맵 너비에 자동으로 늘어나는 팩은 아닙니다.
960px보다 좁은 화면에서는 배경 장식이 카메라 밖으로 잘리는 것은 허용하되
플레이 타일과 충돌 경계는 가리지 않습니다. 원본 비정수 축소는 하지 않습니다.

연출
사슬 추의 윗부분12행은 고정, 아래부분만 최대2px 좌우 이동합니다.
선택적인 배경 idle이며, 이동/턴/코스트에 연결하지 않습니다. 시계 얼굴은 정적인 장식입니다.
게임 중 섬광, 파티클, 화면 흔들림, 줌, 반복 효과음, 햅틱을 추가하지 않았습니다.
별도의 앞뒤 깊이가 있어도 퍼즐의 논리적 칸 높이와 이동 판정은 동일합니다.

검수와 한계
4096개 타일 이웃 조합의 접합 불일치0. 80px 규격/HEX/이진 알파/외곽선을 검사했습니다.
돔 분할 재조립, 캡-기둥-기둥-발 접합, 음수 좌표를 포함한 세 카메라 위치를 검사했습니다.
8프레임의 캔버스/고정축/테두리 잘림을 검사했습니다.
예시에서 망원경이 이동 가능한 칸을 덮는 픽셀은0이며 받침이 실제 장식 데크에 닿습니다.
사슬 고리5개 및 망원경 구조의 작은 개방부는 의도한 투명 공간입니다.
예시는 실제 납품 PNG를 합성한 검수 화면이며 Unity 실행 화면이 아닙니다.
Unity 프로젝트 연결, 기기별 시야/성능, 기존 장치와의 실제 가독성은 적용 후 확인해야 합니다.
