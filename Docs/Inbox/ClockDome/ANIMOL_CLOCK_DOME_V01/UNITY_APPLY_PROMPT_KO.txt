ANIMOL Unity CLI 적용 명령 — CLOCK DOME V01

현재 ANIMOL 프로젝트의 실제 씬/Tilemap/카메라/맵 점유 데이터/장치 렌더링 구조부터 확인하라.
이번 요청은 시계탑의 어두운 천문대 돔 내부 배경과 환경 아트 적용이다.
ANIMOL은 가변 크기 정사각형 탑뷰 스와이프 퍼즐이다. 횡스크롤 러너로 처리하지 않는다.
기존 이동/코스트/수집/출구/장치/승패 로직은 그대로 유지하고 새 기능이나 UI를 추가하지 않는다.

1. 입력
ANIMOL_CLOCK_DOME_V01의 README_KO.txt, manifest.json, qa_report.json을 먼저 읽어라.
실제 사용 자산은 parts, tiles/*/blob47, animation, backgrounds이다.
source, inspection, camera, examples를 게임용 충돌 타일로 자동 등록하지 마라.
기존 편지 천문대 장치가 있다면 아트 참조를 보존한다. 이 팩에는 장치 대체품이 없다.

2. 픽셀 임포트
Sprite Single, PPU80, Mesh Full Rect, Filter Point, Compression None, Mipmap Off.
투명 여백을 trim하지 않는다. Sprite Atlas의 회전/Tight Packing을 끄고 패딩을 둔다.
기본 타일 피벗(0.5,0.5). 장식 피벗은 manifest.parts의 pivot을 따른다.
원본은 80px 또는80px의 배수이며 알파0/255다. PNG에 AA/보간/자동색 보정을 추가하지 않는다.
스크린 이동/패럴랙스는 최종 픽셀 좌표를 정수로 맞춘다. 정수배 Point 확대를 사용한다.
승인 팔레트 밖의 색이 생기는 Bloom/필름그레인/색보정 후처리를 이 아트에 적용하지 않는다.

3. 바닥과 단면
o=노출된 직교 이웃의 비트합: N1 E2 S4 W8.
i=두 직교 이웃이 있고 해당 대각선만 비었을 때의 비트합: NW1 NE2 SE4 SW8.
tiles/floor/blob47/oXX_iYY.png와 동일 마스크의 underside를 선택하라.
레벨 밖은 빈 칸으로, 같은 칸의 장치 존재는 바닥을 끊는 이유로 보지 않는다.
바닥과 단면 모두80px/1unit 간격. underside를 localY=-0.15unit으로 옮긴다.
Underside 전체를 바닥 전체보다 먼저 렌더링한다. 단면은 콜라이더가 없는 시각 레이어다.
광원은 좌측 상단이다. 회전/반전으로 방향별 타일을 대체하지 않는다.
직접 inner4를 합성한다면 manifest의20×20 RGBA 전체를 교체하라. alpha-over 합성은 안 된다.
격자는 optional/floor_grid_80.png를 참고하되 바닥 중앙 #566C86에만 표시한다.
림, 투명 구멍, 단면에 격자를 덮지 않는다.

4. 돔 조립
기준점을 돔의 이미지 왼쪽 위로 잡는다. 지붕은 dome_cap_960x400 한 장을 사용한다.
동일한 대안은 분할 left/center/right를 X=0/320/640px에 붙이는 방식이다.
한 장 버전과 분할 버전을 동시에 표시하지 않는다. 분할 center는 반복 타일이 아니다.
좌 기둥 X=0px, 우 기둥 X=800px. 양쪽의 첫 반복행은 Y=400px이고
80px 간격으로 N행을 배치한다. 기둥 발은 Y=400+80*Npx에 놓는다.
건축 부품 기본 피벗은(0,1)이므로 위 픽셀 좌표를 Unity(x/80,-y/80)로 변환할 수 있다.
960px 폭은 고정이다. 카메라/보드 크기 때문에 돔을 비정수 축소/비균등 확대하지 않는다.
폭이 큰 맵은 중앙 돔 + 반복 벽 레이어로 구성한다. 지붕 전체를 반복하지 않는다.
돔/시계/배경 사슬은 모든 이동 가능한 바닥과 플레이 오브젝트보다 뒤에 둔다.
배경 장식에 Collider2D나 게임플레이 Raycast Target을 붙이지 않는다.

5. 소품
시계는240×240/피벗(0.5,0.5), 사슬 추는80×240/피벗(0.5,1), 망원경은160×160/피벗(0.5,0).
시계의 얼굴과 눈금은 정적 장식이다. 코스트/남은 시간/턴 수 표시로 새로 연결하지 않는다.
사슬 추는 기둥/천장에 닿는 위쪽 고정점을 기준으로 배치한다.
망원경은 실제 이동 칸 바깥 장식 데크에 놓고 받침을 바닥에 닿게 배치한다.
예시의 walkableExample과 맵 모양은 검수용이다. 기존 레벨 데이터 위에 덮어쓰지 않는다.
top-left=(x,y), 크기=(w,h), 피벗=(u,v)이면 이미지 기준 원점에 대한 Unity 위치는
((x+u*w)/80, -(y+(1-v)*h)/80)이다.

6. 반복 배경
Far/Mid/Near는 각960×960이고 X/Y 반복한다. 스크롤 비율 기본값은0.15/0.30/0.45다.
최종 표시 좌표를 정수 픽셀에 맞추고 floor-mod로 음수 좌표도0..959에 접어 넣어라.
화면을 덮는 데 필요한 만큼 반복 사본을 배치한다. 카메라가 움직여도 모서리 빈틈이 없어야 한다.
Far는 완전 불투명이다. Mid/Near의 투명부는 정상이며 항상 Far 위에서 합성한다.
돔 캡은 반복 레이어와 별개의 세계 좌표 장식이다. 스크롤에 따라 잘려도
Far/Mid/Near의 반복 바탕이 실내 배경을 계속 채우게 한다.
기존 카메라 추적/줌 로직을 교체하지 말고 배경 렌더링에만 위 규칙을 적용한다.

7. 선택 애니메이션
pendulum_idle 8프레임, 프레임당400ms, 루프3.2초. 프레임 캔버스와 피벗을 고정한다.
위12행이 고정되고 아래 부분만 최대2px 이동한다. Transform 회전/추가 sway를 중복 적용하지 않는다.
화면 밖이거나 배경 움직임을 끄는 설정이 있으면 정지 프레임으로 대체할 수 있다.
기존 퍼즐 입력/충돌/결과 연출과 연결하지 않는다. 새 사운드, 햅틱, 파티클, 셰이크를 추가하지 않는다.

8. 씬 검수
좁은/넓은/세로 긴/가로 긴/불규칙 맵과 한 칸 통로·끝점·섬·오목 구멍을 확인한다.
상하좌우 이동 중 타일선, 기둥 반복부, 음수 카메라 좌표, Sprite Atlas 경계를 확인한다.
장식이 이동/충돌/출구/수집물을 가리지 않고 임포트 후에도 팔레트와 Point 표시가 유지되는지 확인한다.
시계 장식이 새 목표나 UI처럼 보이지 않는지 실제 장치·캐릭터가 있는 씬에서 확인한다.
기존 로직의 동작을 먼저 검증하고, 수정 파일/연결 내용/씬 검사 결과/남은 문제를 보고하라.
환경팩 자체는 PNG 검수를 통과했지만 Unity 프로젝트 실행은 아직 검증되지 않았다.
