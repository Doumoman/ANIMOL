ANIMOL 기억 극장 — 공중 무대 환경팩 V02

제작 범위
가변 크기 탑뷰 퍼즐을 위한 연결형 무대, 붉은 카펫, 짧은 하부 단면과 극장 소품입니다.
첨부 극장의 커튼·금장 구조·파이프 오르간을 ANIMOL의 기존 픽셀 그림체로 옮겼습니다.
시점은 상하좌우 정사각형 탑뷰이며, 사진의 원근이나 사실적인 조명은 사용하지 않았습니다.
이 팩은 배경/무대/장식용입니다. 이전 기억 극장 11종 퍼즐 장치를 새로 구현한 팩은 아닙니다.

구성
tiles/wood, tiles/velvet, tiles/underside
  종류별 외곽 16 + 오목 모서리 패치 4 + 미리 조립한 47종, 모두 원본 80×80 PNG.
  각 종류에 설명용 inner4_samples 4장이 추가되어 있습니다.
  실제 Tilemap에는 blob47을 권장합니다. 런타임 패치 합성보다 단순합니다.
props
  좌/우 커튼 기둥 각 80×160, 반복 상단 가로대 80×80.
  파이프 오르간 160×160, 2인 객석 160×80.
  각광 80×80: 켜짐/어두움/꺼짐 세 상태. 총 8개 PNG.
animation
  좌/우 커튼 idle 각 5프레임. 3.2초 주기, 천 부분만 최대 1px 이동.
  각광 등장 점등 3프레임, 240ms, 1회 재생 뒤 켜짐 상태 유지.
  모든 프레임은 같은 캔버스와 피벗을 유지하고 root motion은 없습니다.
backgrounds
  Far/Mid/Near 독립 PNG 각 960×960. X/Y 양축 반복, 낮은 대비의 하늘/극장 실루엣.
inspection
  1배 원본 부품, 목재+단면과 카펫의 1배/4배 접합 시트,
  3·5·9칸 너비로 조립한 커튼 틀, 디자인 확인판, 커튼 idle GIF.
examples
  불규칙 맵의 단면/목재/카펫/합성 PNG, 격자 유무, 극장 조립 예시와 맵 데이터.
camera
  세 카메라 위치의 레이어별 PNG와 합성 비교판.
prompts
  사용한 이미지 생성 프롬프트 5개와 추가 제작 결정 기록.

색과 픽셀 규칙
승인 Sweetie-16을 유지했습니다. 무대/소품에는 다음 7색만 사용했습니다.
#1A1C2C 윤곽, #333C57 깊은 면, #5D275D 벨벳 그림자,
#B13E53 붉은 천, #EF7D57 목재선/금속 어두운 면,
#FFCD75 목재/금장 밝은 면, #F4F4F4 건반/작은 렌즈 하이라이트.
원본은 알파 0 또는 255이며 중간색·안티앨리어싱·디더링이 없습니다.
검사판 글자에는 승인 16색 중 별도 설명용 색이 쓰일 수 있습니다.

레이어 조립
Underside 전체 → Wood 전체 → Velvet → 선택 격자 → 장식 → 기존 장치/캐릭터 → UI.
단면은 목재와 같은 점유 맵을 사용하고 이미지 기준 Y+14px, Unity 기준 Y-0.175unit입니다.
타일별로 단면과 윗면을 번갈아 렌더링하지 말고 전체 레이어 단위로 정렬합니다.
카펫은 별도의 부분집합 마스크로 선택하는 비충돌 오버레이입니다. 새로운 칸/높이를 만들지 않습니다.
80×80 캔버스의 투명 여백을 자르지 않습니다. 배치 간격은 80px/1unit(PPU80)입니다.
inner4는 지정한 20×20 RGBA를 교체하는 패치입니다. 투명 픽셀도 지워야 하므로 alpha-over로 붙이지 않습니다.
격자는 선택 요소입니다. 목재 밝은 면과 카펫 중앙 면에만 표시하고 외곽 금장/구멍/단면을 침범하지 않습니다.

소품과 가독성
커튼/오르간은 뒤쪽 데크, 객석은 앞쪽 데크, 각광은 앞 가장자리에 붙였습니다.
예시 데이터에는 structuralGround, carpet, walkableExample을 구분했습니다.
이 예시는 검수용 배치입니다. 기존 레벨의 이동 가능 칸을 이 데이터로 덮어쓰면 안 됩니다.
예시에서 소품이 이동 칸을 가리는 픽셀은 0이며, 모든 소품의 밑면은 데크 위에 닿습니다.
기존 맵에 장식 공간이 없으면 이동 칸을 침범하지 않는 별도 시각 데크나 바깥 가장자리에 배치합니다.
배경 레이어는 모두 판 뒤에 둡니다. 전경 소품처럼 플레이어 위에 덮지 않습니다.

검수 및 한계
6144개 이웃 조합에서 RGBA 접합 불일치 0.
원본 크기/HEX/이진 알파/투명 RGB0, 타일의 불필요한 구멍과 어두운 외곽선 뭉침을 검사했습니다.
가로대의 좌측/중앙 반복/우측 접합과 커튼의 고정 프레임을 검사했습니다.
세 카메라 위치와 음수 좌표에서 배경 반복을 검사했습니다.
실제 Unity 프로젝트의 씬 실행, 기존 퍼즐 이벤트 연결, 모바일 성능은 이 파일 제작 환경에서 검증하지 않았습니다.

원화는 기본 image_gen으로 제작했습니다. 팔레트·알파·타일 접합·1px 윤곽은 별도 정리했습니다.
원화 생성 결과 자체가 아니라 이 폴더의 최종 PNG를 게임 자산으로 사용하십시오.
