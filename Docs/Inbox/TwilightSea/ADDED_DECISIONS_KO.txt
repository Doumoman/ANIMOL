이번 작업에서 추가한 디자인 판단 / 사용 프롬프트 복기

사용자 확정: 황혼의 바다 배경·이탈 가시 발판·조종 나룻배·구르는 통·3턴 폭탄과 공통 장치의 테마 외형.
기준: 사용자가 제공한24장치 그림 도감24~28쪽. 공통4종은07/09/18/19. 기존80px 팩과의 호환 규격.
내장 이미지 생성 도구로 원화11종을 제작했고 GENERATION_PROMPTS.json에 전체 문장을 기록했다.
API/CLI 이미지 생성은 사용하지 않았다. Sharp로 기술적 분리·정렬·팔레트/알파 정리·애니메이션 프레임을 내보냈다.

추가한 시각 판단:
- 청록 바다, 살구/금색 부두, 남색/보라 하드웨어. 허용16색 안에서만 제작, 실제13색 사용.
- 공통 장치는 기존 실루엣을 따라 재질을 통일. 튕김 모서리의 안쪽 홈은 투명하게 유지.
- 가시4상태, 나룻배4방향 및 완전 분할 레이어, 통 원형 나뭇결8프레임, 폭탄의 큰5×7 숫자.
- 폭발은 비대칭 연결 색면과 불균등 파편으로 제작. 게임 범위와 시각 폭발 외곽은 별개.
- 해안 마스크16종, 물결·등·해초 장식. 이는 신규 게임플레이가 아닌 테마 기초 부품.
- 예측 표시는 통의 실제 정지 칸/기존 폭탄 범위 데이터를 읽는 정보 레이어로 분리.
- 배 승객은 기존 캐릭터를 사용. 셀 간 root 이동은 굽지 않고 기존 로직과 연결.
- 원화의 통 나뭇결이16색 변환에서 소실되지 않도록 방향별 밝기 양자화 경계를 조정.
- 원화의 해안 가장자리에서 추출한 짧은 띠를 모듈화해 같은 방향 연결부를 연속 색면으로 구성.

임의 확정하지 않은 항목:
- 가시의 다시 낮아지는 조건.
- 폭발 범위의 수치/모양, 플레이어/일반 물체 영향.
- 보트의 별도 비용/조작 버튼, 통의 추가 피해/굴림 비용, 신규 목표/보상.

유지/통합/삭제 제안의 근거 범위:
프로젝트 코드를 받지 않아 실제 중복 코드·미사용 기능을 발견했다고 주장하지 않는다.
유지: 기존 공용 UI·방울·캐릭터·출구·장치 로직.
통합: 적용 시 발견되는 중복 테마 재생기·방향 변환·턴 이벤트·사운드 경로.
삭제: 참조 검색으로 미사용을 확인한 임시 그림과 중복 이펙트만. full 배와 레이어 동시 렌더, 개별PNG와 시트 이중 임포트는 방지.

실제 사용한 프롬프트 전문은 GENERATION_PROMPTS.json, 원화 경로는 GENERATION_SOURCES.json에 있다.
원화와 제작 코드 전체는 별도 SOURCE.zip에 포함한다. 원화 자체는 최종 게임용 스프라이트가 아니다.
