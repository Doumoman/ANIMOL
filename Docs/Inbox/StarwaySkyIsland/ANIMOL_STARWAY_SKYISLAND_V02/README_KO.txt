ANIMOL 별길 목장 — 하늘섬 외곽 V02

이번 범위
별길 목장의 잔디 외곽과 짧은 하부 단면을 우선 교체하는 팩입니다.
다른 세 테마와 흙길·돌벽·물가·장치의 리디자인은 포함하지 않습니다.
첨부 화면을 형태와 배치의 기준으로 사용하고, 기존 승인 Sweetie-16 HEX를 유지했습니다.
따라서 첨부 화면의 중간색·부드러운 톤을 그대로 복제한 파일은 아닙니다.

시각 변경
넓은 밝은 잔디 면 → 연결된 초록 잔디 턱 → 짧은 청회색 단면 순서로 이어집니다.
섬 본체는 6색만 사용합니다. 점무늬·디더링·흩어진 하이라이트를 넣지 않았습니다.
하늘 속 덩굴 장식을 없애고 구름과 먼 천체만 남겼습니다.
클로버·울타리·나무는 이전 참고 스프라이트를 팔레트 정리한 선택용 환경 소품입니다.
배치 예시는 퍼즐 로직이나 실제 완성 스테이지가 아니라 외곽 연결 확인용입니다.

파일 구성
tiles/grass, tiles/underside : 각각 외곽 16 + 오목 모서리 패치 4 + 조립 완료 47종
각 PNG 원본은 80×80. under와 grass의 점유 맵은 동일합니다.
inner4_samples : 오목 모서리를 중앙에 적용한 설명용 원본, 레이어별 4장
atlases : 원본 시트 4장. 게임에는 blob47의 개별 PNG를 권장합니다.
backgrounds : Far/Mid/Near 독립 960×960 PNG, 가로·세로 반복 가능
context_props : 클로버/가로 울타리/세로 울타리 80×80, 나무 80×160
inspection : 1배 기본 부품, 1배·정수 4배 접합 시트, 디자인 확인판
examples : 불규칙 맵 PNG, 분리 레이어, 격자 유무 비교, 맵 점유 데이터
camera : 세 카메라 위치의 개별 레이어와 합성 비교
manifest.json : 경로·마스크·크기·배치 정보
qa_report.json : 실제 PNG 픽셀 검사 결과
prompts : 사용한 두 이미지 생성 프롬프트와 최종 보정 결정 기록

핵심 조립 규칙
1. Underside 전체 레이어를 먼저 그리고 Grass 전체 레이어를 나중에 그립니다.
2. Underside는 이미지 좌표에서 Y+14px, Unity에서는 Y-0.175unit(PPU80)입니다.
3. 80×80 캔버스를 자르지 않습니다. 배치 간격은 정확히 80px/1unit입니다.
4. 오목 패치는 alpha-over가 아니라 지정된 20×20 RGBA 사각형을 교체합니다.
   투명 픽셀도 교체해야 하므로, 보통은 이미 조립한 blob47 사용이 안전합니다.
5. 선택용 격자는 Grass의 중앙 밝은 면에만 적용합니다. 턱·구멍·단면에 그리지 않습니다.
6. 울타리와 나무는 외곽에 붙이고 이동 칸의 중심을 가리지 않도록 배치합니다.

검수
출력 PNG: HEX 팔레트, 알파 0/255, 투명 영역 RGB0 확인.
본체 타일: 단일 연결 형태, 의도치 않은 내부 알파 구멍 없음.
4096개의 이웃 조합 비교에서 RGBA 접합 불일치 0.
두 레이어의 어두운 외곽선 2×2 뭉침 0, 패치 조립 일치.
4배 시트는 최근접 정수 확대, 배경 반복 및 세 위치의 음수 좌표 래핑 확인.
실제 Unity 프로젝트 실행/모바일 성능/기존 충돌 로직은 이 환경에서 검증하지 않았습니다.

사용 도구
원화: 기본 image_gen. 후처리: Nearest 샘플링, 팔레트 고정, 알파 복구, 경계 규격 정리.
원화 생성 결과 자체는 규격 원본이 아니며, 납품 PNG가 게임용 최종 자산입니다.
