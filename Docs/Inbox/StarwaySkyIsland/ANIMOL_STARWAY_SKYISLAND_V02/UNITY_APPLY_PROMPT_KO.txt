ANIMOL Unity 적용 작업 — 별길 목장 하늘섬 외곽 V02

현재 프로젝트의 실제 씬, Tilemap, 맵 점유 데이터, 자산 임포트 규칙을 먼저 확인한다.
ANIMOL은 상하좌우 정사각형 격자의 2D 탑뷰 스와이프 퍼즐이다.
이 작업에서는 별길 목장의 외곽 표현만 교체한다. 이동·충돌·스와이프·코스트·수집·출구 로직,
다른 테마, 기존 공통/테마 장치를 임의로 바꾸지 않는다.

사용 자료: ANIMOL_STARWAY_SKYISLAND_V02 폴더의 README_KO.txt, manifest.json, qa_report.json.
압축을 푼 폴더를 프로젝트의 기존 아트 구조에 맞춰 가져온다.
개별 PNG는 Texture Type Sprite, Sprite Mode Single, PPU80, Pivot center(0.5,0.5),
Mesh Type Full Rect, Filter Mode Point, Compression None, Mip Maps Off로 설정한다.
Sprite Atlas를 쓴다면 회전/타이트 패킹을 끄고 충분한 padding/extrusion을 둔다.
원본 PNG와 팔레트를 재보간/재압축하거나 캔버스를 자동 trim하지 않는다.
최종 화면은 정수 확대와 픽셀 정렬을 사용한다.

타일 선택
o는 이웃이 없는 노출 방향의 비트 합: N1 E2 S4 W8.
i는 대각선만 비어 있고 그 코너의 두 직교 이웃은 모두 있을 때의 비트 합: NW1 NE2 SE4 SW8.
상/우/하/좌 순의 값과 대각선 값을 실제 맵 점유 배열에서 계산한다.
tiles/grass/blob47/oXX_iYY.png와 동일 이름의 underside PNG를 선택한다.
파일 이름은 exposed mask다. existing RuleTile이 connected mask를 사용하면 값을 변환한다.
외곽 방향별로 이미 광원을 반영했으므로 스프라이트를 회전/반전해 재사용하지 않는다.
레벨 경계 밖은 빈 칸으로 간주한다. 지형 점유와 오브젝트 점유를 혼동하지 않는다.

렌더링
같은 점유 맵으로 Underside/Grass 두 Tilemap 또는 두 렌더 레이어를 만든다.
Underside 전체를 먼저, Grass 전체를 나중에 렌더링한다.
Underside transform의 local Y에 -0.175unit을 적용한다(14/80).
Grass의 셀 간격은 X/Y 모두 1unit. 기울기나 원근을 적용하지 않는다.
Underside는 시각 전용이며 Collider와 게임플레이 점유에 관여하지 않는다.
기존 타일별 렌더러에서 잔디 다음에 해당 타일의 단면을 그리는 방식은 금지한다.
그렇게 하면 인접한 하단 잔디 위로 윗 타일의 단면이 튀어나올 수 있다.
외곽 5px 전후의 투명 여백은 연결 규격이므로 자동 crop하지 않는다.
격자를 쓰는 경우 optional/cell_grid_80.png를 Grass 중앙 밝은 색(#A7F070)에만 클립한다.
가장자리, 투명 구멍, 단면 위에는 격자가 표시되지 않아야 한다.
inner4 패치를 직접 합성할 필요가 있다면 manifest의 20×20 replaceRectTopLeft 전체 RGBA를 교체한다.
단순 알파 블렌딩으로 붙이지 않는다. 기본 경로는 blob47이다.

배경
Far -> Mid -> Near -> Underside -> Grass -> 선택 격자 -> 기존 오브젝트/캐릭터 -> UI.
세 배경 레이어는 모두 플레이 판 뒤에 놓는다. 스케일은 정수배를 유지한다.
960px 주기로 X/Y 양축 반복하고 화면 바깥에도 필요한 복사본을 배치한다.
기본 시차: Far 0.15, Mid 0.35, Near 0.65. 최종 샘플 좌표는 정수 픽셀로 반올림한다.
음수 카메라 좌표는 floor-mod를 사용한다. 카메라 예제 (0,0), (640,480), (-400,960)를 확인한다.
구름을 타일마다 장식으로 뿌리지 않는다.

표현 규칙
판 전체를 위아래로 흔들거나 이동 경계를 흔드는 연출을 추가하지 않는다.
이 파일 교체 때문에 화면 흔들림, 점광원, 발광, 파티클, 새로운 UI를 추가하지 않는다.
현재 장치의 입력/준비/행동/변화/결과/정착 순서는 유지하고, 표현 누락이 확인되면 별도로 보고한다.
context_props는 선택 자료다. 울타리/나무는 시각 가장자리에 뿌리가 닿도록 놓되 셀 중심을 가리지 않는다.
본체 색상은 제공된 6색만 사용한다. 나머지 자산도 SWEETIE16_MASTER.hex 밖의 색을 만들지 않는다.

완료 검증
한 칸 섬, 1칸 폭 통로, 네 방향 끝점, 안쪽 구멍, 오목/볼록 모서리의 접합을 확인한다.
inspection/island_join_1x.png 및 island_join_4x.png와 같은 형태를 실제 씬에서 확인한다.
에디터/모바일 세로 화면에서 알파 테두리, 겹친 단면, 잘림, 타일 틈이 없는지 점검한다.
세 카메라 위치에서도 배경이 빈틈 없이 이어지는지 확인한다.
기존 스와이프, 코스트, 수집, 이동 가능한 칸, 출구 동작이 이전과 같은지 확인한다.
수정한 파일, 적용된 씬, 검증한 항목과 남은 한계를 보고한다. 실행하지 않은 테스트를 통과했다고 쓰지 않는다.
