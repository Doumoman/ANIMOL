21 유리벽: 정적/부품PNG 9개 · 클립 15종 · 프레임 105개
정사각/가로/세로 유리, 접촉·4방향 비대칭 파괴
온전한 유리는 빛만 통과시키고 몸체·바람은 차단. 폭탄/석상의 기존 파괴 사건에 깨짐. 금 간 모습은 중간 연출이며 추가 체력이 아님.

배경·기초 부품
1024×1792 불투명 배경, 평평한 바닥2종, 벽·금 간 벽·파괴, 천문대 기둥·망원경·편지함·봉투·별등·난간을 포함한다.
봉투 idle은1680ms, 별등 idle은1200ms다. 이 움직임은 충돌·턴·코스트를 바꾸지 않는다.
망원경과 편지함은 테마 장식이다. 새 상호작용이나 보상 기능을 뜻하지 않는다.

색상·픽셀·규격
새 게임용 PNG는 Sweetie-16 안의 색만 사용한다. 알파0/255, 투명 픽셀RGB0. 배경은 허용색 중8색 범위로 제한한다.
참고 원화·합성 미리보기·기존V04 UI/토끼/분홍 방울은 새 자산 색수 검수의 대상이 아니다.
이번 팩은 앞선 V04·DEVICE8·기억 극장 팩과 같은80px 논리 셀 기준이다. 네이티브32×32팩은 아니다.
기본96×96 캔버스, 유리128×128, 망원경160×128, 봉투64×64, 별등64×96이다. 실제 셀 간격은80px다.
도약 궤적은256×96 또는96×256이며 시작 피벗에서 목적지까지240px, 정확히3셀이다.
캔버스 여백을 이동거리나 Collider 크기로 사용하지 않는다. 일반Sprite에96px 간격을 주면 안 된다.
PPU=80/(현재 Grid 한 셀의 월드 크기). Point/Nearest, 정수배 확대, 압축 없음, Mipmap 없음, Full Rect가 기준이다.
광원은 원화의 좌측 상단. 거울 반사면과 세로 유리의 회전 파생 프레임에는 기존 픽셀을 강체 회전한 명암이 포함된다.
최종 외곽 알파 경계와 넓은 색면을 정리했으며, 불필요한 작은 색 조각을 제거했다. 얇은 내부 반사면·금은 의도된 구조다.

피벗·루트 이동
JSON 피벗은 PNG 왼쪽 위 기준 픽셀. Unity normalized=(pivotX/width,1-pivotY/height).
일반 중심(48,48), 유리(64,64), 거울 내부 회전축(48,43), 망원경(80,116), 별등(32,76).
도약 궤적은 방향에 따라 (8,48)/(248,48)/(48,8)/(48,248)이므로 중앙 피벗으로 덮어쓰지 않는다.
PNG에는 셀 간 위치 이동을 굽지 않았다. 플레이어 도약·상자 견인·포털 이동은 기존 논리 from/to와 상태에 연결한다.
도약 시각 권장값320ms·최대높이18px는 캐릭터 시각 자식용이다. 새 게임 규칙·코스트·타이머가 아니다.
같은 이동을 PNG 프레임과 Transform에서 이중 적용하지 않는다.

광선·유리·반사
data/OPTICS_RULES.json에 두 거울 면과8방향 반사 사례가 있다. direction은 광선의 진행 방향이다.
슬래시(/): E→N, N→E, W→S, S→W. 역슬래시: E→S, S→E, W→N, N→W.
광선은96캔버스 내부80px 셀에서 끝과 끝이 이어진다. 양 끝을 어두운 윤곽으로 막지 않는다.
광선은 유리 외형 위, 불투명 몸체 아래에 그린다. 실제 광선 추적이 막힌 곳 너머에 잔상을 남기지 않는다.
온전한 유리는 큰 투명 중심이 정상이며, 광선 통과와 몸체 충돌을 알파로 추론하지 않는다.
유리 파괴의 마지막 프레임과 broken 상태는 완전 투명이다. 충돌 제거 시점은 기존 로직이 결정한다.
정사각/가로/세로 외형이 새 점유 규칙을 뜻하지 않는다. 기존 레벨 데이터의 점유를 유지한다.
source_off는 현재 프로젝트에 비활성 광원 상태가 있을 때만 쓴다. 기획서의 고정 광원에 새 on/off 조작을 추가하지 않는다.

포털·자석
A/B는 같은 별자리이며 금색 표식1개/2개로 양 끝을 구분한다. 내부만 움직이고 외곽은 고정한다.
exit_preview는 짝 포털 자체가 아니라 진행 방향의 바로 다음 칸에 표시한다.
출구가 막혔으면 걷기 최초 시도는 무효0, 이미 미끄러지는 중이면 원래 유효 입력 비용만 유지한다.
자석의 방향은 열린 자극이 바라보는 쪽이다. 견인 화살표는 그 반대, 자석을 향한다.
금속 상자와 나무 상자는 다른 표식을 쓴다. 여러 상자의 처리 순서는 현재 로직을 확인한다.

공통 규칙
유효 스와이프/밀기1회 비용1, 변화 없는 입력 비용0·장치 턴0, 한 행동 안 자동 연쇄 추가 비용0.
방울3개 후 출구를 유지한다. 스태미나·러너·점프 버튼 등 폐기된 장르 규칙을 다시 넣지 않는다.
애니메이션·빛의 맥동·idle 시간이 장치 턴을 진행시키면 안 된다.
비눗방울·캐릭터·상단 UI·출구는 기존 공용 자산/프리팹을 유지한다. 이 팩에는 새 오디오·햅틱 바이너리가 없다.

PREVIEW_QA.json은 Node VM으로 선택/재생/정지/프레임 경계를 검수한 결과이며 실제 브라우저 렌더링 검수가 아니다.
