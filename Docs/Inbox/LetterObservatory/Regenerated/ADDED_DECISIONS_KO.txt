사용자 요청 외에 추가한 제작 판단 / V01

1. 내장 이미지 생성 도구로 원화12종(배경+기초부품+공통4+전용5+분리 거울부품)을 제작하고, 배경을1회 정리했다. 전체 프롬프트를 기록했다.
2. 이전 제공 팩과 호환되도록80px 논리 셀·96px 일반 캔버스를 유지했다. 최초32px 규격과 다르다는 점을 숨기지 않는다.
3. 천문대의 색 비중을 남색·청회색·아이보리·하늘색으로 옮기고 금색을 문양에 제한했다. 허용 HEX는 변경하지 않았다.
4. 광원·거울·감지기는 별개의 구성품으로 제공하지만 기획 장치10번 하나로 묶었다. 전용5+공통4=9장치군이다.
5. 거울 받침대/반사면/회전축을 나눠 받침대가 회전하지 않게 했다. 기본 제공 클립은 합성 완료본이다.
6. 자석의 금속 표식, 감지기-문의 별, 포털 A/B의 동일 별자리와1/2표식으로 관계를 표시했다.
7. 비대칭 유리 파편에는128px 캔버스를 사용해 잘림을 피했다. 금 간 상태는 중간 프레임이며 새 내구도 규칙이 아니다.
8. 광선·도약/포털 목적지 표시·X는 정확한 게임 정보를 나타내므로 코드로 정렬한 픽셀 오버레이다. 몸체 원화는 이미지 생성 결과에서 왔다.
9. 최종 RGBA를 팔레트 양자화·알파 정리·작은 색 조각 제거·고정 프레임 보정한 뒤 시트와 프레임으로 내보냈다.
10. 배경의 작은 잎/꽃과 표면 잔점이 강해 한 번 더 넓은 색면으로 정리했다. 바닥에는 무늬/디더링을 넣지 않았다.
11. 봉투·별등 idle을 포함했다. 새 편지 수집·망원경 조작·광원 토글 기능은 추가하지 않았다.
12. UI/토끼/분홍 방울은 배치 예시에만 기존V04를 재사용했다. 전체 V04팩을 이 새 팩에 복제하지 않았다.
13. 예시 레벨·GIF·HTML은 아트 검토용이다. 실제 Unity 검수와 미확정 기획은 적용 단계로 남겼다.
