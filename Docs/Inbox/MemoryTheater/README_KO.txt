배경·기초 부품
1024×1792 불투명 극장 배경, 평평한 바닥 2종, 벽·금 간 벽·파괴 완료 상태, 나무 상자, 극장 기둥, 막, 벽등, 가로/세로 무대 테두리를 포함한다. 막 idle 3040ms, 벽등 idle 1000ms, 금 간 벽 파괴 240ms. 파괴 완료 스프라이트는 의도적으로 완전 투명하다.

색·픽셀 규격
새 게임용 PNG는 Sweetie-16의 정확한 16색 안에 있다. 알파는 0/255, 투명 픽셀 RGB는 0이다. 배경은 그중 8색 범위로 제한해 장치보다 대비를 낮췄다. 생성 원화·참고 화면·합성 미리보기는 이 색수 검수에서 제외한다.
V04와 동일한 논리 셀 80px 기준이다. 네이티브 32×32 타일 팩이 아니다. 일반 프레임은 96×96, 책장은 256×256, 막은 128×192, 벽등은 64×96이다. 원본 PNG를 임의로 80px로 자르면 안 된다.
한 셀의 월드 크기가 s라면 PPU=80/s. 기존 Grid·물리 크기를 바꾸지 않는다. 확대는 정수배·Nearest/Point. 원화는 좌측 상단 광원이며 책장의 중간 회전 프레임은 기존 픽셀을 강체 회전한다. 완료 상태의 프레임·금속 테두리는 방향별로 정리했다.

피벗·점유·위치 이동
manifest.json과 unity_import_manifest.json의 피벗은 PNG 왼쪽 위 기준 픽셀이다. Unity 정규화 값은 (pivotX/width, 1-pivotY/height). 이 팩은 V04 manifest의 서로 다른 표현을 임의로 혼용하지 않는다.
일반 중심 피벗 (48,48), 책장 중앙 (128,128), 인형 발 (48,82), 막 고정점 (64,17). 장식의 피벗은 각각 메타데이터를 따른다.
책장 외형은 아틀라스의 3칸 긴 형태를 따라 240px로 제작했다. 기존 충돌/점유 데이터가 우선이다. Sprite의 불투명 영역이나 여백으로 새 Collider를 만들지 않는다.
애니메이션 PNG에는 셀 간 위치 이동이 없다. 무대·주사위·석상·인형의 루트 이동은 기존 논리 좌표의 from/to를 받아 시각 자식에서 보간한다. PNG 프레임과 Transform에서 같은 이동을 두 번 적용하지 않는다.
시트와 개별 프레임은 같은 콘텐츠다. 어느 하나만 임포트/참조해 중복 생성과 용량 중복을 막는다. 시트의 빈 마지막 칸은 프레임으로 가져오지 않는다.

주사위 상태
초기: 위1·아래6·북5·남2·동3·서4. 오른쪽 첫 굴림 후 윗면4, 왼쪽3, 위쪽2, 아래쪽5.
data/DICE_ORIENTATIONS.json에 24개 전체 면 상태와 96개 방향별 전이를 기록했다. 파일명 t1_n5_e3은 위1·북5·동3이다. 윗면 숫자는 크게, 앞쪽 왼쪽/오른쪽 작은 점은 인접 남/동 면을 요약해서 표시한다. 긴 등각 측면을 새로 붙이지 않았다.
96개의 굴림 클립은 240ms이며 중간 3번 프레임부터 도착 면을 보여준다. 논리 상태의 커밋을 애니메이션 프레임 이벤트에 맡기지 않는다. 발판의 일치/해제는 실제 현재 윗면과 점유로 판정한다.

튕김 모서리 이름
nw/ne/se/sw는 단단한 벽이 붙은 모서리다. 열린 쪽은 각각 se/sw/nw/ne. 내부 빈 공간은 의도된 투명 영역이다. 누끼 보정으로 채우지 않는다.
화면 벡터 기준: nw에서 N→E 또는 W→S, ne에서 E→S 또는 N→W, se에서 E→N 또는 S→W, sw에서 W→N 또는 S→E. 프로젝트 좌표계/enum과 기존 반사 로직을 확인해 외형에 매핑한다.

게임 규칙 보존
유효 스와이프/밀기 1회 코스트1, 변화 없는 입력 코스트0·장치 턴0, 한 행동 안 자동 연쇄의 추가 코스트0, 방울3개 후 출구 규칙을 유지한다. 과거 러너/스태미나/점프 규칙을 다시 넣지 않는다.
idle 루프, 예고의 점멸, 시간이 흐르는 것만으로 셔터·무대·석상·인형의 턴이 진행되면 안 된다. 금 간 벽의 파괴도 기존 충돌 결과를 표현한다.
기획서의 미확정 예외는 실제 프로젝트 코드에서 확인해 연결한다. 이 아트 팩이 위상 보류·회전 충돌·연쇄 차단·석상 정지 위치를 새로 확정하지 않는다.
