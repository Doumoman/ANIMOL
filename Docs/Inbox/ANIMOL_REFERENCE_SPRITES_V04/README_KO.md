# ANIMOL V04 · 수풀 연결/누끼/방울 수정

이번 팩은 V03의 교체용입니다. 수풀은 연속 화면을 잘라 만든 조각을 폐기하고 온전한 단일 원형으로 재제작했습니다. 가로·세로 이미지와 모든 애니메이션은 전체 96px 프레임을 80px 간격으로 복사해 조립했습니다.

## 사용 파일

- `sprites/`: 정적 투명 PNG 34종. 바닥의 80×80px 사각형과 UI 패널 내부는 의도적으로 불투명합니다.
- `animation/`: 15종 클립의 개별 투명 프레임과 시트. 게임에서는 두 표현 중 하나만 사용합니다.
- `manifest.json`: 피벗, 점유, 프레임 시간, 시트 좌표, 렌더 규칙입니다.
- `unity_import_manifest.json`: Unity JsonUtility로 읽기 쉬운 배열형 임포트 정보입니다.
- `UNITY_CLI_APPLY_V04.txt`: 기존 게임에 실제 적용·검수하게 하는 프롬프트입니다.
- `PREVIEW.html`: 압축을 풀고 열면 수풀과 방울을 직접 재생할 수 있습니다.
- `preview/`: 배경 위에 합성한 검수용 이미지/GIF입니다. 게임 스프라이트가 아닙니다.
- `reference/art_reference.png`: 사용자가 제공한 그림체·비례 기준 화면입니다. 현재 맵이나 게임용 배경으로 대체하지 않습니다.
- `QA_REPORT.json`: 실행한 PNG·프레임·연결 검수 결과입니다.

## 수풀 배치

| 파일 | 논리 크기 | PNG 크기 | 배치 Pivot(왼쪽 위 기준) |
| --- | --- | --- | --- |
| `vine_tile` | 1×1 | 96×96 | [48,48] |
| `vines` | 1×2 | 96×192 | [48,48] |
| `vine_strip` | 3×1 | 256×96 | [48,48] |

한 칸의 간격은 80px입니다. 96px는 여백을 포함한 프레임 크기이며 배치 간격이 아닙니다. 각 원형의 잎 픽셀은 모두 유지하며, 묶음의 연결부에 생기는 작은 닫힌 빈틈에는 덩굴의 청록색 바탕을 채웠습니다. 한 칸 세계 크기가 1 Unity unit이면 이 팩은 80 PPU입니다. 기존 Grid나 물리 크기를 바꾸지 말고 새 스프라이트 PPU를 기존 셀 크기에 맞춥니다.

수풀의 Pivot은 첫 셀 중심으로 통일했습니다. `visual_roots`는 식물의 흔들림 고정점이며 배치 Pivot과 다릅니다. V03의 아래쪽 흔들림 기준점을 Sprite 배치점으로 사용하지 않습니다.

1×2/3×1 묶음을 사용할 때 같은 칸에 단일 타일을 중복 배치하지 않습니다. 단일 프레임을 셀 경계에서 다시 80px로 잘라내거나 RectMask로 가리지 않습니다. 변형 시 잎이 셀 경계를 조금 넘더라도 물리 점유는 기존 로직 그대로입니다.

## 명암·윤곽·투명도

수풀의 새 원형은 Sweetie16 중 5색 범위에서 실제 4색을 사용하고, 외곽 1px 윤곽선을 정리했습니다. 기존 오브젝트는 몸체의 원본 색면을 유지하면서 배경색이 묻은 외곽을 정리하고 전경 윤곽선을 다시 잡았습니다. 울타리 아래쪽의 잘못된 배경 컷도 닫힌 발끝으로 보정했습니다.

PNG는 Straight RGBA입니다. 투명 픽셀 RGB는 0으로 정리했습니다. 원본 화면을 보존한 고해상도 팩이므로 **전체 팩이 16색·32px 축소 규격이라고 주장하지 않습니다**. `sweetie-16.hex`는 고정 디자인 기준으로 동봉했습니다. 매끈한 분홍 비눗방울은 사용자가 지정한 비픽셀 표현 예외입니다.

픽셀 스프라이트는 Point/Nearest로 확대하고 방울에만 Bilinear를 사용합니다. 한 셀이 1 unit일 때 일반 스프라이트는 80 PPU, 월드 방울은 128 PPU로 가져옵니다. 방울 원이 약 0.75칸 크기가 되도록 한 설정입니다. 벽·상자·이동패드는 첫 셀 중심, 캐릭터는 발 기준, 방울은 원 중심으로 정리한 피벗을 사용합니다. Unity에서는 Alpha Is Transparency와 Full Rect, 프레임별 동일 Custom Pivot를 설정합니다. Sprite Atlas·마스크·정렬·Tilemap Culling도 프로젝트에서 별도로 검수해야 합니다.

## 연출

방울은 분홍색 얇은 막과 큰 흰 반사 아크로 단순화했습니다. 한쪽부터 막이 끊기고 불균등한 조각이 줄어드는 10프레임·280ms 수집 클립입니다. 사실적인 무지개 반사와 회색 잔광을 제거했습니다.

식물의 idle은 8프레임이며, 접촉 반응은 12프레임·450ms입니다. 마지막 접촉 프레임이 idle 첫 프레임과 같습니다. 뿌리와 논리 셀은 고정하고 렌더러만 반응시킵니다. 랜턴의 기존 은은한 밝기 변화도 유지합니다.

현재 게임 규칙은 유효 입력 코스트 1, 무효 입력 코스트/장치 턴 0, 자동 연쇄 추가 코스트 0, 방울 3개 수집 후 출구입니다. 이동 거리·정지·실패·코스트 0의 세부 처리는 실제 기존 코드가 정본입니다.

여기서 검수한 것은 PNG와 배치 합성·프레임입니다. 실제 Unity 프로젝트가 전달되지 않아 엔진 내부 적용 완료를 주장하지 않습니다. CLI 프롬프트에는 실제 연결과 PlayMode 검수를 완료 조건으로 명시했습니다.
