# 추가한 제작 판단 복기

1. 잘린 수풀 화면 조각을 반복하기보다 온전한 원형 한 개를 다시 제작했습니다. 위/아래/양끝 잎을 모두 포함하는 단위가 필요했습니다.
2. 묶음은 전체 96px 프레임을 80px 간격으로 복사했습니다. 내부 셀 경계에서 잎을 다시 자르지 않습니다. 연결부의 작은 닫힌 빈틈만 청록 바탕으로 채워 내부 구멍이 보이지 않게 했습니다.
3. 수풀 배치점 [48,48]과 흔들림 고정점 [48,88]을 분리했습니다. 배치 Pivot에 뿌리 점을 혼용하면 줄이 어긋납니다.
4. 실제 원본 배경과 섞인 경계 색을 정리하고 1px 전경 윤곽을 복원했습니다. 이 과정에서 외곽 RGB는 수정되므로 이전의 전체 원본 RGB 불변 주장은 적용하지 않습니다.
5. 울타리 발끝에 배경 컷으로 생긴 톱니를 완결된 형태로 보정했습니다.
6. 방울은 큰 흰 아크 두 곳과 단순한 분홍 막으로 줄였습니다. 새 수집 클립은 10프레임·280ms, 식물 접촉은 12프레임·450ms입니다.
7. 3×3 연결, 1×2/3×1 묶음, 최대 접촉 포즈를 여러 배경에서 확인하도록 검수 범위를 확장했습니다.
8. Unity가 읽을 수 있는 배열형 임포트 JSON과 CLI 적용 프롬프트를 추가했습니다. 벽·상자·이동패드의 피벗은 첫 셀 중심에 맞추고, 방울은 원 중심/128 PPU로 약 0.75칸 크기가 되도록 지정했습니다. 기존 프로젝트의 코드명·이동 거리·실패 규칙은 임의로 가정하지 않습니다.
9. Full Rect·Alpha Is Transparency·셀 간격·Pivot·Mask·Sort·Tilemap Culling 확인을 CLI에 포함했습니다. PNG가 완전해도 엔진 설정으로 잘릴 수 있기 때문입니다.

이번 이미지 생성 프롬프트의 전체 원문은 GENERATION_PROMPTS.json에 동봉했습니다. 새 게임 규칙과 24개 장치를 추가하는 작업은 하지 않았습니다.
