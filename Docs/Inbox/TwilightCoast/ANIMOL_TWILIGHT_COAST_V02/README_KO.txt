ANIMOL 황혼의 바다 — 석양 해변 환경팩 V02

제작 범위
청록빛 바다, 낮게 지는 해, 따뜻한 모래 해변을 중심으로 만든 환경팩입니다.
기존 ANIMOL의 정사각형 탑뷰 시점, 원본80px, Sweetie-16, 좌측 상단 광원을 유지했습니다.
화면 대부분은 퍼즐 판으로 두고 야자수·바위와 조개·로프 울타리를 해변 외곽에 배치했습니다.
기존 황혼의 바다 장치(이탈 가시 발판/조종 나룻배/구르는 통/3턴 폭탄/공통 장치)는 별도 자산입니다.
이번 팩은 장치 로직이나 UI를 새로 구현하거나 교체하지 않습니다.

파일 구성
tiles/sand, tiles/wet_sand_body: 각 외곽16 + 오목 패치4 + 조립완료47종, 원본80×80.
  각 재질의 inner4_samples는 패치를 중앙 타일에 적용한 설명용4장입니다.
props: 야자수160×160, 바위·조개160×80, 로프 울타리160×80,
       해240×160, 반사광240×160, 잔물결3종 각240×80.
backgrounds: Far/Mid/Near 각960×960 양축 반복.
             노을 중심960×320, 해를 뺀 동일 중심, 좌/우 연장 각80×320.
animation: 야자수 idle5프레임, touch6프레임, 잔물결4프레임과 각각의 시트.
inspection: 1배 원본, 정확한4배 Nearest 접합 시트, 넓은 노을 조립, 미리보기/GIF.
examples: 불규칙 맵, 레이어 분리, 격자 유무, 배경 조립 예시와 레이아웃 JSON.
camera: 세 카메라 위치에서 반복 바다 레이어 비교.
prompts: 실제 이미지 생성 프롬프트5개와 추가 제작 판단.

주요 색
바다 기본 #257179. 잔물결 #94B0C2 / #73EFF7.
모래 #FFCD75, 젖은 모래 #EF7D57, 짧은 단면 그림자 #B13E53.
포말 #F4F4F4 / #94B0C2. 물가에도 물리적인 바닥 외곽은1px입니다.
노을 하늘 #B13E53 / #EF7D57, 긴 구름 #5D275D, 해와 반사광 #FFCD75.
잎 #A7F070 / #38B764 / #257179, 바위 #94B0C2 / #566C86 / #333C57.
윤곽 #1A1C2C. 총13색을 Sweetie-16 안에서 사용했습니다.
재질별로 넓은 색 덩어리를 유지했고 디더링/모래 점/그라데이션/중간색을 넣지 않았습니다.
모든 납품 PNG의 알파는0또는255이며 투명 영역의RGB는0입니다.

연결 지형
모래와 짧은 젖은 모래 단면은 같은 점유 맵을 사용합니다.
단면 이미지Y+8px, UnityY-0.1unit. 전체 단면을 먼저, 전체 바닥을 나중에 렌더링합니다.
단면은 충돌 없는 시각 요소이며 깊은 절벽이나 별도의 이동 높이가 아닙니다.
외곽의 약한 굴곡은 원화 해변 실루엣에서 얻고 연결 양끝은 같은 픽셀열로 맞췄습니다.
모서리/한 칸 통로/끝점/섬/오목 구멍에 각각 대응하며 임의 회전으로 방향을 대신하지 않습니다.
inner4는 지정20×20 영역의RGBA 교체입니다. 투명 픽셀까지 교체해야 합니다.
실제 게임에는 blob47의 미리 조립된 PNG를 권장합니다.
격자는 선택이며 모래 중앙의 #FFCD75에만 #EF7D57로 표시합니다.

바다와 노을의 반복 범위
Far는 불투명 청록 바탕, Mid는 낮은 대비의 잔물결, Near는 조금 밝은 잔물결입니다.
세 레이어는 각각 X/Y 양축 반복합니다. 기본 패럴랙스 비율0.12/0.30/0.50.
노을 중심은 해가 하나만 있는 별도 장식입니다. 중심 PNG를 반복하지 않습니다.
화면이 넓으면 왼쪽에는 left 연장, 오른쪽에는 right 연장을80px 단위로 반복합니다.
노을 자체는 세로로 반복하지 않습니다. 수평선이 여러 줄 생겨서는 안 됩니다.
해를 따로 배치하려면 horizon_without_sun에 해와 반사광 PNG를 올립니다.
원본 중심을 재현하는 top-left 위치는 해(360,80), 반사광(360,218)px입니다.
원본 중심 PNG와 분리형 조합을 동시에 렌더링하면 안 됩니다.
예시는 노을을 맵 위쪽의 세계 배경으로 배치했습니다. 카메라가 아래로 이동하면
노을은 시야 밖으로 나가고 반복 바다가 나머지 공간을 채웁니다.
항상 수평선을 보여야 하는 별도 카메라 연출은 현재 프로젝트 요구를 확인한 뒤 결정합니다.

장식과 연출
야자수 뿌리/바위 받침/울타리 기둥은 장식용 모래에 닿습니다.
예시에서 소품이 walkableExample을 가리는 픽셀은0입니다.
야자수 idle은3.2초/5프레임, 최대1px. 아래48행은 고정됩니다.
touch는430ms/6프레임, 최대3px 반응 후 원래 프레임으로 돌아옵니다.
touch는 기존 장식 접촉 이벤트가 있을 때만 연결하는 선택 자산입니다. 새 충돌 기능을 만들지 않습니다.
잔물결은2.4초/4프레임, 최대4px 수평 이동. Near 정적 레이어를 대체합니다.
정적Near와 애니메이션을 중복 표시하거나 Transform 이동을 중복 적용하지 않습니다.
해나 하늘은 번쩍이지 않습니다. 화면 흔들림/줌/추가 효과음/햅틱은 추가하지 않았습니다.
inspection의 GIF는 프레임 확인용입니다. 게임에는 PNG와 manifest의 개별 타이밍을 사용합니다.

검수와 한계
4096개 실제 이웃 조합에서 접합 불일치0. 팔레트/이진 알파/80px 크기/1px 외곽선을 검사했습니다.
타일의 불필요한 구멍, 2×2로 뭉친 어두운 외곽선, 오목 패치 재조립을 검사했습니다.
야자수 고정 뿌리/복귀/프레임 잘림, 잔물결의 반복 경계, 노을 좌우 접합을 검사했습니다.
해1개 및 분리형 해/반사광의 원본 재조립도 검사했습니다.
3카메라 비교에는 반복 바다 레이어를 사용했습니다. 노을은 반복 레이어가 아닙니다.
예시는 납품PNG 합성 화면이며 Unity 실행 캡처가 아닙니다.
실제 Unity 씬의 장치·캐릭터·카메라 배치와 모바일 성능은 적용 후 확인해야 합니다.
