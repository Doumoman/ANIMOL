ANIMOL Unity CLI 적용 명령 — 황혼의 바다 석양 해변 V02

현재 프로젝트의 실제 씬, Tilemap, 카메라 추적, 점유 맵과 장치 렌더링 구조를 먼저 확인하라.
ANIMOL은 가변 크기의 정사각형 탑뷰 스와이프 퍼즐이다. 과거 러너/플랫포머 구조로 처리하지 않는다.
이번 작업은 황혼의 바다 환경 아트 적용이다. 기존 이동·코스트·방울·출구·승패·장치 로직을 유지한다.
이탈 가시 발판/조종 나룻배/구르는 통/3턴 폭탄/공통 장치를 새로 만들거나 바꾸지 않는다.

1. 자료와 범위
ANIMOL_TWILIGHT_COAST_V02의 README_KO.txt, manifest.json, qa_report.json을 읽어라.
사용 자산은 tiles/*/blob47, props, backgrounds, animation이다.
source/inspection/examples/camera는 제작·검수 자료다. 자동으로 충돌 자산으로 등록하지 마라.

2. 임포트
Sprite Single, PPU80, Mesh Full Rect, Filter Point, Compression None, Mipmap Off.
투명 여백을 trim하지 않고 Atlas 회전/Tight Packing을 끄며 패딩을 둔다.
타일 피벗은(0.5,0.5), 소품은 manifest.props의 pivot을 따른다.
원본80px 또는80px 배수, 알파0/255, Sweetie-16 HEX만 유지한다.
정수배 Point 확대와 최종 픽셀 정렬을 적용한다. AA, Bloom, 색 보정, 부드러운 보간을 추가하지 않는다.

3. 연결 타일
노출 이웃 o=N1 E2 S4 W8. 레벨 밖은 빈 칸이다.
두 직교 이웃은 있고 대각선만 없을 때 i=NW1 NE2 SE4 SW8을 더한다.
oXX_iYY.png를 선택한다. connected bitmask와 exposed bitmask를 혼동하지 않는다.
같은 칸의 장치가 있다는 이유로 바닥 연결을 끊지 않는다.
sand와 wet_sand_body는 동일한 구조 점유 맵을 쓴다.
칸 간격80px/1unit, wet_sand_body는 localY=-0.1unit. 단면은 콜라이더가 없다.
WetSandBody 전체 → Sand 전체 순서다. 칸마다 바닥/단면을 번갈아 그리지 않는다.
광원이 방향별로 들어 있으므로 타일 전체 회전/반전으로 방향을 대신하지 않는다.
inner4를 직접 합성하면 지정20×20 RGBA 전체를 교체한다. alpha-over는 사용하지 않는다.
기본 적용은 미리 조립된 blob47이다. 선택 격자는 모래 중앙 #FFCD75에만 표시한다.

4. 반복 바다
Far/Mid/Near 각960×960. X/Y 양축 반복, 기본 패럴랙스0.12/0.30/0.50.
최종 오프셋은 정수 픽셀. 음수 좌표에도 floor-mod를 사용해0..959 범위로 접어 넣는다.
현재 카메라 시야를 완전히 덮도록 충분한 반복 사본을 배치한다.
Far는 불투명, Mid/Near는 투명 부분이 있는 반사광 레이어다. 모두 지형과 플레이어 뒤에 둔다.
기존 카메라 추적/줌/경계 로직을 교체하지 말고 배경 스크롤에만 연결한다.
바다가 기본적으로 배경이라는 이유로 새 물리/수영/낙사 로직을 만들지 않는다.
기존 물 관련 판정이 있으면 그 데이터에 따르고 장식 바다와 논리적 물 칸을 혼동하지 않는다.

5. 노을과 해
horizon_core_960x320은 해가 한 번만 그려진 중심부다. 가로나 세로로 반복하지 않는다.
폭을 연장할 때 중심의 왼쪽에는 horizon_side_left_repeat_80x320,
오른쪽에는 horizon_side_right_repeat_80x320을80px 간격으로 붙인다.
왼쪽 연장과 오른쪽 연장은 서로 다른 픽셀열이다. 반대쪽으로 바꾸거나 뒤집지 않는다.
기본은 맵 위쪽의 세계 배경에 놓고 모든 지형/장식보다 뒤에 렌더링한다.
카메라가 아래로 이동해 노을이 사라져도 반복 바다가 화면을 채우게 한다.
항상 수평선을 보여 주는 카메라 고정 연출은 임의로 추가하지 않는다.
해를 분리해 배치하는 대안은 horizon_without_sun + setting_sun + sun_reflection이다.
중심 이미지의 왼쪽 위를 기준으로 해 top-left=(360,80), 반사광=(360,218)px.
해/반사광의 피벗(0,1)이므로 Unity 위치는 (x/80,-y/80)이다.
한 장 버전과 분리형 버전은 둘 중 하나만 사용한다. 해나 반사광이 겹치지 않게 한다.
노을 이미지에 비균등 스케일/블러/추가 글로우를 사용하지 않는다.

6. 해변 장식
야자수160×160, 바위·조개160×80, 로프 울타리160×80은 비충돌 장식이다.
뿌리/받침/기둥 발이 실제 외곽 모래에 닿게 배치하고 이동 칸 중심/수집물/출구를 가리지 않는다.
로프 울타리를 단방향 문이나 새 벽으로 등록하지 않는다.
잔물결3종240×80은 물 위의 반사광이며 콜라이더나 클릭 타깃을 만들지 않는다.
examples의 맵 모양/walkableExample은 검수용이다. 기존 레벨 데이터를 덮어쓰지 않는다.
이미지 좌표 top-left=(x,y), 크기=(w,h), 피벗=(u,v)을 Unity로 옮기는 식은
((x+u*w)/80, -(y+(1-v)*h)/80)이다.

7. 애니메이션
palm_idle: 5프레임, [800,400,800,400,800]ms, 루프3.2초. 뿌리와 아래48행 고정.
palm_touch: 6프레임, [40,60,70,80,80,100]ms, 430ms 후 원래 자세로 정착.
기존 장식 접촉 이벤트가 있을 때만 touch를 연결한다. 없으면 idle만 사용한다.
touch가 idle을 잠시 대체하고 완료 후 idle로 돌아오게 하며 두 애니메이션을 동시에 적용하지 않는다.
잔물결: 4프레임, 각600ms, 루프2.4초. animation/water_ripples는 정적Near를 대체한다.
잔물결 캔버스960×960은 반복을 유지하며 알파 페이드/Transform 추가 흔들림을 사용하지 않는다.
PNG 프레임의 픽셀 이동이 이미 들어 있으므로 root motion을 끈다.
예시GIF가 아니라 manifest의 개별 클립 타이밍을 실제 게임에 사용한다.
화면 밖 장식은 정지할 수 있다. 새 효과음, 햅틱, 파티클, 화면 흔들림, 줌은 추가하지 않는다.

8. 적용 검수
한 칸 통로/끝점/섬/대각선 오목 구멍을 포함한 불규칙 맵에서 선이 끊기지 않는지 확인하라.
카메라 상하좌우 이동, 음수 좌표, 가로/세로로 긴 맵, Atlas 경계에서 빈틈을 확인하라.
노을의 해가 하나인지, 좌우 연장 이음새가 맞는지, 반복 바다가 지형 구멍까지 채우는지 확인하라.
소품이 이동·충돌 경계나 방울·출구를 가리지 않는지 실제 플레이 씬에서 확인하라.
기존 수집/장치/승패 연출과 새 배경 idle이 시선을 방해하지 않는지 확인하라.
변경 파일, 연결한 씬/프리팹, 검사 결과, 남은 문제를 보고하라.
환경팩 PNG 검수는 완료됐지만 실제 Unity 프로젝트 실행 검증은 아직 수행하지 않았다.
