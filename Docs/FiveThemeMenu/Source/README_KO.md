# ANIMOL 5테마 메뉴 배경 맵 (352×704)

월궁, 구름고래 목장, 별가루 도서관, 시간유리 온실, 오로라 수정광산을 **각각 한 장으로 이어진 세로 장면**으로 제작했습니다. 일체형 회랑은 화면 좌우를 잇고 아래 기둥/건축 구조에 지지됩니다. 다섯 배경은 모두 352×704 원본 도트, 최대 96색, 무디더링, 화면에서 정수 4배입니다. 토끼 수인은 기존 24×32 원본 8프레임을 4배 표시합니다. 버튼·폰트 등 UI 파일은 v3와 동일하며 2배 표시를 유지합니다.

모든 테마의 표시 영역은 x=41에서 폭270도트입니다. 1080×1920은 세로480도트, 1080×2400은 세로600도트. 테마별 crop 시작점이 다른 것은 **발 y를 모두 화면1488px**에 맞추기 위해서입니다. 각 테마 판 전체가 5초 동안 x±6/y±4 원본 도트를 이동합니다. 회랑, 건물, 기둥을 별도 속도로 움직이지 마세요. 광선은 각 테마 색상으로 분리된 낮은 알파 레이어입니다.

전환은 순서대로 테마당 5초입니다. 마지막 0.5초에 다음 배경과 크로스페이드하고 UI는 페이드하지 않습니다. 토끼는 8프레임 10FPS로 같은 발 높이를 따라 달립니다. 화면 좌우 방향은 각 구간에서 랜덤으로 정하고 왼쪽이면 FlipX. 크로스페이드 중 토끼는 한 마리만 그립니다. 마지막 오로라→월궁도 같은 방식으로 반복합니다.

`UnityImport/Sprites`의 PNG와 `UnityImport/Fonts`의 OTF를 프로젝트로 가져가세요. Point, Compression None, MipMap Off, PPU32입니다. UI Image/RectTransform은 정수 4배 배경, 정수 4배 토끼, 기존 2배 UI로 명시 배치하세요. Unity CanvasScaler는 현재 1080×1920 Width 기준과 SafeArea를 재사용합니다. 시작 화면은 플레이 버튼만, 모드 선택은 하단 가로 3버튼입니다.

`Previews`에는 테마별 1080×1920 및 1080×2400 스틸, 한눈에 보는 갤러리, 25초 순환을 마친 월궁 첫 프레임까지 담은 25.1초 영상이 있습니다. 정확한 적용 요청은 `CLI_APPLY_PROMPT_KO.md`에 있습니다. **이 맵들은 메뉴용 배경 장면**이며 실제 플레이 스테이지의 타일·장애물·충돌체를 구성한 맵은 포함하지 않습니다. Unity Play 모드/실기기 검증은 아직 진행하지 않았습니다.
