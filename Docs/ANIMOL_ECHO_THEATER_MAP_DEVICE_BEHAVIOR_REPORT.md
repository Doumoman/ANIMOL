# 잔영 극장 맵 장치 동작 로직 보고서

2026-10-28 활성 프로젝트의 `memory_theater` 조합 맵과 `PuzzleDeviceSession` 판정을 기준으로 작성했다. 대상은 `Assets/ANIMOL/Data/Puzzle/Prototypes/memory_theater.asset` 및 연결된 `memory_theater_Scenario.asset`이다. 이 맵은 9×87칸의 **장치 조합 프로토타입**이며, 상용 퍼즐 레벨이나 아트 QA 씬과 동일하지 않다. 표시명은 잔영 극장이지만 시나리오 ID는 `memory_theater`다.

## 고정 클리어 규칙

**방울 3개를 모두 수집한 뒤 출구 칸에 도착하면 승리한다.** 이 맵의 `targetBubbles=3`, 방울 좌표는 `(7,2)`, `(7,42)`, `(7,82)`, 출구는 `(7,82)`, 시작은 `(1,2)`다. 출구와 같은 칸의 마지막 방울은 도착 즉시 수집되고 같은 성공 행동에서 승리를 검사한다. 장치 목표 `scenario.goals`는 빈 목록으로 두어 책장 누름판 방문, 도미노 접기, 유리 파괴, 주사위 일치가 별도 클리어 조건이 되지 않게 했다. 이 장치들은 여전히 길을 열거나 플레이어를 움직이는 실제 판정에 관여한다. 연습용 `Device04` 등 독립 시험 맵의 1방울 규칙은 이 조합 맵의 규칙이 아니다.

`PuzzleDeviceSession.Victory()`는 플레이어가 출구에 있고 `ExitReady`일 때만 승리시킨다. 수집과 방문은 시작 칸 및 실제 이동 도착 칸에서 확정된다. 성공한 직접 입력 1회는 코스트 1과 장치 턴 1회이고, 자동 이동 여러 칸은 추가 코스트가 없다. 막힌 입력은 상태·코스트·장치 턴을 바꾸지 않는다. 이 조합 맵의 `costLimit=0`은 비용 무제한이다. Undo는 성공 행동 전 상태로 되돌리고 Reset은 초기 배치로 돌아간다. 클립 재생은 판정을 확정하지 않는다.

좌표는 `+x=동`, `+y=북`이다. 입력은 상하좌우 한 칸이다. 기본 통행에는 지형, 장식 점유, 장치의 현재 충돌과 지지 여부가 적용된다. 장치 그림의 캔버스 크기만으로 충돌 칸을 늘리지 않는다.

석상 방에는 `6_glass`가 `(4,51)`에 함께 있다. 이는 극장 장치 목록 11종에는 없는 **21 유리 보드 부품**이다. 고체 장벽으로 작용하며 석상의 돌진으로 파괴될 수 있다. 유리 파괴를 방울 수집이나 클리어 확정으로 취급하지 않는다.

## 조합과 상태 순서

입력은 변경 전 보드의 복사본에서 판정한다. 플레이어 이동 시 장치 진입·이탈, 방울 수집, 판 점유 갱신, 자동 이동이 이어진다. 자동 이동은 포털 → 일방향 문 출구 → 도약대 → 제동판 → 무빙워크 → 바람 → 얼음 → 반사판 순으로 판정하며, 이 맵에서는 해당하는 장치만 작동한다. 이어서 코스트가 1 증가하고 셔터·무대·석상·인형 등의 장치 턴을 처리한 뒤 승리를 검사한다. 그 턴의 장치 이동으로 플레이어가 방울에 도착해도 수집 대상이다. 패배가 먼저 확정되면 출구에 있어도 승리하지 않는다.

기존 검증 경로 `verificationRoute`는 개발용 완주 경로이며 게임의 정답 강제 규칙이 아니다. 이 맵은 각 장치를 8행 간격 시험 방에 연결한 구성이다. 새 맵을 만들 때 시각 리소스의 이름이나 프레임 순서로 장치 판정을 새로 정의하지 않는다. `PuzzleScenario`의 `role`, `variant`, `group`, `position`, `direction`, `orientation`, `number`, `cells`와 `PuzzleDeviceSession`의 상태 전이가 기준이다.

## 검증 기준과 범위

- 극장 조합 맵에서 `targetBubbles=3`, 방울 좌표 3개가 서로 다름, `scenario.goals=[]`를 확인한다.
- 검증 경로를 끝까지 실행해 세 방울을 수집하고 출구에서만 승리하는지 확인한다. 세 방울 미만에서는 승리하지 않아야 한다.
- 책장 판 눌림/해제, 셔터 점유, 무대 운반, 도미노 연쇄, 주사위 윗면, 석상 경고·돌진, 인형 후퇴와 막힘을 별도 장치 테스트에서 확인한다.
- V03 카탈로그의 시각 프레임과 실제 Unity 바인딩은 판정과 구분한다. 특히 책장 논리 점유와 원화 슬롯, 누름판·주사위 보조 시각 키는 [V03 적용 결과](ANIMOL_ECHO_THEATER_V03_PROJECT_APPLY_RESULT.md)에 남은 검수 항목이다.
