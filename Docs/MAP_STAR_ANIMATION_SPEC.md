# 별자리 지도 · 비대칭 별과 선택 회전

지도 스테이지 별의 윤곽만 살짝 비대칭으로 다듬고, 플레이어가 선택한 별 몸체만 초당4프레임으로 회전시킨다. 네온 조작·선택 패널·별자리 그림·좌표·입장·다시보기·BM은 유지한다.

## 정적 스프라이트

- 실루엣3종, 기존 Available/Current/Done/Locked4상태, 회전4프레임을 조합한48개 PNG다.
- 경로는 `Map/Stars/Star_{State}_V{0..2}_F{0..3}.png`, 캔버스160×160, 피벗(0.5,0.5), 공통 회전 중심(80,80)이다.
- 각 꼭짓점의 길이와 방향을 조금씩 달리하되 기존 굵은 남색 윤곽·평면 셀 면·상태 팔레트를 유지한다. 외곽선과 손상되지 않은 투명 여백을 확보한다.
- 각 단계의 실루엣은 `stageId` UTF-16 코드 단위 합을3으로 나눈 나머지로 정한다. 새로 열기·스크롤·선택 갱신으로 모양을 다시 뽑지 않는다.
- 기존 `Map/Star_Available/Current/Done/Locked.png`4개는 V0/F0 호환 복사본이다. 새 지도에서는48프레임을 직접 참조한다.

## 재생 규칙

선택한 별의 프레임은 F0→F1→F2→F3 순서로0.25초마다 바뀌고1초에 한 바퀴를 반복한다. 별 Image의 PNG만 교체하며 부모 Transform·위치·크기·색은 움직이지 않는다. 잠금 아이콘·번호·선택 테두리·연결선은 정지한다. 선택되지 않은109개 별은 항상F0이다.

명시적인 별 선택과 지도 선택 패널이 있을 때만 회전한다. 새 별을 선택하면 이전 별은F0, 새 별도F0부터 시작한다. 지도 진입 전 기본 선택값만으로 회전하지 않는다. 지도 퇴장·선택 해제·모달 표시·앱 비활성/포커스 이탈·접근성 움직임 감소에서는F0으로 정착한다. 다시 재생할 때도F0부터 새 위상을 시작한다. UI 시계는 unscaled time을 쓰고 지갑의1초 갱신과 분리한다. 별110개 각각의 코루틴을 만들지 않는다.

선택된 잠금·클리어 별도 해당 상태의 색을 유지해 회전한다. 회전이 입장 권한이나 스토리 다시보기 활성 조건을 바꾸지 않는다. 회전 후에도 별 중심은 기존 catalog의 별자리 정점과 일치한다.

## 적용과 검증

`MAP_STAR_ANIMATION_APPLY_COMMAND.txt`에 따라 현재 지도만 갱신한다. 원본 그림32종·스테이지110개(20/30/30/30)·catalog·별선·NightSky·MapNeon·얼굴 패턴·메인/설정/인게임 자산과 BM은 바꾸지 않는다.

정적 PNG의 크기·해시·피벗·투명 여백과4프레임 구별,3종 모양의 안정 배정, 선택1개만4fps재생, 포커스/모달/화면/접근성 전환의F0 복귀를 검사한다. 실제 Unity Import·C# 컴파일·Play Mode·Prefab Stage·Undo 실행은 이번 환경에서 수행하지 않았다.
