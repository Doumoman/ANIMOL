# 별자리 그림 32종의 모티프와 게임 해석

이 문서는 제작용 메타데이터다. 아래의 별자리 이름·설명은 플레이어의 지도 화면에 표시하지 않는다. 테마별 8종, 총 32종을 배치하며 기존 스테이지 개수 20·30·30·30과는 별개의 단위다.

표의 **모티프**는 IAU의 대표 대상 표를 확인해 한국어로 설명한 것이다. **게임에서 부여한 의미**는 이번 작품을 위한 창작 제안이다. 인물의 성별·의상·성격과 각 테마의 서사 해석을 원전 신화의 사실처럼 설명하지 않는다. [IAU 자료][iau]

IAU의 공식 별자리는 하늘의 영역과 경계다. 별 연결선이나 인물 그림의 형태는 하나의 공식 도안으로 고정되지 않으므로, 여기서는 모티프를 살린 그림과 플레이용 별 배치를 사용한다. 실제 천구 좌표를 재현한 과학 성도는 아니다. [IAU 자료][iau] [NASA 용어집][nasa]

## 별너울 해안 — 항해·동행·헤어짐·귀환

| 자산 ID / 별자리 | 확인한 모티프 | 게임에서 부여한 의미 |
|---|---|---|
| `delphinus` / Delphinus | 돌고래 | 낯선 바다에서도 혼자가 아니라는 동행을 뜻한다. |
| `cetus` / Cetus | 바다 괴물 | 수평선 너머를 상상할 때 커지는 미지의 불안을 뜻한다. |
| `pisces` / Pisces | 물고기들 | 다른 방향으로 흘러가도 끊어지지 않는 인연을 뜻한다. |
| `aquarius` / Aquarius | 물을 나르는 이 | 떠나기 전에 누군가에게 남기는 작은 온기를 뜻한다. |
| `eridanus` / Eridanus | 강 | 헤어짐을 지나 결국 다시 이어지는 흐름을 뜻한다. |
| `carina` / Carina | 배의 용골 | 기억을 싣고 항해를 버티게 하는 보이지 않는 중심을 뜻한다. |
| `puppis` / Puppis | 배의 선미 | 뒤에 남겨 둔 이를 돌아보는 마지막 시선을 뜻한다. |

Sagitta의 확인된 모티프는 **화살**이다. 활을 든 인물로 표현하는 경우 그 인물은 화살을 의인화한 창작 표현이며, 별자리의 공식 대상이 궁수라고 설명하지 않는다. Cetus는 이 문서에서 단순한 현실의 고래로 단정하지 않고 IAU의 바다 괴물 모티프를 따른다.

## 표현과 배치 원칙

- 새 인물·동물·소품 그림은 정적 투명 PNG로 제공한다. 그림을 임의의 게임 캐릭터로 치환하지 않는다.
- 그림의 손·발·꼬리·날개·돛이 잘리지 않게 포함하고, 별과 연결선은 그림보다 앞에 배치한다.
- 밤하늘과 그림 자체의 색은 고정한다. 별자리 이름을 설명하는 추가 팝업이나 별도 선택 화면을 만들지 않는다.
- 이 선택은 IAU 88개 전체의 목록이 아니라, 네 테마에 배치한 32개 모티프의 선별 목록이다.
