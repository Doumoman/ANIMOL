실제 저장·에디터 경로
CampaignMapEditorWindow → 원본 썸네일 패널 → AnimolTerrainMapEditorBridge
→ StageMapDefinition.ReadTerrain → AnimolTerrainPlacementEngine
→ StageTerrainStructureIntegration.Write → 기존 StageMapObjectAuthoringOperations의
  footprint/path/overlap 검증(폐기 가능한 candidate clone에서 실행)
→ StageMapDefinition.EditorApplyTerrainCandidate.
기존 StageMapBackupService로 변경 전 백업, 한 map asset/Undo group에 transaction 기록.
변경 없는 일반 셀의 tileId/variant와 객체는 그대로 유지한다.
candidate당 authoring revision 1회 증가, derived collision revision -1로 무효화.
changed는 기존 workspace preview 갱신만 예약하며 정본/revision을 다시 변경하지 않는다.
프리뷰 callback 실패 시 Undo 복원 후 저장 파일도 다시 저장하여 메모리/디스크 상태를 복구한다.
기존 일반 브러시는 EditorSetCell/EditorEraseCell의 소유권 guard를 거친다.
#셀 부분 삭제/덮어쓰기는 거부, .셀 일반 지형 배치는 허용한다.
받침 상실 장식은 일반 셀 수정 transaction에서 함께 제거한다.
구조물이 걸친 청크 축소는 완성 instance 이동/삭제를 먼저 하도록 거부한다.

실제 런타임 경로
CampaignRuntimeBootstrap → StageMapRuntimeLoader.Load → Engine.Resolve
→ StageTerrainStructureRuntime → 기존 operational Terrain TilemapCollider2D.
완성 아트에는 Collider가 없고 #만 Grid collider tile로 합친다. .에는 새 충돌이 없다.
frameId로 SourceFrame을 찾아 원본 Sprite/Material, art child offset/균등배율을 적용한다.
구조/일반 terrain/장식 sorting order는 10/20/30. 기존 workspace는 같은 상대 순서 5/10/15.
맵 전역 instance 사전과 GetCoveredChunks로 전체 그림 범위의 모든 16셀청크를 색인한다.
원점 청크를 숨겨도 다른 청크가 보이면 같은 완성 instance를 유지한다.

기존 M9 Save + Local Play는 회색 박스 충돌을 굽고 loader에 Terrain Tilemap을 연결하지 않았다.
이 경우 operational loader가 Grid/Tilemap을 소유하도록 보완했다. 정확한 M9 생성 root와
segment 이름에 해당하는 기존 지형만 비활성화하여 중복 충돌을 없앤다. 기존 일방통행 ID는
별도 Tilemap/PlatformEffector2D를 유지한다. legacy-only 맵 로드 시 기존 회색 지형을 복원한다.
패키지 MapPreview는 별도 additive 진단 씬이며 운영 loader/물리 owner가 아니다.
StageMapRuntimeFactory의 기존 객체 Configure/reset 경로를 읽고 그대로 유지했다.

저장 schema와 호환성
StageMapDefinition에 terrainPlacements: AnimolTerrainPlacementCollection(schemaVersion=3) 추가.
instanceId/catalogId/catalogVersion/maskHash/themeId/styleId/x/y/orientation=None 저장.
기존 cells/objects 필드와 9방향 enum은 대체하지 않는다. placement를 content hash에 포함하고
변경 시 기존 human completion review를 무효화한다. 보상/Ready 성공을 연출하거나 부여하지 않는다.

Resources/ANIMOL_TerrainStructureRegistry는 정본 JSON과 frame asset 참조 및 명시적인
tileId/variant 대응표다. 기존 registry의 정확한 ID/variant 및 알려진 DEV/M9 ID를 Txx_A
호환 스타일로 등록한다. 새 B/C/D 일반 셀 선택은 Txx_B/C/D@CENTER variant로 명시한다.
대응 없는 variant를 기본 스타일로 추측하거나 누락하지 않고 오류로 표시한다.
현재 campaign map 8개를 read adapter로 읽었으며 모두 대응표 검증을 통과했다.
기존 호스트에는 구조물 소유 셀의 직렬화 캐시가 없다. base/owner 충돌은 손상으로 거부한다.
hash/version/schema/orientation/theme/duplicated instanceId 오류는 자동 복구하지 않는다.
알 수 없는 object type/dataKey 및 settings version 999를 포함한 기존 객체 전체 직렬화가
terrain transaction에서 보존되는 것을 검증했다. 소스에 없는 raw-JSON 필드를 추측해 추가하지 않았다.
Unity가 읽지 못하는 임의의 미래 필드까지 보존한다고 주장하지 않는다.
