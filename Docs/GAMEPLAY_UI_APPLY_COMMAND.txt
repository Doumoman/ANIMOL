현재 Unity 프로젝트의 실제 플레이 씬에 최초 고리형 HUD, 우하단 새 망원경 재시작, 패널 안 얼굴 스크롤링 팝업을 연결해줘.

먼저 현재 활성 Scene/Prefab/Bootstrap, 코스트·수집·출구/클리어·정지·재시작·다음 입장·망원경 원장 소유 코드를 읽어줘. UI 생성기만 실행하고 현재 게임에 적용됐다고 보고하지 마.

1. 기존 게임과 원본을 보존해.
   메인·별자리 그림32종·스테이지110개·별자리 좌표·기존 캐릭터 얼굴 스크롤링 원본·월드 별4프레임·맵·캐릭터·장치·카메라·충돌·이동·저장·기존 BM은 다시 만들지 마. 현재 목표1~4개와 실제 수집 판정을 연결해. Preview/GameplayCleanReference.png는 배치 미리보기용이므로 실제 맵에 적용하지 마.

2. 숫자·별·일시정지를 최초 고리 디자인으로 되돌려.
   좌하단 Gameplay/CostMedallion은 보존된 최초 고리 원본이야. 1080기준 왼쪽24·아래24,300×300으로 표시해. 숫자0~9는 갈무리14의 단색 크림 개별 PNG를 NotebookSpriteNumber.SetNumber(int)로 조합해 왼쪽84·아래126,180×96에 맞춰. 최대 글리프 높이는96, 간격은3이야. 두꺼운 검은 테두리·입체 베벨·외부 그림자·COST 제목을 넣지 마.
   우상단은600×144 묶음을 Safe Area 오른쪽24·위24에 고정해. 별 홈432×144는 내부X0, 일시정지144×144는 내부X456이야. 1080기준 각각X456/912야. 목표1~4개별 StarDock_{required}_{filled}14상태와 크림 PauseGlyph를 쓰고 HUD 수집 분수는 숨겨.
   망원경 재시작 버튼은 우상단에서 빼고 Safe Area 오른쪽24·아래24의264×264로 독립 배치해. TelescopeRetry_0..5/Pressed_0..5는 새 망원경·되감기 궤도·컬러와 흑백5구간을 담은 PNG야. 기존5회 승인 계약을 그대로 사용해.
   HUD 자산은 White Tint, Sprite Single/Full Rect, Bilinear, Mipmap Off, 압축 없음, PPU100, 중앙 피벗, Border0으로 표시해. 팝업 전용 Modal/PanelBase·PanelFrame·Primary_*·Button_*·Utility_*만 Border36의9-slice를 써. 노트 줄·접힌 귀·찢어진 종이 질감은 팝업에서 제거하고 기존 메인/지도 자산은 유지해.

3. 모서리 배치와 활성 프리팹을 갱신해.
   ANIMOL > New Notebook UI > Build Gameplay Overlay Prefab으로 GameplayCanvas.prefab과 CollectibleStarVisual.prefab을 다시 생성해. 실제 플레이 씬에 새 Canvas를 하나만 연결해. 현재 씬에 추가할 때는 Create Gameplay Overlay In Current Scene을 쓰고 메인용 Build Fresh Scene으로 퍼즐 씬을 덮지 마.
   예전 상단 바·코스트 문구·TMP 숫자·일시정지 안 재시작 버튼·클리어 모은 별/완료 엠블럼/재시작 버튼은 해당 UI 범위에서 제거하거나 비활성화해. 다른 게임 오브젝트·메뉴·EventSystem을 지우지 마. PNG만 복사하면 옛 UI가 남으므로 실제 Canvas/Prefab 참조와 초기화 루트까지 바꿔.
   NotebookGameplayCanvasLayout을 사용해 실제 Safe Area 가로·세로에 대응해. HeaderReservedHeight는0이고 상단224픽셀 예약을 남기지 마. TopRightHUDScreenRect·CostHUDScreenRect·RestartHUDScreenRect·IsScreenPointOverHud로 실제 세 모서리만 기존 입력과 대조해. 카메라/맵에 빈 상단 띠를 만들지 마.

4. 전체 화면 막과 팝업 안 얼굴 패턴을 분리해.
   물리 화면 전체에는 #28282C·불투명도0.58의 회색 반투명 막만 표시해. 어두운 전체 화면 얼굴 스크롤링은 없애고 실제 뒤 메인/게임 화면은 비치게 해.
   설정·일시정지·클리어와 일반 팝업의 패널 내부에만 기존 얼굴 스크롤링을 넣어. Modal/PanelBase→안쪽24픽셀로 클리핑한 패턴→Modal/PanelFrame→글자·버튼 순서야. 패턴은 패널 밖으로 새지 않아야 하고 노트 선·접힌 귀·종이 질감은 사용하지 마.
   Assets/ANIMOL/UI/Pattern/Textures/CharacterFacesStars_All_2048.png와 원본 셰이더·모션 코드는 그대로 사용해. 얼굴·별·배치·PNG 바이트를 재생성/수정하지 마. 잉크색 #A66E48,불투명도0.16,타일1080,대각선 속도8·8,unscaled time을 유지해. 설정 화면에는 얼굴 스크롤 켜기/끄기 항목을 만들지 마. 얼굴 배경은 기본으로 스크롤하며 예전 저장값 scroll:false는 더 이상 정지 조건으로 쓰지 마. SetPatternScrolling(bool)은 내부 호환 API로만 유지하고 사용자 설정과 연결하지 마. SetReducedMotion(bool)은 기존 접근성 연출 감소에만 연결해.
   설정 뒤 메인은 표시만 유지하고 입력·포커스를 차단해. 설정이 열린 동안 기존 전역 얼굴 패턴은 숨겨 팝업 밖 움직이는 얼굴이 남지 않게 하고 복귀 시 원래 상태로 돌려.
   클리어에는 성공 여부·스테이지명·다음/지도만 보여줘. 모은 별·별점·엠블럼·보상·재시작은 표시하지 마. 일시정지에는 계속하기와 지도만 두고 재시작은 우하단 망원경에서 처리해.

5. 실제 코스트·수집·출구 판정을 이어 써.
   BeginStage(actualStageId,actualStageLabel,currentCost,collectedStars,requiredStars)와 SetCost를 기존 스테이지 초기화·재시작·확정 코스트 이벤트에 연결해. 유효 이동/밀기의 소모,막힌 입력의 미소모는 기존 게임이 처리하고 HUD는 별도 계산/차감하지 마.
   승인된 고유 수집ID·화면/월드 위치·확정 수집 수를 ConfirmStarCollected/ConfirmWorldStarCollected에 전달해. 월드 별을 한 번만 숨기고 실제 채워질 별 홈으로 비행한 뒤 StarDock 상태를 바꿔. 기존 노란 별4프레임(0.25초 간격,1초 주기),0.44초 비행과 중복 방지를 유지해.
   목표1~4개와 출구 도착이 기존 게임에서 클리어로 확정된 이벤트에만 ShowVerifiedClear를 호출해. 팝업에서 모은 별을 숨기더라도 판정 조건은 없애지 마. 기존 클리어 저장·대전 해금·별자리 진행 소유권을 유지해.

6. 재시작용5칸 망원경을 실제 원장에 연결해.
   사용자가 확정한 것은 재시작5회분과 승인된 재시작1회당1칸 감소야. 보충/초기화/전역 망원경 변환 정책은 아직 제공되지 않았으니 임의로 만들지 마.
   `NotebookGameplayRetryGaugeSnapshot{sessionId,remaining,revision}`를 `SynchronizeRetryGauge(snapshot)`로 전달해. `NotebookGameplayGateway.RequestRestart(currentStageId,sessionId,expectedRevision,operationId,completed)`의 응답은 `NotebookGameplayRestartApproval{approved,operationId,sessionId,remaining,revision}`야. 재시작 요청에는 현재 스테이지·세션·예상 리비전·고유 작업ID를 담고 승인 응답의 같은 세션/작업ID·새 리비전·이전보다1적은 남은 횟수를 검증해 표시한 뒤 기존 로더를 한 번 호출해. 거절·취소·실패·중복 콜백은 추가 차감하거나 로드하지 마. UI에서 remaining을 다시1빼지 말고 호스트가 확정한 결과를 복사해. 호스트가 콜백보다 먼저 같은 확정 스냅샷을 알린 경우도 같은 승인으로 처리하되 더 최신 잔량을 과거 응답으로 되돌리지 마. 공급자가 없으면 미연결로 보고하고 승인처럼 처리하지 마.
   BeginStage/재시작으로 게이지를 자동5칸 채우지 마. BeginStage 후에는 실제 서비스의 명시적인 SynchronizeRetryGauge 스냅샷으로만 재시작을 활성화해. 재시작 후 같은 원장의 스냅샷을 다시 연결해. 0칸·스냅샷 미연결·요청 중에는 직접 재시작 버튼을 비활성화해. TelescopeRetry_0..5와 같은 횟수의 Pressed PNG로 컬러/미충전 흑백을 표현해.
   기존 캠페인 망원경 최대10개·180초당1개·검증된 광고+5,유료 지역·대전 해금은 유지해. 재시작 UI가 전역 원장을 다시 차감하거나 새로운 광고/보충 상품을 추가하면 안 돼. 서비스가 두 체계를 연결할 경우 단일 승인 파이프라인에서 한 번만 처리해. 재시작·클리어·스테이지 이동의 동시 요청도 원장 소유 서비스에서 조정해 이미 끝난 단계에 늦은 소모가 남지 않게 해.

7. 실제 실행을 확인해.
   최초 고리와 단색 숫자0..9 및 여러 자리 값,별 홈14상태,망원경0..5상태,재시작5→4 승인·거절·취소·중복·빠른 두 번 누름·재시작 후 같은 잔량·세션/리비전 불일치·0칸 비활성화를 확인해. 수집 중 재시작/출구,일시정지·비활성화,감소된 움직임에서도 과거 비행·팝업·게이지가 되살아나지 않아야 해.
   얼굴 스크롤링은 설정/일시정지·클리어·일반 팝업 패널 안에서만 보여야 하고 원본 PNG 해시가 일치해야 해. 전체 회색 막의 #28282C/0.58을 확인하고 패널 밖에는 움직이는 얼굴이 없으며 뒤 메인/게임 화면은 실제로 비쳐야 해. 설정에서 뒤 화면 버튼을 누르거나 포커스할 수 없어야 하며 복귀 후에는 입력이 돌아와야 해. 클리어에는 수집 개수/별 엠블럼이 없어야 해. 360×640,390×844,445×773,노치 Safe Area,1440×900에서 받침·숫자·별·망원경·일시정지와 팝업이 잘리지 않아야 해.
   Unity Import→C#컴파일→PlayMode를 실행하고 같은 상태의 미리보기와 실제 게임을 비교해. 실제 수정한 Scene/Prefab·끊은 옛 UI 위치·연결한 권위 이벤트·원장 소유자·미연결 서비스·미실행 검증을 구분해 보고해. 생성기와 동작 미리보기만으로 현재 게임 적용 완료라고 부르지 마.
