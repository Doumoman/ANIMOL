ANIMOL 별길 목장 V12

이번 수정은 별길 목장의 방향별 장치, 실제 애니메이션 프레임, 따라오는 병아리와 풍차를 대상으로 한다.
잔영 극장 및 다른 두 테마의 스프라이트는 수정하지 않았다.

V11에서 확인된 누락
장치 원화는 9개 아트 계열의 정적 상태 18장뿐이었다. 병아리는 정면 1장뿐이었으며, Runtime은
지형/배경 5개 클래스였다. 실제 장치 애니메이션·네 방향 추종 원화·검증된 프로젝트 바인딩은 없었다.
V12는 이 누락을 원화·프레임 시퀀스·시각 재생기·Unity 생성기·구체적인 이관 지침으로 보완한다.

새 외형
병아리: 실제 동서남북 원화와 idle/walk. 북쪽은 뒷모습이며 보이는 눈에는 흰 광채를 유지한다.
무빙워크·단방향 문·바람 통로: 진행 축에 맞는 네 방향 구조와 프레임 시퀀스.
튕김 모서리: 중앙 통로가 열린 날씬한 ㄴ과45도 작동면. 네 모서리의 접촉/반동/복귀.
제동판: 두 진입 축에 맞는 두 정지선. 운반 화살표를 사용하지 않고 눌림과 정지를 표현한다.
별돌/홈: 전체가 오각별인 돌과 바닥에 맞물리는 중간 프레임·낮은 완료 바닥.
누름판/덩굴 다리: 눌림과 펼침·수축. 가로/세로 전용 원화를 구분한다.
풍차: 고정 목재 몸체와 정확한 중심의 대칭 네 날개를 분리한다. 로터만 회전한다.
굵은 남색 외곽선, 넓은 단색 면과 각진 셀 음영을 유지한다. 픽셀·16색 제약을 적용하지 않는다.

최신 원화만 쓰기
animation_catalog.json은 방향/상태/프레임의 유일한 시각 목록이다. manifest.json은 승인된 지형,
배경, 소품과 프레임의 전체 목록이다. V11과 바이트가 같은 승인된 지형은 V12 최신 집합의 일부다.
낡은 폴더의 이미지를 찾는 fallback은 금지한다. 예전 상태 경로를 보존한 endpoint alias도 모두
V12의 새 프레임으로 덮으며, 병아리 front 하나를 나머지 방향의 대체물로 쓰지 않는다.
원 프로젝트의 GUID/fileID·씬·프리팹·카탈로그·클립·Resources·Addressables·풀/캐시·스포너까지
모두 추적하여 바꾸는 실제 작업은 UNITY_APPLY_PROMPT_KO.txt의 지시대로 수행해야 한다.

Unity 적용
스프라이트 임포트 값은 sprite_import_settings.json/정확한 V12 임포터가 기준이다. .meta/GUID를
일괄 삭제하지 않는다. 실제 프로젝트에서 Editor 생성기를 실행해 .asset/.anim을 생성한 뒤
기존 확정된 행동·방향·장치 상태 이벤트에 연결한다. 새 시각 재생기는 시뮬레이션을 진행하지 않는다.
현재 제공물에는 기존 프로젝트용 enum/GUID/씬 경로를 지어 넣지 않았다. device_bindings_template.json을
실제 프로젝트 증거로 채우고 required_gameplay_checks.json의 NOT_RUN 항목을 실제로 검증해야 한다.

보존 사항
병아리 표시 배율 .62는 visual 자식에 한 번만 적용한다. 논리 루트·코스트·추종·점유는 변경하지 않는다.
장치/다리 아트 슬롯을 실제 점유로 덮어쓰지 않는다. G/W/S 및8이웃·하부·다리 연결·독립 풀·거의
고정된 별과 움직이는 구름·섬·달/행성 없는 배경은 기존 승인 상태를 유지한다.
무효 입력은 장치 턴/애니메이션을 시작하지 않고 자동 이동 연쇄에 추가 코스트를 붙이지 않는다.
다른 문양 홈·수축 중 다리 탑승자·병아리 포털/배/둥지의 미확정 규칙은 새로 확정하지 않는다.

검증 경계
PNG/프레임/방향/메타데이터/합성 재생 검수와 실제 Unity 프로젝트 검증을 구분한다.
이 환경에는 원 Unity 프로젝트와 컴파일러가 없으므로 Unity import/compile/Play Mode/모바일
실행 및 실제 프로젝트의 레거시 참조0은 아직 확인하지 않았다. 합성 영상은 Unity 녹화가 아니다.
동봉 C#은 연결용 구현 소스이며 실제 프로젝트에서 컴파일하고 어댑터를 검증해야 한다.

최종 제공 수량
전체 런타임 PNG1945장(승인된 기존 지형·배경·소품 포함), 방향/동작 고유 프레임127장,
프레임 재생 정의46개, 풍차 부품2장. animation catalog 직접 Sprite 참조129개만 포함하여
정적 지형 전체가 장치 카탈로그를 통해 일괄 로드되지 않도록 했다.
걷기12fps, 다른 동작10~12fps. 정적 idle은 단일 이미지이며 가짜 애니메이션으로 세지 않는다.
생성기는 실제 Unity에서46개 .anim과1개 카탈로그 .asset을 만들어야 하며, 이 환경에서
이미 생성·씬 연결·실행 검증을 끝냈다는 뜻은 아니다.
