ANIMOL 잔영 극장 — 한 타일 셔터 수정 패키지 V01

기존 셔터의 가로2×1/세로1×2 아트 규격을 두 방향 모두1×1 시각 규격으로 바꾼다.
붉은 벨벳 커튼,금색 기둥,가면 장식,굵은 네이비 윤곽선과 각진 셀 셰이딩을 계승했다.
새 원화는 내장 이미지 제작 도구로 만들고,코드는 동일비율 축소/중앙 정렬/고정 틀 등록만 수행했다.
원화 RGB를 다시 그리거나 프레임마다 크기를 달리하지 않는다.

Sprites/horizontal/frame_00~03.png: 가로형 닫힘→열림4프레임.
Sprites/vertical/frame_00~03.png: 세로형 닫힘→열림4프레임.
각 폴더 closed.png/open.png: 실제0/3프레임과 바이트가 같은 정지 별칭.
모두256×256 RGBA,PPU256,중앙Pivot,1×1캔버스. 장식과 가장자리 여백도 타일 안에 들어간다.
H/V의 세부 비율은 유지하며,빈 공간을 채우려고 가로·세로를 서로 다르게 늘리지 않는다.
같은 방향의 금색 기둥/가면/외곽은0프레임으로 고정한다. 커튼 내부 창만 움직인다.
기존10fps,열림4프레임과 역순 닫힘을 유지한다. 기본 길이는.4초이며 기존 호스트의 연출 시간을 우선한다.

이 패키지는 셔터 전용이다. 원래V03 전체 패키지/글로벌 카탈로그를 덮어쓰지 않는다.
Runtime/의 새 View/Art를 셔터에만 연결하거나,동일 규격8프레임을 기존 셔터 전용 시각 재생기에 바인딩한다.
기존2칸 아트에 맞춘시각 스케일/2×1 logicalRect 확장은 제거하고 실제 월드1칸 크기로 표시한다.
콜라이더/점유/유효 행동 후 교대/점유 중 닫힘 보류/Undo/Reset 등 실제 게임 규칙은 호스트가 계속 소유한다.
한 타일 아트 요청은 새로운 충돌 규칙이나 셔터 위상 규칙 변경을 의미하지 않는다.

UNITY_APPLY_KO.txt에 적용 명령과 코드 예시가 있다.
Preview/OVERVIEW.png와ONE_TILE_SHUTTER.gif는 한 타일 경계를 보여주는 오프라인 검수본이다.
실제 Unity 프로젝트가 없어 C#컴파일/임포트/카탈로그 바인딩/플레이는 NOT_RUN이다.
