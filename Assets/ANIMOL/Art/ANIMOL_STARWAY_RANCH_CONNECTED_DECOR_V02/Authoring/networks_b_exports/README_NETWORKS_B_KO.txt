별길 목장 연결 장식 V02 — 신규 연결 장식 3종

orchard_trellis(과수원 연결 격자), herb_planter_strip(허브 화분 띠), ranch_lantern_strip(목장 발치등 띠).
각16이웃 마스크이며 총48개 런타임 PNG다. 마스크48개를 장식48종으로 세지 않는다.
모두 새 built-in imagegen 원화에서 제작했으며 다른 테마의 이미지를 재색칠한 것이 아니다.
원본 PNG3장과 실제 전체 생성 프롬프트, 크롭/등록/포트 제작 코드 및 출처를 포함한다.

Ranch 전용 등록
320×320, logicalRect=[32,32,256,256], PPU256, Unity pivot=[0.5,0.5].
최근 해안/극장 등의320×384 등록을 그대로 쓰지 않는다. N1 E2 S4 W8, 월드+Y 북쪽.
세 계열 모두16상태다. 256상태 raised_flower_meadow는 별도 제작자에서 병합한다.
이 세 계열에는 periodic_post.png를 추가하지 않는다.

native 조립
독립H/V띠와 중앙 연결체를 새 원화에서 잘라 균일하게 등록한다. RGB를 다시 칠하지 않는다.
알파128 본체+2px 원래 AA 프린지만 유지하고, 근불투명 알파245이상은255로 정규화한다.
8미만 알파 잡티를 지우며 RGB 컬러 키/팔레트 양자화/비균일 스트레칭을 쓰지 않는다.
같은 native 단면을 양끝12px에 등록해 접합 프로파일을 일치시킨다.
4px 외부 bleed는 동일RGB의 완전 불투명 부분만 공유하고 반투명 외곽은 반열린 셀 영역이 소유한다.
가로/세로 긴 직선에는 중앙 연결체를 매 칸 넣지 않는다. 실제 끝·꺾임·T·십자에서만 공유한다.

검수
각 계열128쌍, 총384개 호환 native포트쌍 RGBA 일치, 부적절한 겹침0.
48개 전부PNG 로딩 및16상태별 decodedRGBA 구별, 전체 마스크와 연결 예시 육안 확인.
CPU축소 합성210경우 측정: Bilinear의 불투명 중심 alpha손실0, Lanczos에서 최대3/255 차이.
AA외곽과 투명 RGB 차이를 전역RGBA동일성/GPU무봉제로 주장하지 않는다.
실제 UnityImport/C#Compile/씬 바인딩/Play는 NOT_RUN이다. 장식은 게임 충돌이나 새장치가 아니다.
