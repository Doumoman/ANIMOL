별길 목장 연결 장식 V02 — 배경 합성 참고도

RANCH_SCENE_CONTEXT.png는 새26종 장식과 기존 목장 V12의 하늘·별·구름·원경 섬·잔디 바닥·하부 마감을 조합한 오프라인 참고도다. 실제 Unity 화면이나 실행 캡처가 아니다.

새 스프라이트의 exactmanifest pin, PPU256, logicalRect와 지면 중심 pivot, +Y북쪽 좌표를 따랐다. 검사 보드는65연결칸+20묶음/한칸소품=120점유이며, 보조기둥4개와 시드 꽃6개가 같은 칸 위에 추가된다. 장식 종류는26종이며362마스크/보조PNG를 종류로 세지 않는다.

입체 잔디는 RAW8방향256상태와n000~n255 경로를 사용하고, 다른5계열은4방향16상태를 사용한다. 꽃은 월드XY를 포함한 StableHash%5==0,변형=(hash/5)%4로 골랐다. 별도 꽃/기둥 점유는 없다. 부모 기술 참고도 선택기와95개파일·위치·정렬값이 일치한다.

기존455잔디칸과6개 내부 빈칸은 장식 배치가 보이도록 만든 검사전용 지형이다. 실제 게임 맵/세이브/통행/충돌 규칙을 생성하거나 변경하지 않는다. 다칸 그룹당하나의 전체그림을 배치했고, 모든120점유가 지면에 들어간다.

하부는 기존 V12의 순수 EdgeSelector 방식을 참고해1~4칸 한몸 마감, 긴잔디 구간의 결정적 간격 몸체, 모든노출칸의 얕은collar를 선택했다. 안쪽잔디 구멍에는깊은몸체를 두지 않는다. 별은모든구름뒤이며 달·행성·해가 없다. 기존배경풍차섬은원경이며 실제작동풍차·병아리·장치·옛소품은 전경에 넣지 않았다.

출력1600×3000,64px/논리1칸의26종전체개요다. 실제게임의카메라확대율이나플레이중화면을보여주는자료가아니다. 배경/바닥/하부원본PNG는새런타임팩으로복사하지않았고,새런타임원화도재색칠/비균등늘리기하지않았다.정확한입력파일SHA/좌표/선택은context_provenance.json과context_layout.json을따른다.
