별길 목장 연결 장식 V02 — 핵심 연결 3종

크림 울타리·목초지 돌담·입체 화단 3종을 새 내장 이미지 생성 원화로 다시 제작했다.
전체 294 PNG: 울타리16+기둥1, 돌담16+기둥1, 화단 raw8-neighbor256+꽃 보조4.
4개의 원화와 모든 생성 프롬프트/등록 좌표/제작 코드/오프라인 검수 이미지를 포함한다.
기존 V01의 대응294경로를 보존했으며 실제 decoded RGBA가 모두 달라졌음을 비교했다.

모든 연결 그림은320×320, 지면[32,32,256,256], PPU256, pivot[.5,.5]이다.
입체 화단의 상·하부 잎 띠는58~60px 높이의 새 native 쐐기 잎으로 뚜렷하게 보강했다.
5상태 또는47상태로 줄이지 않고 N1 NE2 E4 SE8 S16 SW32 W64 NW128의256상태를 제공한다.
내부 구멍·대각 접촉·2/3/4칸·긴 영역에서 하나의 영역처럼 이어지고 내부 칸의 테두리는 그리지 않는다.
꽃4개는 기존 화단 칸 위에만 놓는 보조 원화이며 장식 종류/점유를 추가하지 않는다.
선택 기준과 안정된 해시/기둥 간격은 실제 V02 Planner/호스트 데이터를 따른다.

RGB를 칠하거나 다른 테마를 재색칠하지 않았다. native crop/균일 등록/단면 반복/레이어 합성과
alpha 지지영역 정리만 사용한다. 완전 불투명한 동일RGBA 지지 패딩만 중복 허용하고,
반투명 fringe는 가까운 실제 칸 하나가 소유해 중복 블렌딩을 피한다.

cardinal256접속쌍 및 meadow2048로컬일관접속쌍의 원화 접합을 검사했다.
같은 native 전체 영역과 실제 개별 PNG 합성 간 RGBA가 일치하고 비안전 중복이 없어야 한다.
CPU 축소 검수는 실제 Unity/GPU 캡처가 아니다. 실제 Import/C#컴파일/Play는 NOT_RUN이다.
