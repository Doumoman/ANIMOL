ANIMOL 별길 목장 — 장치 규칙 / V13
최신 대화 우선. PDF의 옛 누름판·덩굴 다리와 한 칸 바람 규칙은 사용하지 않는다.

[확정]
목표: 비눗방울 3개 수집 후 출구 도착.
유효한 스와이프·밀기 1회 = 코스트 1, 장치 턴 1회.
아무 변화도 없는 막힌 입력 = 코스트 0, 장치 턴 0회.
한 행동에 이어지는 자동 이동·연쇄·추종 = 추가 코스트 0.
실시간 애니메이션 재생 시간은 장치 턴과 무관하다.

01 별돌 끼움홈
- triangle / diamond / cross는 아트 문양 키이며 새 공식 장치 ID가 아니다.
- 같은 문양의 별돌만 해당 홈으로 들어간다. 도착하면 통과 가능한 별 바닥이 된다.
- 다른 문양의 홈에는 진입·소모·교환하지 않는다. 밀기를 거절하고 reject 표시만 한다.
- 아무 상태 변화가 없으면 코스트와 턴은 0이다.

목장 수문 — 새 공식 ID 미부여
- 고정 본체의 논리 점유는 가로 2×1. 본체를 타일마다 두 번 생성하거나 1×1로 축소하지 않는다.
- 물꼬 손잡이를 한 칸 밀어 두 위치를 전환한다. 두 수로 A/B의 마른 통행길·물이 찬 막힌 길이 교환된다.
- 다시 밀면 원래 상태로 돌아간다. 수로 전체 면적은 2×1 본체와 별도 데이터다.
- 움직이는 것은 손잡이/물꼬의 표현이다. 수문 전체 루트를 한 칸 옮기는 일반 상자로 만들지 않는다.
- 수문을 지난 병아리는 실제 통과를 마친 그 위치에서 멈춘다. 입구로 되돌리거나 반대편으로 순간이동시키지 않는다.

20 바람개비 / 바람 통로
- 플레이어의 밀기 상호작용으로 제자리에서 꺼짐→3칸→6칸→9칸→꺼짐 순환. 제자리 상태 변화도 유효한 한 수다.
- 본체 좌표는 고정. 회전 날개와 3칸 단위 표시만 변경한다.
- 플레이어·가벼운 나무상자·별양·병아리는 바람 끝 또는 이동 불가 칸 직전까지 자동 이동한다.
- 금속 상자는 바람에 이동하지 않고 그 뒤 바람을 차단한다.
- 바닥 화살표와 끝마개는 설정 최대치가 아닌 실제로 도달 가능한 범위를 표시한다.
- 표시창의 밝은 삼각 표식 0/1/2/3개는 꺼짐/3/6/9칸에 해당한다. 숫자가 필요하면 기존 UI 글꼴로 표시한다.

24 따라오는 병아리 + 둥지
- 플레이어가 실제로 지난 타일 경로를 따라가며 여러 칸 이동도 경로를 생략하지 않는다.
- 병아리는 플레이어·물체의 통행을 막지 않으며 일반 누름판을 누르지 않는다. 별도 코스트가 없다.
- 바람 이동도 막히지 않는 범위 끝까지 수행한다.
- 병아리 자신이 둥지 칸에 도착하면 추종을 끝내고 앉는다. 플레이어의 둥지 진입만으로 성공시키지 않는다.
- 수문 통과 후에는 통과 위치에서 waiting_at_sluice로 정지한다.
- 둥지와 병아리를 방울 대체 수집물, 출구 열쇠, 별점으로 자동 연결하지 않는다.
- 둥지는 새 공식 ID가 없다. nest/settled는 비어 있는 둥지의 정착 표현이며, 앉은 병아리는 chick/*/sit로 별도 표시한다.

풀 먹는 별양 — 새 공식 ID 미부여
- 직접 밀기는 한 칸이다. 앞의 키 큰 풀 한 칸을 먹고 그 칸으로 움직인다.
- 먹힌 풀은 영구 통행 바닥. 플레이어는 양의 이전 칸으로 들어간다.
- 보통 바닥에서도 직접 밀기는 한 칸. 바람에 실릴 때는 끝 또는 막힘 직전까지 움직인다.
- 풀줄 끝의 주차 칸·측면 우회로는 맵 설계 권장사항이며 새 장치 규칙이 아니다.

밀 수 있는 나무상자 / 금속 상자
- 나무상자: 직접 밀기 한 칸, 바람 이동은 끝 또는 장애물 직전까지.
- 금속 상자: 바람 차단과 바람에 밀리지 않음만 확정. 직접 밀 수 있는지는 기존 프로젝트 규칙을 유지한다.
- 연쇄 상자 밀기, 여러 물체 동시 이동 우선순위를 새로 확정하지 않는다.

공통 07 무빙워크 / 09 단방향 문 / 18 튕김 모서리 / 19 제동판
- 07: 화살표 방향으로 끝 또는 막힘 직전까지 자동 운반.
- 09: 기존 허용 방향 통과 후 닫힘. 반대 방향 무변화 입력은 코스트·턴 0.
- 18: 홈으로 표시한 기존 접촉 방향에서 90도 전환. 아트의 ne/se/sw/nw는 코너 모양 키다.
- 19: 기존 제동판 도달 시 자동 이동을 멈추는 규칙을 유지한다.
- 바람과 제동판·다른 이동 장치가 같은 칸에서 경합할 때의 세부 우선순위는 기존 확정 로직을 조회한다.

[아직 미확정 — 아트와 샘플이 기획 결정을 대신하지 않음]
1. 침수될 수로 칸에 플레이어·물체가 있을 때의 처리. '전체 밀기 거절 + 붉은 칸 예고'는 안전 제안이다.
2. 수문 통과 후 멈춘 병아리의 재추종 조건.
3. 포털·도약·나룻배 통과 때 병아리의 세부 경로 판정.
4. 바람에 실린 별양이 키 큰 풀과 만났을 때 먹기까지 자동 발동하는지.
5. 여러 바람·컨베이어·모서리·제동판의 경합, 여러 물체의 동시 이동·점유 예약 순서 중 기존에 확정되지 않은 부분.
미확정 조합을 프레임 재생 완료나 임의 기본값으로 확정하지 않는다. 해당 조합은 별도 검토 대상으로 보고한다.

[행동 처리 연결 권장 순서 — 새로운 확정 기획이 아닌 구현 제안]
입력 후보 → 원본 상태를 보존한 이동·문양·점유 검사 → 무변화면 피드백만 재생.
유효 행동이면 코스트·장치 턴을 각각 한 번만 확정하고 실제 통과 경로/최종 상태를 기록한다.
기존 결정된 자동 연쇄를 해결하며 실제 경로를 이어 붙인다. 미확정 조합은 새 규칙으로 메우지 않는다.
병아리는 실제 경로를 소비하다 자기 둥지 또는 수문 통과 정지 이벤트에 도달하면 해당 상태로 바뀐다.
수로 변경은 A/B를 하나의 원자적 변경으로 반영한 뒤 이웃 마스크·표시를 갱신한다.
표현 계층에 확정된 상태와 경로를 전달해 준비→동작→충돌/변화→결과→정착을 보여 준다.
코루틴 종료, 마지막 애니메이션 프레임, 이미지 알파 영역으로 논리 점유/수집/코스트를 계산하지 않는다.

[제외]
누름판·덩굴 다리, 청크 붕괴, 타일 진입 횟수, 실시간 가속, 움직이는 방울,
병아리 별점 수집, 관측 지도 변형, 글자·속성 코어 신규 시스템은 포함하지 않는다.
