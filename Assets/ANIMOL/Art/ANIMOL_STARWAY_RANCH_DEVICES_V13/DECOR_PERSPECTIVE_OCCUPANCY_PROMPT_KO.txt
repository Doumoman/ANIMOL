ANIMOL 장식·장치 공통 제작 기준 R2
원근 / 지면 깊이 / 높이 / 접지 / 크기 / 타일 점유 보강본

이 문서는 기존 공통 프롬프트의 카메라·캔버스·Pivot 설명을 보완한다.
기존의 '탑뷰, 윗면과 짧은 전면, 모든 PNG 중앙 Pivot'만으로 제작하지 않는다.
아래의 R2 규칙이 서로 충돌하는 옛 시각 규칙보다 우선한다.
장치의 기능·코스트·공식 ID·미확정 예외는 별도의 최신 기획을 그대로 따른다.

1. 첨부 화면에서 확인해야 할 문제

상단의 건물·울타리·바닥이 묶인 장식은 작은 장면을 축소한 모형처럼 읽히고,
아래의 작업대는 개별 가구처럼 읽힌다. 두 종류가 같은 지면 위 물건이라는 느낌이 약하다.
큰 장식은 바닥이 뒤로 좁아지거나 더 압축되어 보이는 반면, 다른 장치의 윗면은 격자에 가깝다.
건물 안의 문·상자·울타리와 주변 가구·캐릭터의 크기 단위도 대조할 필요가 있다.
이는 화면을 보고 파악한 시각적 문제다. 한 장의 화면만으로 원화, 임포트 설정,
Transform 비율 중 어느 단계가 원인인지 확정하지 않는다. 원본과 실제 배치를 함께 확인한다.

핵심은 '물체가 모두 입체적이어야 한다'가 아니라, 서로 같은 공간 규칙을 사용해야 한다는 것이다.
같은 그림체·색·윤곽선만 맞아도 지면 투영과 크기 단위가 다르면 콜라주처럼 어색해진다.

2. 카메라 규칙: 정사각 지면 + 고정된 높이 표현

ANIMOL은 바닥의 가로/세로가 같은 크기인 정사각 격자를 사용한다.
이 바닥에 물체의 높이를 화면 위쪽으로 더해 그리는 2D 탑뷰 보정 투영을 사용한다.
이는 카메라의 물리적인 각도를 '30도/45도'로만 지정하는 방식과 구별한다.
정확한 3D 사선 카메라는 바닥의 세로 길이를 압축할 수 있으므로,
정사각 지면과 짧은 전면을 함께 원하는 이 프로젝트에서는 아래의 도형 규칙을 먼저 고정한다.

- 화면의 오른쪽/왼쪽은 지면의 가로축이다. 화면의 위/아래는 지면의 앞뒤축이다.
- 지면의 1칸 가로와 1칸 세로는 동일한 픽셀 길이다.
- 같은 크기의 물건은 화면의 위쪽/아래쪽 어디에 놓아도 같은 크기로 보인다.
- 지면의 앞쪽 변과 뒤쪽 변은 평행하며 길이가 같다. 바닥이 뒤로 갈수록 좁아지지 않는다.
- 물체의 기둥·다리·수직 모서리는 화면 수직 방향으로 선다.
- 높이에 의해 윗면이 위로 이동해도 좌우 중심이 옆으로 밀리지 않는다.
- 윗면과 짧은 전면을 보이되, 카메라가 물체마다 왼쪽/오른쪽으로 바뀐 것처럼 옆면을 혼용하지 않는다.
- 지붕의 경사선, X자 판자, 사선 장식은 허용한다. 그것이 지면 전체의 축을 기울이는 근거는 아니다.
- 물체의 잘린 모서리나 사선 외곽 장식과 지면 투영의 사다리꼴 왜곡을 구별한다.

소실점에 모이는 바닥선, 멀수록 작은 소품, 등각 마름모 격자,
물체마다 다른 바닥 세로 압축률, 같은 물체의 좌우 방향에 따라 달라지는 카메라는 사용하지 않는다.

3. 앞뒤 깊이와 높이는 별도의 값이다

앞뒤 깊이: 물체의 밑동/다리가 땅에서 차지하는 북-남 방향의 길이.
높이: 그 밑동에서 물체가 서 있는 정도를 화면 위쪽으로 표현한 길이.
두 값이 화면에서 모두 세로로 보이더라도 논리와 제작 기준은 분리한다.

예시(수치는 이번 보강본의 시각 제작 예시이며 게임플레이 규칙이 아님):
- 2×1 작업대: 가로 두 칸, 앞뒤 한 칸이 접지 영역이다. 다리 높이를 96px로 그려도 2×2 점유가 되지 않는다.
- 2×1 낮은 수문: 작업대와 같은 2×1 접지이지만, 전면 높이는 더 낮을 수 있다.
- 3×2 가판대: 가로 세 칸, 앞뒤 두 칸에 실제 앞다리/뒷다리와 물건 배치가 존재한다.
  지붕을 길게 그리거나 앞면을 높게 그리는 것만으로 깊이 두 칸을 대신하지 않는다.
- 높은 상자: 땅에서 1×1을 차지하면서 그림은 위쪽으로 더 돌출할 수 있다.

검사 방법:
물체를 그리기 전에 땅 위의 W×H 사각형을 그리고, 밑동 또는 다리의 접촉 위치를 표시한다.
그 접촉 위치에서 화면 수직 위쪽으로 높이를 쌓는다.
그림을 완성한 뒤 스프라이트의 전체 외곽 높이로 점유 칸을 거꾸로 추정하지 않는다.
지면 사각형 → 접지점 → 높이 → 윗면 → 가림 순서로 제작한다.

4. 단일 장식을 작은 디오라마로 바꾸지 않는다

일반 작업대·벤치·수레·상자에 각자 별도 바닥판·테두리·울타리를 자동으로 붙이지 않는다.
원래 그런 구조가 있는 가판대/양봉장/우리 등은 하나의 복합 소품으로 만들 수 있다.
이때 내부의 상자·의자·문·병·울타리도 주변의 같은 물건과 같은 크기 단위를 사용한다.
여러 소품을 지정된 캔버스에 모두 넣기 위해 장면 전체를 축소하지 않는다.
적정 크기로 들어가지 않으면 소품 구성을 덜어내거나 명시적으로 점유 W×H를 재검토한다.
사용자가 의도적으로 '미니어처 모형'을 요청한 경우만 별도의 미니어처 비례를 사용한다.

기존의 '점유한 바닥을 충분히 채운다'는 말은 빈 칸마다 색을 칠하라는 뜻이 아니다.
테이블 다리 사이, 벤치 아래, 수레 바퀴 사이에는 빈 공간이 존재할 수 있다.
접지점들의 배치와 물체의 실제 크기가 그 점유를 설명해야 한다는 뜻이다.
큰 바닥판 위에 작은 물건들을 올려서 W×H를 채운 것처럼 보이게 만들지 않는다.

5. 같은 크기와 높이를 공유하는 기준

같은 종류의 판자 폭, 기둥 굵기, 울타리 높이, 상자 한 개 크기를 테마 안에서 통일한다.
캐릭터·나무상자·작업대 중 이미 승인된 대표 자산을 한 화면에 두고 크기를 맞춘다.
사람용 건물의 문이 옆 캐릭터보다 지나치게 작아 보이거나,
같은 상자가 한 소품에서는 통 크기, 다른 소품에서는 컵 크기로 보이면 재검토한다.
동물용 집·장난감·미니어처처럼 원래 크기가 다른 대상은 그 용도가 실루엣으로 읽히게 한다.

같은 높이의 물체에는 같은 높이 표현량을 사용한다.
낮은 바닥 장치/쟁반, 벤치·작업대, 울타리·상자, 건물·수목의 높이를 전부 똑같이 만들지는 않는다.
모든 사물을 '전면은 짧게' 한 문장으로 눌러 그리지 않는다.
높은 건물은 지붕을 위로 올려 표현하되, 지면을 뒤로 눕히거나 좁혀 높이를 대신하지 않는다.
지형의 절벽 면은 지면 아래로 내려간 부분이므로 아래쪽에 보일 수 있다.
이 절벽 규칙을 지면 위 가구의 기둥/다리에 그대로 적용하지 않는다.

6. 캔버스와 Pivot: 그림 중심보다 지면 기준점을 우선한다

기준 논리 타일 T = 256px, 기준 PPU = 256을 유지한다.
평평한 물체의 기본 여백은 사방 32px다.
추가 높이 여백이 필요 없는 기존 규격:
1×1 = 320×320px, 2×1 = 576×320px, 2×2 = 576×576px, 3×2 = 832×576px.
이때는 가운데 논리 사각형과 중앙 Pivot이 서로 맞는다.

그러나 높은 물체를 모두 이 고정 캔버스에 억지로 맞추면,
전체 크기가 작아지거나 앞뒤 바닥 깊이가 압축되어 작은 모형처럼 보일 수 있다.
따라서 새로 재제작하는 높은 소품은 필요한 만큼 위쪽 캔버스를 늘리고,
지면에서 차지하는 크기와 기준점을 그대로 보존한다.

추가 위쪽 여백 E가 필요한 경우(여기서 E는 모든 물체의 고정 높이가 아니라 필요한 추가 돌출 공간):
CanvasWidth  = W×256 + 64
CanvasHeight = H×256 + 64 + E
지면 사각형의 이미지 좌상단 위치 = (32, 32+E)
지면 사각형 크기 = (W×256, H×256)

게임 루트를 지면 사각형의 중심에 두는 경우:
PivotX = 0.5
PivotY = (32 + H×256/2) / CanvasHeight
PivotY는 Unity의 이미지 아래쪽 기준 정규화 좌표다.

예: 점유 2×1이고 추가 위쪽 여백 E=96이면 캔버스 576×416,
지면 사각형은 (32,128)에서 512×256, Pivot은 (0.5, 약 0.384615).
이 스프라이트도 게임에서 차지하는 바닥은 여전히 2×1이다.
이 계산은 지면 중심 루트를 쓸 때의 예시다. 기존 프로젝트가 다른 앵커를 쓰면
그 앵커를 보존하는 방식으로 rect/Pivot/visual offset을 함께 계산한다.

중요: 기존 V13 장치 빌더는 고정 캔버스·중앙 Pivot 규격을 검사한다.
높이 확장 자산은 카탈로그/임포터/시각 오프셋을 함께 개정해야 한다.
새 Pivot 숫자만 기존 모든 자산에 일괄 적용하지 않는다.
그림의 알파 외곽에서 자동으로 Collider나 논리 점유를 만들지 않는다.

7. 가림, 접지와 광원

앞다리·뒷다리의 밑동은 각자의 지면 위치에 붙어 있어야 한다.
발·바퀴·상자 밑면이 접지 그림자와 떨어져 떠 보이지 않게 한다.
접지 그림자는 밑동 근처에 짧고 단순하게 둔다. 큰 원형 그림자로 점유를 부풀리지 않는다.
광원은 화면 좌측 상단으로 고정하며, 물체를 다른 방향으로 그려도 광원이 함께 돌아가지 않는다.
평면 색과 단순 셀 음영을 유지한다. 명암으로 잘못된 지면 투영을 덮지 않는다.

렌더 순서는 그림의 중앙/지붕 꼭대기보다 지면의 전면 접지 기준을 사용해 검토한다.
캐릭터가 물체 뒤에 있으면 적절히 가려지고, 앞에 있으면 물체 앞에 보여야 한다.
큰 복합 소품은 필요한 경우 전경/후경 또는 행 단위로 시각 레이어를 분리한다.
레이어 분리가 논리 오브젝트 중복이나 충돌 칸 추가를 뜻하지는 않는다.

8. 방향과 애니메이션

south/east/north/west는 물체가 바라보는 방향이다. 카메라가 물체 주위를 도는 것이 아니다.
네 방향 모두 동일한 지면 투영과 크기 단위를 유지한다.
비대칭 문양·문 경첩·빛 방향을 단순 좌우 반전으로 뒤집지 않는다.
움직임에 필요한 다리·날개 변화와 방향별 외형은 허용한다.
애니메이션 중에는 캔버스, 지면 사각형, Pivot, 접지 기준과 몸통 크기를 고정한다.
프레임마다 알파 바운드를 새로 맞춰 크기나 접지 위치가 흔들리게 하지 않는다.
준비→행동→충돌/변화→결과→정착이 읽히게 하며, 논리 타일 경로는 게임이 확정한다.
고정 기계는 본체를 유지하고 실제 움직이는 부품만 바꾼다.

9. 같은 화면에서 반드시 하는 검수

개별 PNG 확대 화면만 보고 완성 처리하지 않는다.
아래 검수 장면은 새로운 장식이 아니라 시각 일관성 검사 배치다.

A. 정사각 격자 위에 승인된 캐릭터·1×1 나무상자·2×1 작업대·다칸 건물을 같은 배율로 둔다.
B. 물체 아래에 논리 점유 사각형과 접지 기준점을 표시한 화면을 만든다.
C. 표시를 꺼 실제 게임 화면에서도 바닥 접지가 자연스러운지 확인한다.
D. 화면 위/아래에 같은 물체를 복제해 크기가 달라 보이지 않는지 대조한다.
E. 같은 높이/같은 재질의 다른 소품에서 기둥 굵기와 앞면 높이가 일치하는지 확인한다.
F. 100% 원본 배율뿐 아니라 실제 플레이 배율에서 확인한다.
G. 캐릭터를 앞/뒤/좌/우에 놓아 가림, 떠 보임, 통행 칸 침범을 검사한다.
H. 애니메이션 전 프레임에서 접지점과 지면 사각형을 겹쳐 흔들림을 확인한다.
I. Unity에서는 texture PPU, 부모 포함 lossyScale, 비균일 스케일, 회전, Pivot, visual offset을 원본과 대조한다.
   단일 PNG를 가로/세로로 다르게 늘려 잘못된 원근을 임시로 맞추지 않는다.

10. 장식 제작 채팅에 붙일 최종 프롬프트

당신은 ANIMOL의 실사용 2D 장식·장치 스프라이트를 제작한다.
첨부한 승인 자산을 그림체·색·크기·시점의 기준으로 삼고 위 R2 제작 규칙을 적용하라.

지면은 가로·세로 1칸이 같은 정사각 격자다. 모든 물체는 같은 고정된 정면 중심 탑뷰를 공유한다.
바닥 앞뒤 변의 길이를 같게 유지하고, 지면의 가로/세로 축은 화면 수평/수직과 맞춘다.
물체가 위쪽에 있다고 작게 그리거나, 물체마다 바닥 세로를 다르게 압축하지 마라.
밑동의 앞뒤 깊이와 물체의 높이를 별도로 설계하라. 먼저 W×H의 지면 사각형과 접지점을 확정하고,
접지점에서 화면 위쪽으로 높이를 쌓아 몸체와 윗면을 구성하라.
2×1은 바닥 두 칸×한 칸이고, 3×2는 바닥 세 칸×두 칸이다.
기둥이나 앞면의 높이를 늘려 점유 깊이를 대신하지 마라.

일반 가구를 작은 바닥판·울타리·여러 미니 소품이 붙은 축소 디오라마로 바꾸지 마라.
복합 소품이 필요한 경우에도 내부의 상자·문·기둥 크기는 주변 물건과 같은 기준을 사용하라.
지정 캔버스에 들어가게 하려고 전체 물체를 축소하거나 가로/세로 비율을 찌그러뜨리지 마라.
높이가 필요한 소품은 지면 크기를 유지하면서 위쪽 캔버스와 앵커 메타데이터를 함께 조정하라.

짙은 남색의 굵고 정리된 외곽선, 간결한 내부선, 큰 단색 면과 소수의 평면 셀 음영을 사용하라.
목장 자산은 상아·따뜻한 목재·잎색·청록·남색의 기존 색감을 따르라.
각진 실루엣과 쐐기·삼각·사다리꼴 장식은 허용하되 바닥 투영 전체를 사다리꼴로 왜곡하지 마라.
광원은 화면 좌측 상단에 고정한다. 점무늬·복잡한 잔질감·번짐·바탕에 구운 발광을 만들지 마라.

논리 점유, 캔버스 크기, 지면 사각형, Pivot, 시각 높이, 접지 기준점을 먼저 명세하라.
실제 투명 RGBA PNG와 방향/상태/프레임 순서/fps/반복 여부를 제공하라.
같은 클립의 모든 프레임에서 캔버스·Pivot·지면 기준·몸통 크기를 유지하라.
최종 검수에는 승인된 캐릭터·상자·작업대와 새 소품을 동일 격자·동일 배율로 배치한 비교 화면을 포함하라.
점유 표시를 켠 화면과 끈 화면 모두에서 접지·크기·깊이·가림을 확인하라.

11. Unity 적용 담당에게 보낼 보충 명령

원근 보정은 먼저 원화의 지면 사각형·접지점·높이·주변 물건과의 크기를 비교하라.
원화가 서로 다른 카메라를 사용하면 Transform 비균일 스케일로 덮지 말고 재제작 대상을 기록하라.
PPU와 부모 스케일·Pivot 오류는 원화 문제와 분리해 수정하라.
높이 확장 캔버스를 도입할 경우 카탈로그·임포터·Pivot·시각 오프셋을 함께 갱신하고,
논리 점유·장치 ID·게임 루트 좌표·충돌·코스트는 해당 변경 때문에 달라지지 않게 하라.
새 원화의 앵커 규격이 준비되지 않은 상태에서 기존 자산들의 Pivot만 일괄 변경하지 마라.
최종 결과에는 원본 크기 비교, 점유 표시 화면, 실제 플레이 배율 화면, 앞뒤 가림 검사를 남겨라.
