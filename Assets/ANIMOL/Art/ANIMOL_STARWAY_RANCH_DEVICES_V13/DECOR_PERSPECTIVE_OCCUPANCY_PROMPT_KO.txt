ANIMOL 장식·장치 공통 제작 프롬프트 — 원근 / 점유 / 애니메이션 일관성

아래 내용을 장식 제작 채팅에 그대로 붙이고, 마지막의 대상·점유·상태만 바꾼다.
최신 별길 목장 V12 / 연결 장식 V02 / 장치 V13 이미지를 함께 스타일 참고로 첨부한다.

당신은 탑뷰 스와이프 퍼즐 게임 ANIMOL의 실사용 2D 장식/장치 스프라이트를 제작한다.
첨부 이미지는 그림체·색면·카메라·타일 비례의 기준이다. 배경이나 격자까지 복제하지 않는다.

[카메라와 형태]
상하좌우 정사각 격자를 수직 정렬한 정면 중심의 탑뷰. 모든 물체에 같은 고정 카메라를 사용한다.
바닥 접지면의 가로와 세로 축을 수평·수직으로 유지하고, 물체 윗면과 짧은 전면만 보여 높이를 전달한다.
등각 다이아몬드 격자, 소실점 원근, 멀어질수록 좁아지는 바닥, 길고 두꺼운 옆면을 만들지 않는다.
가로 방향으로 긴 물체의 길이와 바닥 두 줄을 사용하는 깊이를 혼동하지 않는다.

[그림체]
매우 짙은 남색의 굵고 또렷한 바깥 윤곽선, 간결하고 더 가는 내부선.
삼각형·사다리꼴·쐐기·각면과 긴 직선으로 선명한 실루엣을 만든다.
넓고 단정한 기본색과 소수의 평면 셀 음영. 빛은 화면 좌측 상단으로 통일한다.
목장 기준색은 상아/크림, 황토/따뜻한 목재, 잎색/청록, 짙은 남색이다.
점무늬·잔금·복잡한 털/나뭇결·에어브러시 광택·안개·번짐·사진 질감을 추가하지 않는다.
최근 고해상도 플랫 카툰 자산의 마감과 일치시킨다. 명시적 요청 없이 16색/32px 제한을 새로 적용하지 않는다.

[논리 점유와 실제 그림]
제작 전에 점유 W×H를 명시한다. 1칸의 논리 크기는 256×256px이며 기준 PPU는 256이다.
그림의 투명 여백을 포함한 출력 크기는 (W×256+64)×(H×256+64)px, 사방 여백 32px.
1×1: 320×320px. 2×1: 576×320px. 2×2: 576×576px. 3×2: 832×576px.
논리 바닥 사각형은 이미지 좌상단 (32,32)에서 W×256, H×256 범위다. Pivot은 정중앙 (0.5,0.5).
2×1 물체는 실제로 이웃한 가로 두 칸을 쓰며, 1×1 도안을 가로로 늘려 만들지 않는다.
2×2/3×2 물체는 점유한 앞뒤 바닥을 자연스럽게 채운다. 얕은 한 줄 물체에 큰 투명 여백만 붙이지 않는다.
밑동·다리·판·바닥받침이 실제 접지 영역과 연결되게 하며, 비어 있는 이웃 통행 칸을 덮지 않는다.
높이에 따른 작은 위쪽 돌출은 허용하지만 다른 칸을 점유하는 것처럼 보이는 긴 지붕·그림자·앞면을 피한다.
논리 점유는 명시된 W×H로만 관리한다. 알파 실루엣이나 그림자로 충돌 범위를 추정하지 않는다.
여러 칸 소품 하나를 타일마다 중복 생성하지 않는다. 하나의 루트와 하나의 시각 묶음으로 배치한다.

[연결 장식]
같은 재질의 연결부는 경계의 정확히 같은 좌표·폭·색면에서 만난다.
직선·모서리·T자·십자·끝·안쪽 구멍을 함께 검사한다. 내부 연결 경계에 겹친 테두리나 검은 틈을 만들지 않는다.
수문 본체 2×1과 젖은/마른 수로 영역은 별개다. 물과 마른 바닥의 판정이 장식 이미지 때문에 바뀌면 안 된다.

[애니메이션]
idle → anticipation → action → change/impact → result → settle의 원인과 결과가 읽히게 만든다.
같은 방향의 모든 프레임에서 캔버스·Pivot·몸통 크기·접지 기준을 고정한다. 프레임마다 자동 fit/center로 크기를 흔들지 않는다.
정면(south), 오른쪽(east), 후면(north), 왼쪽(west)을 같은 스케일로 제작한다.
비대칭 장식·문양·문 경첩·빛 방향이 있는 물체를 단순 좌우 반전으로 복제하지 않는다.
이동할 때만 걸음 동작을 재생하고, 이동 거리·정지점은 게임이 확정한 타일 경로에 맞춘다.
기계 본체가 고정인 장치는 루트를 옮기지 않는다. 바람개비는 몸체 고정 + 날개 회전 + 범위 표식만 변경한다.
눈이 보이는 양/병아리는 읽기 쉬운 흰 눈 하이라이트를 유지한다. 후면에는 눈을 새로 그리지 않는다.
거절은 짧은 진동/붉은 예고처럼 표현하되 유효 이동·코스트 소비로 보이게 하지 않는다.

[출력]
실제 투명 RGBA PNG. 체크무늬·배경색·주변 발광을 바탕으로 구워 넣지 않는다.
프레임 분리 PNG와 순서/방향/fps/반복 여부/점유 크기 목록, 투명 여백이 보이는 미리보기를 함께 제공한다.
이름·숫자·설명·워터마크는 실사용 PNG에 넣지 않는다. 숫자는 필요한 경우 기존 게임 UI에서 별도로 표시한다.
