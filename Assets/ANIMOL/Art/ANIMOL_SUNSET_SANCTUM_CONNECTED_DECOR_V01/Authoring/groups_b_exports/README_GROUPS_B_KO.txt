낙일 성소 연결 장식 V01 — 다칸 6종 및 한 칸 장식 8종

총14종은 모두 새 built-in image_gen 원화에서 등록한 투명 PNG이다. 기존 극장/목장 원화의 재색칠이 아니다. 제작 프롬프트와 최초 원본은 Authoring/prompts.json, Authoring/angular_fix_prompts.json 및 sources에 보존했다.

다칸 장식은 대형 서책 진열대2x1, 두루마리 보관 묶음2x2, 성소 휘장 단2x1, 각면 천구의 좌대2x2, 파손된 별 모자이크2x2, 봉헌 계단2x1이다. 각 다칸은 하나의 PNG와 하나의 배치 인스턴스로 사용한다. 타일별로 분해하거나 각 점유 칸에 같은 원화를 반복하지 않는다.

한 칸 장식은 석조 등불, 부러진 기둥, 서책 받침대, 구릿빛 각잎 식물, 서기관 잉크대, 봉헌 촛불 묶음, 두루마리 바구니, 별 문양 경계석8종이다. 16방향 연결 마스크나 색상 변화로 종류 수를 부풀리지 않았다.

각진 형태 재검수에서 모자이크 원형 선, 서책 표지의 원형 문양, 둥근 촛불 단면과 두루마리 끝을 발견하여 새 native 원화로 다시 제작했다. 최종 런타임은 별과 계단형 사각 프레임, 마름모 표지/메달, 명확한 육각 기둥 촛불, 육각주/직사각 접지 문서로 구성한다. 해당 초안은 제작 이력용 원본으로만 남고 최종 PNG는 새 수정 원본을 사용한다.

PPU256이며 logicalRect는 실제 256px 단위 지면 슬롯이다. pivot은 그 지면의 중앙이다. 전체 PNG를 1칸에 fit하지 않는다. 2x2 장식은 사각 좌대나 실제 앞뒤 두 줄 보관 배치가 두 깊이 칸을 채운다. 모든 다칸 폭90% 이상, 깊이2칸의 높이85% 이상과 각256px 행 불투명 점유35% 이상을 파일로 검수했다. 정확한 측정값과 SHA는 groups_b_qa.json/manifest.json에 있다.

Authoring/build_groups_b.py는 native 분리·동일 비율 크기 등록·알파 여백 처리·메타데이터와 검수 이미지만 만든다. RGB를 다시 칠하거나 비균일 늘이기, 흰색 키 제거를 사용하지 않는다. 기존 생성 알파의 주요 성분과 2px 안티앨리어싱 여유를 보존하며 멀리 떨어진 극소 노이즈와 alpha0의 RGB만 지운다.

검수 이미지는 OFFLINE ART REFERENCE이다. 원 Unity 프로젝트가 없으므로 실제 Import/C#컴파일/Prefab생성/Play/레거시참조0은 NOT_RUN이다. 장식은 새 게임 충돌·입력·턴·광선 장치가 아니다.
