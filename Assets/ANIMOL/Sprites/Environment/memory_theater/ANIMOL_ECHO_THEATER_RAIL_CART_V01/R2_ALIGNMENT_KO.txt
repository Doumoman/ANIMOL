잔영 극장 레일 카트 — R2 정렬 수정

사용자 요청: 바퀴를 별도 자원으로 납품하는 것이 아니라, 카트에 그려진 바퀴가 레일 위에 맞도록 수정.
결과: 카트는 소품·차체·바퀴까지 합쳐진 완성 PNG 한 장이며 카트당 SpriteRenderer 하나다.
바퀴 자식 오브젝트나 바퀴 전용 런타임 스프라이트는 없다.

시각 기준
1. 같은 256px 논리 셀에서 레일 두 선 중심 간격160px, 바퀴 접촉 중심 간격160px로 통일했다.
2. 앞뒤 축 간격128px. 직선은 두 축의 바퀴가 각 선 위에 놓인다.
3. 곡선 레일은 반지름128px인 경로에서 같은 폭을 유지한다.
   카트는 호스트가 확정한 진행방향의 완성 PNG로 전환한다. 그림을 통째로90도 돌리지 않는다.
4. 직선·모서리 모두 셀의 입구/출구에서 두 레일의 폭과 진행 접선을 맞췄다.
5. 받침의 두께를 줄이고 레일 체결구를 같은 위치에 놓았다.
   바닥이 위에 있고 바퀴가 붕 떠 있는 느낌을 줄이도록 바퀴 아래 접점을 레일 중심선에 등록했다.

나무 받침 간격
- 레일 타일6종은 바로 사용할 수 있다. 직선64px, 모서리 약67.02px의 일정한 로컬 간격이다.
- 모든 곡선과 연결부까지 같은 간격이 필요하면 포함된 레일 바닥용 EchoRailTrackViewV02를 쓴다.
  타일마다 간격을 새로 시작하지 않고 전체 경로의 누적 길이로 배치한다.
- 닫힌 경로는 정수 개 받침으로 나눈 같은 간격을 사용한다. 약64px를 기준으로 조금 조정되며
  마지막 받침과 첫 받침 사이도 다른 간격과 같다. 예시12셀 루프는45개, 약63.3833px 간격이다.
- 카트와 바퀴를 분리하는 기능은 아니다. 레일 표시를 위한 선택적 보조 코드다.

호출 예
카트: EchoRailCartVisualV01.Configure(catalog, out error)
직선: ShowCart("east")
방향 전환 후: ShowCart(확정된_새_진행방향)
레일: EchoRailTrackViewV02.Configure(catalog, orderedCells, true, cellSize, out error)
진행방향과 접촉 상태는 실제 게임에서 확정된 값을 넘긴다.

현재 한계
이번 수정은 가로/세로 접점과 레일 연결을 맞춘 것이다. 이동 중 바퀴를 계속 조향하는 애니메이션은 없다.
R2 프리뷰 GIF는 네 방향의 직선 배치 확인이며 실제 Unity 캡처나 연속 주행 구현의 증거가 아니다.
게임의 이동/밀침/복귀/장애물 판정은 기존 호스트의 책임이다. RULES_KO.txt의 미결정 항목을 유지한다.

검수
16개 PNG 디코드/크기/해시,12개 클립 참조,직선 바퀴 접점과 직선·모서리 레일의 기하 연결,
예시 닫힌 경로의 받침 등간격,ZIP CRC/압축 해제/전체 파일 SHA를 오프라인 검수한다.
기하 계산값은 원본 접촉 등록 좌표이며, 안티앨리어싱과 시각 원근 때문에 모든 외곽 픽셀이
레일 선과 일치한다는 의미는 아니다. 실제 Unity 컴파일/임포트/플레이는 NOT_RUN이다.
