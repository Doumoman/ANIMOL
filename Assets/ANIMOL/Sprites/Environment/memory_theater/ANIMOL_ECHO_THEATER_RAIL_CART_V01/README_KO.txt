ANIMOL 잔영 극장 — 소품 적재 레일 카트 V01

빈 이동 발판을 소품이 가득 찬 1×1 레일 카트로 바꾼 시각 자원 패키지다.
소품 상자·접은 자주색 커튼·작은 무대 패널을 적재해 플레이어가 탈 빈 공간을 없앴다.
사용자가 준 아트 프롬프트의 굵고 각진 남색 윤곽선, 넓은 단색 면, 제한된 셀 명암을 적용했다.

PNG14개: 카트4방향×기본/완충대 접촉2상태=8개, 레일 직선2종+모서리4종=6개.
모든 PNG320×320, 논리 셀256px, 바깥 여백32px, PPU256, 중앙 Pivot(.5,.5), FullRect, Bilinear, 무압축, Mipmap Off.
레일 연결 포트는 셀 변의 중앙이며 이웃 타일의 연결 단면 픽셀이 일치한다.
카트 몸체/소품은 접촉 상태에서도 고정되고 앞 완충대 영역만 달라진다.

애니메이션 정의12개: 방향별 idle/move/contact. move는 정적 한 프레임이며 실제 이동은 호스트의 좌표 tween이 보여 준다.
contact는 기본→눌린 완충대→기본3프레임/12fps다. 바퀴 회전 다중 프레임이 있는 것처럼 표시하지 않는다.
Editor 빌더 소스로 실제 Unity의 Sprite 카탈로그와12개 .anim을 생성한다. 시각 재생 보조 소스도 포함한다.

RULES_KO.txt: 플레이어 먼저 이동→카트 한 칸→밀침/입력 전 위치 복귀라는 새 판정 의도.
UNITY_APPLY_ART_CLI_KO.txt: 이번 아트 설치와 기존 장치 시각 연결 명령.
실제 이동/충돌/되돌림 게임 로직은 이번 스프라이트 패키지에서 구현하지 않았다.
기존 M06의 '무대 탑승/운반' 판정을 새 카트 판정으로 바꾸는 작업은 실제 프로젝트에서 별도로 진행해야 한다.

기존 잔영 극장 V03 전체 ZIP을 덮어쓰지 않는 별도 패키지다. 기존 장치 ID·다른 장치를 새 번호로 교체하지 않는다.
새 원화/프롬프트/등록값은 Authoring~에 포함하며 built-in imagegen을 사용했다.
파일/포트/카탈로그/압축을 오프라인 검수했다. 실제 Unity 컴파일/임포트/플레이는 NOT_RUN이다.
