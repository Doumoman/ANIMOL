ANIMOL 잔영 극장 — 소품 적재 레일 카트 V01 / 수정 R2

카트는 바퀴와 소품을 포함한 완성 PNG 한 장으로 표시한다.
별도 바퀴 스프라이트, 바퀴 자식 오브젝트, 바퀴 조립 컴포넌트가 필요하지 않다.
상자·자주색 커튼·무대 패널을 채운 기존 콘셉트와 굵고 각진 남색 윤곽선/셀 명암을 유지했다.

R2 수정
- 레일 중심 간격160px와 카트 바퀴 접촉 위치를 같은 기준으로 맞췄다. 축 간격은128px다.
- 직선과 네 모서리 레일의 두 선이 이웃 셀 경계에서 같은 위치와 접선으로 이어진다.
- 나무 받침을 얇게 정리했다. 전체 경로용 시각 보조는 경로 길이를 따라 받침을 등간격 배치한다.
- 가로·세로 네 방향 완성 카트의 바퀴 접점을 레일에 맞췄다.

자원16개: 완성 카트8개(방향4종×상태2종), 레일 타일6개, 레일 바닥 조립용 재질/받침2개.
카트마다 SpriteRenderer 하나만 사용한다.
원래 카트/레일 키와 V01 패키지 경로를 유지하며 installationRevision은2다.

논리 셀256px/PPU256=1유닛이다. 원본 이미지의 전체 크기로 셀 간격을 정하지 않는다.
완성 카트 PNG448×448, Pivot(.5,192/448), 논리Rect(96,128,256,256).
레일 타일320×320, 중앙 Pivot, 논리Rect(32,32,256,256).
그 외 재질512×64, 받침320×96. 각 자원의 크기와 Pivot은 animation_catalog.json이 기준이다.
전부 FullRect/Bilinear/무압축/Mipmap Off/NPOT None. 레일 재질만 Repeat, 나머지는 Clamp.

클립12개: 기존 방향별 idle/move/contact를 유지한다.
move는 정적 한 프레임이다. 이동 좌표와 턴은 호스트가 확정하며, 아트 클립은 게임 상태를 변경하지 않는다.
모서리에서는 호스트가 확정한 진행방향의 카트로 전환한다. 연속 조향/회전 애니메이션은 포함하지 않는다.

레일 배치 방식
1) 기존 Tilemap 유지: rail/ew, ns, ne, es, sw, wn을 논리 셀 간격1로 배치한다.
   직선 받침 간격64px, 모서리는 곡선 길이를3등분한 약67.02px다.
2) 경로 전체 받침 간격 일치: EchoRailTrackViewV02.Configure에 순서가 있는 셀 목록을 전달한다.
   닫힌 경로는 전체 길이/받침 개수로 간격을 정해 마지막 연결부도 같은 간격이 된다.
   이 컴포넌트는 레일 바닥 표시만 만들며 카트·바퀴·충돌·게임 턴을 제어하지 않는다.
   두 방식을 같은 경로에 겹쳐 표시하지 않는다. rail/material은 SpriteAtlas에서 제외한다.

UNITY_APPLY_ART_CLI_KO.txt: 실제 프로젝트에 적용할 명령과 점검 순서.
R2_ALIGNMENT_KO.txt: 바퀴 접점·받침 간격·현재 검수 범위 설명.
RULES_KO.txt: 플레이어 이동 후 카트 한 칸, 밀침 또는 입력 전 위치 복귀라는 게임 판정 인계.
실제 이동/충돌/되돌림은 이 아트 패키지에서 구현하지 않았다.

Preview/OVERVIEW.png와 R2_ALIGNMENT_REPLAY.gif는 오프라인 자원 검수용이다.
Unity 컴파일/임포트/플레이는 NOT_RUN이다. 전체 원화와 생성 프롬프트는 Authoring~에 포함한다.
