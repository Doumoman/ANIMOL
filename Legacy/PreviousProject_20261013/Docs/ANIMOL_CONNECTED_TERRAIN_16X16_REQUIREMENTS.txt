1. 사용자가 원하는 결과

Scene 맵 에디터에서 원하는 모양의 지형을 만들면, 그 모양에 자연스럽게 맞는
발판·측면·밑면·천장·안쪽 마감 그림이 자동으로 선택되어야 한다.
현재처럼 내부 질감을 붙일 수 있는 받침 위치를 사용자가 찾아다니게 하지 않는다.
작은 조각의 경계가 드러나거나 벽돌 크기와 무늬가 갑자기 바뀌지 않아야 한다.

사용자 제안은 최대 16×16 논리 셀 안에 들어가는 연결된 덩어리마다 완성 Sprite를
직접 제작하는 것이다. 후속 지시에 따라 직사각형과 계단형을 대상으로 좁히고,
굴곡·아치는 이번 제작 범위에서 제외한다. 완성된 그림의 자연스러움을 우선한다.
기존 아치 부품과 맵은 삭제하지 않는다. 새 제작 목록에서 제외한다는 의미다.
계단 각 단의 폭·높이까지 일정하게 제한할지는 아직 확인 전이다.

2. 반드시 구분할 모양의 범위

A. 빈 곳 없이 꽉 찬 직사각형
   폭 1~16 × 높이 1~16 = 256가지 / 스타일.
   위치를 제외하고 폭·높이를 구분한다. 그림의 방향성이 있으므로 3×5와 5×3은
   별도 형태다. 외형 변형, 색상, 천장 전용 그림은 이 수량에 포함하지 않았다.
   5테마 × 4스타일 전체에 동일 범위를 적용하면 5,120가지 / 외형 변형 1종.
   이 수량은 '직사각형 한정'일 때만 맞으며, 모든 연결 지형의 수량이 아니다.

B. 규칙적인 계단 — 제작 수량을 제한하는 제안, 아직 미확정
   한 덩어리의 모든 단이 같은 폭 t, 같은 높이 r을 가진다.
   단수 n은 1~16, t와 r은 양의 정수이며 n*t <= 16, n*r <= 16이다.
   폭=n*t, 높이=n*r. 왼쪽부터 각 열의 높이는 (floor(x/t)+1)*r이다.
   바닥에서 각 열의 높이까지 전부 고체이며, 계단 아래 추가 몸체 높이는 없다.
   좌우 계단은 모두 포함하되 위아래 뒤집기·90도 회전은 수량에서 제외한다.
   n=1은 직사각형이다. 같은 점유 모양은 한 번만 센다.

   예: n=3, t=2, r=1 → 6×3, 오른쪽으로 올라가는 계단(top-first)
     ....##
     ..####
     ######
   반대 방향은 ##.... / ####.. / ######이며 별도의 방향 아트로 센다.

   n별 가능한 (t,r) 수는 floor(16/n)^2이다.
   n=1~16의 합은 390개이며, 그중 n=1의 직사각형이 256개다.
   나머지 134개를 좌우 방향으로 각각 제작하면:
     직사각형 256 + 계단 134*2 = 524개 / 스타일 / 외형 변형 1종.
     5테마*4스타일에 같은 목록을 적용하면 10,480개다.
   실제 높이 배열을 열거하고 좌우 반전을 포함해 중복 제거한 결과도 524개다.
   이 수량에는 추가 몸체 높이, 불완전한 마지막 단, 별도 천장 방향, 외형 변형을
   포함하지 않는다. 해당 옵션을 허용하면 모양 목록과 수량을 다시 계산해야 한다.

C. 단마다 폭·높이가 자유로운 계단
   굴곡·아치를 제외하고 한 방향으로만 올라가는 계단이어도 경우의 수가 커진다.
   예를 들어 폭 16열에서 1~16 높이를 낮아지지 않는 순서로 배열하고 바닥까지
   채우면, 모두 연결되고 구멍 없는 단조 계단/직사각형이 된다.
   이 제한된 형태만 중복조합 C(31,16) = 300,540,195개다.
   폭 1~16 전체의 한 방향 단조 높이 배열은 C(32,16)-1 = 601,080,389개다.
   이 수량도 천장 방향이나 외형 변형을 포함하지 않는다.
   따라서 '계단 포함'만으로 수량을 확정할 수 없고 단의 규격을 정해야 한다.

용어 초안: 연결은 상하좌우 변을 공유하는 4방향 연결이다.
신규 제작은 내부가 채워진 직사각형과 단조 계단으로 한정한다.
내부 구멍·아치·오르내림이 반복되는 굴곡은 신규 모양 목록에서 제외한다.
이는 기존 맵의 해당 형상을 자동 삭제하거나 로드를 거부하라는 의미가 아니다.

3. 제작 방식과 범위 결정

사용자 의도에 따라 직접 제작한 완성 Sprite를 정확한 모양에 자동 할당하는 방식을
우선 요구한다. 규칙 계단 제한(B)을 선택하면 524개라는 유한 목록을 만들 수 있다.
이 목록이 확정되기 전에는 524개를 최종 발주 수량으로 표시하지 않는다.
각 단을 자유롭게 바꾸는 C를 선택한다면 대표 모양 목록으로 추가 제한하거나,
검수된 연결 아트의 합성을 별도로 선택해야 한다. 합성 방식은 자동 채택하지 않는다.
합성 결과를 한 Sprite로 굽는 것과 원본 Sprite를 전 경우 직접 제작하는 것은 다르다.
단순히 기존 질감 패치를 반복하는 방식은 사용자가 원하는 품질을 보장하지 않는다.

16×16은 새 아트 제작 단위의 최대 논리 크기 제안이다. 기존 청크 크기 16과
개념을 혼동하지 않는다. 맵 전체 크기를 16×16으로 줄이는 요구가 아니다.
인접한 두 덩어리가 합쳐져 16셀을 넘거나 삭제로 하나가 둘로 갈라질 때의
거부·분할·합성 정책은 해당 제작 방식을 선택한 뒤 명시한다.
자동 분할을 사용한다면 분할 경계가 외벽처럼 그려지거나 무늬가 끊기면 실패다.

4. 아트 발주 요구사항

ART01. T01_A 한 스타일을 선행 제작·검수하고 다른 스타일로 확장한다.
       전체 수량 제작 전에 작은 발판, 1셀 두께, 최대 크기, 천장과 안쪽 모서리가
       같은 그림 체계로 자연스럽게 표현되는지 확인한다.
ART02. 최종 발주에는 지원 모양별 shape ID, 폭·높이, 명시적 고체 마스크,
       필요한 방향, 변형 수량을 포함한다. 미확정 수량을 '모든 경우'로 발주하지 않는다.
ART03. 모든 아트는 동일한 셀 기준 크기, 픽셀 밀도, 팔레트, 광원과 선 굵기를 따른다.
       폭이나 높이에 따라 원본을 비균등 확대하여 벽돌과 장식 비율을 찌그러뜨리지 않는다.
ART04. 연결 조각 방식을 선택하면 윗면·아랫면·양쪽 벽·볼록/오목 모서리·내부·
       1셀 두께 선분·끝부분·독립 셀과 계단의 안쪽/바깥쪽 모서리를 다룬다.
       신규 아치/구멍 그림은 이번 발주에서 제외한다. 기존 9방향만으로 완전성을 주장하지 않는다.
ART05. 이어 붙인 경계에서 틈, 두 겹 외곽선, 어긋난 벽돌 줄눈, 불연속 그림자가 없어야 한다.
       장식은 단순 반복으로 무늬가 과밀해지지 않도록 덩어리 크기에 맞게 배치한다.
ART06. 천장과 벽의 광원·중력 방향 장식은 별도로 검수한다.
       Sprite를 돌리는 것만으로 천장 그림이 완성된다고 가정하지 않는다.
ART07. 기존 SourceArt PNG 5장과 v3 60프레임은 보존한다.
       신규 연결 아트는 별도 버전·경로로 제작한다. DebugArt 47슬롯은 최종 아트가 아니다.
ART08. 픽셀 해상도와 아틀라스 메모리는 별도 확정한다. 16×16은 16×16픽셀이라는 뜻이 아니다.
       공통 부품 재사용과 패킹을 포함한 실제 메모리·로딩 비용을 측정한 뒤 전체 제작량을 확정한다.

5. 자동 할당과 편집 요구사항

ED01. Scene View에서 지형 칠하기·지우기·영역 편집 후 그림을 자동 갱신한다.
      사용자가 InteriorOverlay의 받침 조건을 맞추는 것을 기본 제작 흐름으로 요구하지 않는다.
ED02. 완성 Sprite 라이브러리는 원점을 정규화한 점유 모양, theme/style 및 아트 버전으로
      정확히 조회한다. 미등록 모양을 비슷한 다른 마스크로 대체하지 않는다.
ED03. 자유 지형 합성을 선택하면 주변 셀 상태와 경계 위치로 그림을 고른다.
      theme/style 경계, 청크 경계와 연결된 덩어리의 합침/분리를 일관되게 처리한다.
ED04. 동일한 저장 데이터와 아트 버전은 재오픈·Undo/Redo·런타임에서 동일한 그림을 만든다.
      무늬 변형 선택을 프레임마다 무작위로 바꾸지 않는다. 캐시만으로 결과를 유지하지 않는다.
ED05. 큰 합성 영역의 이동·삭제와 한 번의 브러시 드래그는 각각 한 transaction으로 처리한다.
      기존 v3 완성 instance의 # 소유 셀은 부분 수정하지 않는다. 기존 데이터를 새 방식으로
      전환하는 것은 명시적 백업·이전 결과 검증이 있는 별도 작업이다.
ED06. 지원 범위 밖 모양, 누락된 아트, 연결 불가능한 경계를 저장 전에 구체적으로 알린다.
      미완성 진단 그림을 정상 게임 아트로 취급하지 않는다.

6. 저장·점유·충돌 연결 요구사항

기존 소스에서 확인한 경로:
  TerrainEditorSceneEditor.UpdateCandidate
  → TerrainEditorAdapter.Read / Validate / Commit
  → AnimolTerrainMapEditorBridge
  → StageTerrainStructureIntegration.Validate / Write
  → StageMapDefinition.ReadTerrain / EditorApplyTerrainCandidate

런타임의 기존 연결 지점:
  StageMapRuntimeLoader → StageTerrainStructureRuntime → 논리 고체 Grid / 기존 physics owner.
  StageMapRuntimeFactory의 맵 객체 생성·설정 경로는 유지한다.

DATA01. 운영 정본은 StageMapDefinition이다. 별도 맵 asset을 새로운 정본으로 만들지 않는다.
DATA02. 기존 일반 셀 tileId/variant, TerrainTileTopology 9방향 enum과 원본 데이터는 보존한다.
        새 렌더링 규칙을 기존 enum의 값 변경으로 억지로 표현하지 않는다.
DATA03. 새 모양/아트 매핑과 버전을 저장할 위치는 구현 설계에서 실제 소스를 보고 확정한다.
        본 문서의 shape ID는 신규 설계 용어이며 현재 존재하는 저장 필드명이 아니다.
        v3 schemaVersion=3과 기존 placement의 version/hash를 조용히 재해석하지 않는다.
DATA04. 점유가 그림 선택의 기준이다. 원본 알파를 읽어 자동으로 고체를 추정하지 않는다.
        정수 bottom-left 원점, top-first 마스크, localY=height-1-rowIndex를 유지한다.
        명시적 #셀만 충돌을 만들고, 빈 셀에는 충돌이 없어야 한다.
DATA05. 아트에 전체 사각형 Collider를 붙이지 않는다. 기존 operational physics owner에서
        고체 셀 충돌을 재생성한다. 일방통행 발판과 일반 고체/천장 정책을 혼합하지 않는다.
DATA06. 충돌 셀 수정과 그림 재계산은 기존 bounds/object footprint/swept path 검증을 거친다.
        변경 전 백업, 변경 asset Undo, revision 1회 증가, derived collision 무효화를 유지한다.
        실패 시 정본·프리뷰·캐시·저장 파일이 함께 이전 상태로 복원되어야 한다.
DATA07. 청크 좌표는 floor division이다. 음수 좌표와 청크 경계에 걸친 완성 그림의 전역
        수명을 유지한다. 원점 청크만 보고 부분 삭제하거나 중복 생성하지 않는다.
DATA08. 기존 v3 InteriorOverlay는 호환 로드와 받침 상실 cascade 규칙을 보존한다.
        기존 Fill20개를 별도 이전 없이 충돌 지형으로 바꾸지 않는다.
DATA09. 맵 저장·운영 스테이지 할당·Ready/보상 승인은 별개다.
        이번 아트 작업으로 기존 T01-S01, 객체 레이어, 보상/Ready를 자동 변경하지 않는다.

7. 단계별 산출물 및 완료 기준

AT01 — 지원 모양 확정
  직사각형과 계단형을 포함하고 굴곡·아치는 제외한다.
  계단의 B/C 규격, 연결 정의, 최대 크기와 초과 시 처리 정책을 기록한다.
  완성 Sprite 방식이면 정확한 모양 목록과 개수를 먼저 낸다.
  현재 단계에서 모든 16×16 연결 모양의 개별 제작을 완료 목표로 설정하지 않는다.

AT02 — T01_A 아트 시제품
  지원 범위 안에서 가장 작은/얇은/큰 모양과 꺾이는 경계를 먼저 제작한다.
  직사각형 방식이면 1×1, 1×16, 16×1, 2×2, 3×5, 5×3, 16×16을 포함한다.
  규칙 계단 방식이면 좌우 2단·3단, 1셀 단 폭/높이, 폭과 높이가 다른 단,
  16단 1×1 계단을 포함한다. 굴곡·아치는 신규 시제품에 포함하지 않는다.
  확대 화면과 실제 플레이 배율에서 연속성·무늬 비율·마감 품질을 검수한다.

AT03 — 기존 에디터·저장·런타임 연결
  실제 Scene 브러시로 만들기 → 수정 → 이동/삭제 → 저장 → 재오픈 → 시험 플레이를 연결한다.
  그림만 보이는 별도 샘플 씬을 구현 완료로 보고하지 않는다.
  선택된 아트와 점유 마스크가 같고, 재빌드 결과가 결정적인지 확인한다.

AT04 — 회귀 및 확대
  T01_A 품질을 검수한 뒤 T01의 나머지 스타일, 이후 T02~T05로 확장한다.
  신규 Sprite/매핑 누락, 잘못된 version/hash, 미지원 모양은 명시적으로 실패시킨다.
  기존 60부품·일반 셀·객체·맵 로더·보상/Ready의 저장 및 실행 회귀를 확인한다.
