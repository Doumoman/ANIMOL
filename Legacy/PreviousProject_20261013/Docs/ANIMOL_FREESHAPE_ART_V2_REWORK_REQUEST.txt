ANIMOL 자유형 지형 아트 수정본 요청

목표
현재 자유형 맵 편집·점유·저장·충돌은 동작한다. 새 에디터나 충돌 시스템을 만들지 말고,
ANIMOL_FreeShape_Sprites_v1의 아트 품질을 개선한 패키지를 제작하라.
중간 질감이 끊기거나 어긋나 보이고, 외곽 프레임 안쪽으로 제한되어야 할 질감이
프레임을 넘어 보이는 문제, 측면·밑면·안쪽 모서리 마감이 불분명한 문제를 해결하라.

확인된 근거
Unity 6000.3.8f1의 실제 FreeShapeTerrainRenderer로 T01_A/B/C/D의 16×16 사각형을
각각 512×512px로 렌더했다. 패키지 Samples/<style>/maximum_rectangle_16x16.png와
비교했을 때 네 스타일 모두 불투명 영역 RGB 차이 0, 알파 차이 0이다.
즉 Unity 좌표/위상/슬라이스를 임의로 바꾸어서 해결할 문제가 아니다.
증거: Docs/Validation/FreeShapePolish/ArtParity.json 및 Unity-T01_*.png.
그림에서 무엇이 프레임 밖이어야 하는지에 대한 새 시각 마스크는 기존 논리 점유와 구분하라.

수정 범위
1. 20스타일(T01~T05, A/B/C/D)의 정체성과 Sweetie16 팔레트를 유지한다.
2. 내부 질감은 일관된 2×2셀 위상 원본에서 제작한다. 이웃 타일에 걸친 벽돌/무늬의
   형태·색·높이가 연결되어야 한다. 내부에 외곽 전용 테두리나 잘린 상단 장식이
   반복 노출되지 않게 한다. 노이즈를 얹어 이음새를 숨기는 방식은 피한다.
3. 내부 채움, 외곽 마감, 내부 모서리를 별도 제작 레이어로 다룬 뒤 최종 PNG로 합성한다.
   채움 질감은 해당 마감의 내부 영역에 클리핑하고, 프레임의 바깥으로 새지 않게 한다.
   이 시각용 마스크는 논리 solid 셀이나 Collider를 변경하는 용도가 아니다.
4. 상단/좌우/밑면/볼록·오목 모서리에 마감이 이어져야 한다. 상단 Sprite를 회전해
   측면이나 천장으로 재사용하지 않는다. 1셀 폭·높이에서도 양쪽 마감이 충돌하거나
   중복되지 않게 한다. 고립 mask000도 완결된 하나의 고체 블록이어야 한다.
5. 문양 20개는 지형 위 장식이다. 별개 타일의 상단 캡이나 기둥이 잘려 붙은 듯한
   사각 경계를 피하고, 기존 내부 질감과 자연스럽게 어울리게 다시 정리한다.
6. 다른 스타일 간 전환 아트는 이번 요청에 포함하지 않는다. 같은 스타일 연결의
   품질부터 확실히 검증한다. 기존 v3 원본 5장/60프레임은 수정하지 않는다.

유지할 기술 계약
- ANIMOL_FREE_SHAPE_BLOB47_V1의 논리 연결 표를 유지한다.
- N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128.
- 양쪽 직교 이웃이 없는 대각선은 제거한다. 256 raw → 47 canonical 매핑 유지.
- 20스타일 × 47형태 × 4위상 = 셀 Sprite 3,760개.
- v = floorMod(x+(seed&1),2) + 2*floorMod(-y+((seed>>1)&1),2).
- 80개 256×192 atlas, 32×32 셀 rect, 기존 styleId/variantId/canonicalMask/rect 순서 유지.
- 셀 PPU32, 중심 pivot, Point, mipmap Off, 무압축. 알파는 0/255.
- 20개 128×128 motif, PPU32, bottom-left pivot, 4×4셀.
- 문양 후보와 6×6 동일 스타일 받침 조건, FNV-1a/seed 규칙 유지.
- 자동 회전·뒤집기·필터링·팔레트 변환으로 불일치를 숨기지 않는다.
- 논리 지형 크기는 제한하지 않는다. 16×16은 청크 단위다.

납품과 검수
1. 기존 폴더 구조의 아트 수정 ZIP, 새 SHA256/크기 manifest, 변경 목록을 제공한다.
   원본 v1 ZIP을 덮어쓰지 말고 명시적으로 아트 수정본 v2로 납품한다.
   논리 계약이 같다는 것과 아트 revision이 새롭다는 것을 별도로 표기한다.
   Unity의 저장 artVersion 갱신/기존 맵 표시 정책은 통합 시 명시적으로 처리한다.
2. 같은 논리 fixture·같은 seed의 수정 전/후 비교를 각 스타일별로 제공한다.
3. 16×16과 34×6 사각형, 가로/세로 1셀, 고립 셀, 비대칭 계단, U자 구덩이,
   닫힌 구멍, 천장/돌출부/안쪽 코너, (-1,-1) 및 16셀 청크 경계를 모두 렌더한다.
4. 정규화 후 실제로 이웃 가능한 mask 조합과 네 위상 전이에서 연결을 검사한다.
   인접 경계 픽셀을 무조건 같은 색으로 만드는 것이 아니라, 공통 질감 원본에서
   잘라 이어 붙였을 때 무늬가 연속되고 외곽 마감이 중복/누락되지 않아야 한다.
5. 확대 최근접 1:1/4:1 보기와 게임 배율에서 내부 반복·테두리 새어 나옴을 확인한다.
6. Sprite 누락/중복/방향 오류와 팔레트/알파 위반 검사 결과를 제공한다.
   이미지 생성 완료를 Unity 통합·플레이 검증 완료라고 표현하지 않는다.
