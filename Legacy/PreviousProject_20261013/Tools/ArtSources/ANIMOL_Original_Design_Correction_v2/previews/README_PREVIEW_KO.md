# 기존 디자인 복원 02 미리보기

`ANIMOL_Original_Design_Correction_v2_Preview.html`을 열면 외부 파일이나 네트워크 연결 없이 비교할 수 있다. 이 미리보기는 배경 아트와 캠페인 배킹 복원의 검토용이며 실제 Unity 캡처가 아니다.

- 메인 배경: 원래 디자인 / 지난 개정 v1 / 이번 수정. 아트 변경 시 같은 재생 시점을 유지한다.
- 5개 테마: 자동 5초 순환 또는 개별 선택. 전환 시간 0.36초.
- 발판: 카메라 이동 0. 원경·중경·근경은 기존 이동량과 속도를 유지한다.
- 토끼: 모든 비교에서 같은 현재 v1 시트, 64×96, 8프레임, 14fps, 셀 상단 Y=436. 캐릭터 디자인 변경은 없다.
- 확대: 1/2/3/4배 정수 최근접 표시. 작은 창에서는 스크롤하므로 원본 도트를 축소하지 않는다.
- 다리 보기: 네이티브 PNG의 Y=454~703 영역만 표시한다. 켜면 재생을 멈추고 청색 배킹 위에서 알파 윤곽을 확인한다.
- 캠페인 UI: 흰 배킹과 짙은 글자를 복원한 352×704 정지 참고 합성. 진행도·상태는 미연결이며 첨부 화면 글자 crop은 미리보기 전용이다. 실제 프리팹 배치나 글자 자산으로 수입하지 않는다. 배경 비교 설정은 이 화면에서 비활성화한다.

교체 범위는 배경 PNG 20개와 SC02 배킹·글자색 설정이다. SC02 런타임 PNG 교체는 0개다. 나머지 메인 UI·토끼·동물·게임 로직은 이번 비교의 변경 대상이 아니다.

`preview-verification.json`은 HTML에 포함된 JavaScript를 native Skia Canvas와 간단한 DOM 어댑터에서 실행한 결과다. 실제 15개 Canvas 렌더, 이미지 입력 해시, 정수 확대, 일시 정지, 화면 전환, 다리 crop 및 캠페인 참고 PNG 일치를 검사했다. 브라우저 엔진과 Unity 실행은 수행하지 않았으므로 Safe Area나 실제 프로젝트 폰트·이벤트 검증을 대신하지 않는다.

아트 파일을 수정한 후에는 다음 두 명령을 순서대로 실행하여 포함된 이미지와 검사 보고서를 갱신한다.

```bash
python work/art-correction02/preview/build-preview.py
node work/art-correction02/preview/verify-preview.cjs
```

두 번째 명령의 native Canvas 의존성은 이 작업 환경의 `CODEX_PRIMARY_RUNTIME_NODE_MODULES`에서 확인한다. HTML 자체에는 이 의존성이 없고 별도 설치가 필요하지 않다.
